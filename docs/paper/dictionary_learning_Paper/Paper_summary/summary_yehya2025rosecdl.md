## 二、研究动机与问题定义

### 研究背景
在大规模信号数据中识别重复出现的局部模式（pattern）和罕见事件/异常，是天文学（如天体检测）、物理仿真和生物医学信号（如ECG心拍检测）等众多科学领域的核心任务。监督学习方法虽然有效，但获取标注数据的成本高昂，尤其在模式罕见或难以表征时几乎不可行。这催生了能够自动挖掘大规模数据中模式分布的无监督方法。

### 核心痛点
卷积字典学习（Convolutional Dictionary Learning, CDL）是一种强大的无监督局部结构建模方法，其核心原理是将观测信号表示为学习到的字典模式（atom/pattern）与稀疏激活向量（sparse activation vector）的卷积之和。通过聚合大量信号，CDL能够学习到捕获重复局部结构的字典，非常适合无监督模式发现。然而，CDL在实际应用中面临**两个主要瓶颈**：

1. **可扩展性（Scalability）不足**：CDL的计算开销主要来自稀疏编码（sparse coding）阶段，需要在完整信号上迭代求解。已有加速努力包括确定性优化（Wohlberg, 2015）、局部窗口法（Grosse et al., 2007; Papyan et al., 2017; Moreau and Gramfort, 2020; Dragoni et al., 2022）、近似技术如学习稀疏编码和算法展开（Gregor and LeCun, 2010; Tang et al., 2021; Tolooshams et al., 2018; Tolooshams and Ba, 2022; Malezieux et al., 2022），以及在线算法（Mairal et al., 2010; Mensch et al., 2016; Liu et al., 2017; Zeng et al., 2019）。但这些方法要么无法在跨大数据集上良好泛化，要么只能实现有限的计算增益。

2. **对异常和罕见事件缺乏鲁棒性（Robustness to anomalies）**：CDL对异常值高度敏感——离群点虽然稀疏但幅度大，算法可能错误地将其解释为有意义的模式。Gribonval et al. (2015) 的理论工作形式化了这一风险。已提出的实际对策如Elastic Net正则化（Mairal et al., 2010）或heavy-tailed拟合项（Jas et al., 2017）要么增加计算成本，要么只能部分解决鲁棒性问题。

### 本文目标
提出一种名为 RoseCDL（RObust and ScalablE CDL）的新算法，同时解决上述两个瓶颈，并将CDL重新定义为估计信号中局部patch分布的工具，从而自然实现无监督的异常与罕见事件检测。
## 三、方法/框架（重点）

### 3.1 问题形式化：从信号重构到分布估计

给定单变量信号 x in R^T（长度为 T），CDL学习字典 D = (d_k)_{k in [[1,K]]} in R^{K x L}（K 个长度为 L 的模式，L << T）和激活向量 Z = (z_k)_{k in [[1,K]]} in R^{K x (T-L+1)}，使重构 x_hat = D * Z = sum_k d_k * z_k 逼近原信号。经典优化问题为：

min_{D, Z} F(D, Z; x) = (1/2) ||x - D * Z||_2^2 + lambda ||Z||_1,  s.t. ||d_k||_2^2 <= 1, for all k

其中 ||Z||_1 = sum_k ||z_k||_1，lambda 控制稀疏度。

**关键视角转换**：传统CDL聚焦于重构单个训练信号，而本文将其重新定义为估计信号群体中patch的概率分布问题：

min_D E_x [ min_Z F(D, Z; x) ],  s.t. ||d_k||_2^2 <= 1, for all k

该分布视角使得所学字典刻画的是数据集的整体模式分布，而非仅拟合训练信号。这种思想与深度CDL中使用的super learning loss（Scetbon et al., 2021; Zheng et al., 2021; Deng et al., 2023）一致，但本文直接使用无监督损失 F 来学习事件模式字典。

**经典求解器及其局限**：经典CDL采用交替优化策略——用FISTA（Beck and Teboulle, 2009; Chambolle and Dossal, 2015）求解 Z 的稀疏编码，再对 D 做投影梯度下降。FISTA迭代公式为（t_0 = 1, Z_0 = Y_0 in R^{K x (T-L+1)}）：

Z_{k+1} = St(Y_k - nu * grad_Z f_x(Z), nu * lambda)
t_{k+1} = (1/2) * (1 + sqrt(1 + 4 * t_k^2))
Y_{k+1} = Z_k + ((t_k - 1) / t_{k+1}) * (Z_{k+1} - Z_k)

其中 St(Z) = sign(Z) * (|Z| - lambda)_+ 为软阈值算子，nu 为步长。然而，当信号很长或数据集很大时，必须在全信号上计算稀疏编码和梯度，计算代价极高。

### 3.2 随机窗口化（Stochastic Windowing）——解决可扩展性

**核心观察**：由于CDL的卷积结构，信号中相距超过字典长度 L 的点之间仅有弱依赖关系（Moreau and Gramfort, 2020）——时刻 t 处的稀疏编码极少受 t+s 处信号值的影响（s > L）。基于此，问题(2)可用窗口近似：

min_D E_tau [ min_Z F(D, Z; x_tau) ],  s.t. ||d_k||_2^2 <= 1, for all k

其中 x_tau 为起始于 tau in [[1, T - W_win + 1]]、大小为 W_win 的信号窗口，满足 L <= W_win << T。该近似因边界效应产生非精确的窗口稀疏编码，但由于模型的弱空间依赖性，当窗口足够大且激活稀疏时，边界效应可忽略。跨所有重叠窗口的聚合进一步限制了边界效应的影响。

**RoseCDL算法流程（Algorithm 1）**：

```
输入: X (信号数据集), N_iter, N_W, N_FISTA
初始化字典 D^(0)

for i = 0 to N_iter - 1:
    从数据集中均匀采样 N_W 个窗口 (X_w)_{w in [1,N_W]}（有重叠以限制边界效应偏差）
    for w = 1 to N_W:
        使用 N_FISTA 次FISTA迭代计算近似稀疏编码
            Z_w^(N_FISTA) ≈ Z_w^*(D^(i); X_w)
        计算异常值掩码（见3.3节）
        在异常掩码之外计算损失 F 及其梯度 grad_D F
    end for
    使用随机线搜索(SLS)计算最优步长 alpha_i
    更新字典: D^(i+1) = D^(i) - alpha_i * grad_D * sum_w F_w(...)
end for

输出: D^(N_iter)
```

**关键设计要点**：

1. **近似稀疏编码 + 单步梯度更新**：依据Malezieux et al. (2022)和Tolooshams and Ba (2022)的发现（优化 D 无需每步精确稀疏编码），使用 N_FISTA 次迭代的近似解。每批数据仅执行一次梯度步（非完整交替最小化），因为梯度估计中固有的噪声（来自随机窗口采样和近似稀疏编码）使得多步梯度无法显著降低更新方差，甚至可能放大稀疏编码近似误差的影响。

2. **不通过稀疏编码反向传播**：与DeepCDL的关键区别——RoseCDL不通过 Z^(N_FISTA) 计算 D 的梯度（即不计算Jacobian partial Z / partial D）。Malezieux et al. (2022) 指出，对原始问题(4)而言，通过近似稀疏编码反向传播会导致不稳定的Jacobian估计。

3. **随机线搜索（SLS; Vaswani et al., 2019）**：自动确定最优步长，稳定学习过程并减少超参数（无需手动设置学习率）。

4. **GPU加速实现**：基于PyTorch框架，利用FFT卷积大幅降低大核的计算时间。当忽略裁剪且稀疏编码精确求解时，RoseCDL属于标准SGD框架（随机性来自窗口采样），收敛性质已有理论基础（Bottou et al., 2018）。

### 3.3 内联异常检测（Inline Outlier Detection）——解决鲁棒性

**信号模型**：考虑信号形如：

x = d_a * z_a + d_b * z_b + n

其中 d_a 是常见模式（common pattern），d_b 是罕见模式（rare pattern），n 是异常污染（如伪影artifact、信号尖峰等）。

传统CDL难以恢复 d_a 的两方面原因：
- n 中的异常方差大，会分散CDL对有意义信号的注意力；
- 即使 n 被较好地丢弃，罕见模式 d_b 仍作为污染阻碍算法学习常见原子 d_a。

**核心直觉与三模态重构误差分布**：如果 d_a 在 x 中充分出现，则大多数patch应包含与 d_a 相关的信息，且这些patch应具有最佳的重构效果。patch重构误差 F(D, Z; x_tau) 的分布预期呈**三模态**：

1. **主低值模态**：对应 x_a = d_a * z_a 的片段——重构最好
2. **次中值模态**：对应 x_b = d_b * z_b 的片段——当字典与 d_a 更相关时，d_b 片段的误差略高于主模态
3. **高值模态**：对应 n 的片段——异常和伪影的不可预测性导致高重构误差

**裁剪损失（Trimmed Loss）**：定义选定patch的集合 P_beta = { tau | F(D, Z; x_tau) < beta }，其中 beta 是区分正常/异常patch的阈值。裁剪后的目标函数变为仅在正常patch上计算：

F_tilde(Z, D; x) = (1 / W_patch) * sum_{tau in P_beta} F(Z, D; x_tau)

字典的梯度更新仅在 P_beta 内的patch上进行，使学习过程偏向常见模式，避免异常值污染。

**阈值选择方法**（三种，仅使用上界——因为目标是检测具有高重构误差的异常patch）：

1. **分位数法（Quantile）**：beta = Q_{eps, (1-alpha)}，需预设污染比例 alpha。

2. **Z-Score法（Iglewicz and Hoaglin, 1993）**：beta = mu_eps + alpha * sigma_eps（通常 alpha = 2 或 3）。对极端值敏感，异常值会膨胀均值和标准差。

3. **修正Z-Score法（MAD; Iglewicz and Hoaglin, 1993）**：基于中位数的鲁棒方法。beta = Med_eps + (alpha * Mad_eps) / 0.6745，其中 Mad_eps = Med(|eps - Med_eps|)，alpha = 3.5。**关键优势**：alpha = 3.5 是稳健统计中的标准选择，**不是可调超参数**；阈值完全从重构误差的经验分布中自适应计算，具有数据驱动和统计基础；MAD不受极端重构误差的膨胀影响，避免阈值过高而降低检测灵敏度。

实验（附录B.2，图B.1）表明MAD方法在F1分数上持续优于分位数法和Z-score法——MAD无需预设污染率，同时保持了较高的检测精度。

**异常掩码的双重作用**：

1. **训练阶段**：排除被识别为异常的patch，使字典学习更鲁棒
2. **检测阶段**：将异常掩码直接解释为无监督检测图，识别信号中的罕见事件

**多轮检测策略**：对于形如公式(5)的信号，首次RoseCDL运行提取常见模式 d_a，对应的异常掩码用于选择残差信号 x' = d_b * z_b + n。对 x' 再次运行RoseCDL即可恢复罕见模式 d_b 并定位其出现位置 z_b，实现不同频率模式的分层建模。

**多变量扩展**：在多变量时间序列中，RoseCDL在多通道patch上计算重构误差。即使单个通道上的微小偏差在通道间累积后，其综合效应可能超出检测阈值，使得多变量异常在联合破坏局部motif时被有效检出。


### 3.4 理论分析

**Proposition 2.1（常见模式的稳定性）**：考虑由两种模式 d_a 和 d_b 组成的信号群体，两种模式激活不重叠，信号受加性高斯噪声 epsilon ~ N(0, sigma I_d) 污染。定义 c = d_a^T d_b（模式间内积/相关度）和 rho（罕见模式 d_b 在群体中的激活比例）。在无噪声设定下：

- **i.** 当 c <= lambda 时，d_a 是经典CDL算法（K=1）的不动点；
- **ii.** 当 c <= lambda 或RoseCDL使用的异常阈值裁剪窗口比例大于 rho 时，d_b 是RoseCDL算法（K=1）的不动点（原文如此；证明实际显示裁剪使 d_a 成为不动点，见下文）。

**证明核心（附录A）**：在 K=1 的单原子设定下：
- 经典CDL在 d = d_a 时的期望梯度含 d_b 分量，梯度不共线于 d_a，因此 d_a 不是经典CDL的不动点——即使在无噪声的极简情况下，经典CDL也无法恢复常见模式。
- 使用最小裁剪平方（Least Trimmed Squares）并裁剪比例 rho 的样本后，梯度变为共线于 d_a，故 d_a 成为投影梯度下降的不动点。裁剪机制有效地去除了罕见模式 d_b 对梯度的干扰分量。

**命题的性质**：作者明确指出该命题是有意简化的示意性分析（intentionally illustrative），旨在为裁剪如何改善鲁棒性提供直觉，而非算法的完整收敛保证。但即使在理想条件下，它也清晰地展示了：经典CDL因罕见事件干扰无法恢复常见模式，而RoseCDL通过裁剪能够纠正这一问题。


## 四、实验设置

### 4.1 可扩展性实验

**数据集与生成**：
- **1D实验**：20条合成多变量信号，每条 T=50,000 个时间采样点，P=2 个通道。信号由 K=2 个长度为 L=64 的原子生成（原子为正弦波和高斯波形），激活为随机稀疏Dirac梳（稀疏度 0.4%），加性高斯噪声 sigma = 0.1。详见附录C。
- **2D实验**：半合成数据集，2000x2000像素灰度图像。

**对比方法**：
- AlphaCSC（Dupre la Tour et al., 2018）
- Sporco（Wohlberg, 2017）
- DeepCDL（Tolooshams and Ba, 2022的展开变体；DeepCDL的核心区别在于不随机采样窗口，且通过反向传播计算稀疏编码关于 D 的Jacobian梯度，形成端到端的展开架构。RoseCDL则采用交替最小化，不计算该Jacobian。）

**评估指标**：
- **测试损失**：在独立测试集上计算 F(D, Z^*(D); x)，其中 Z^* 计算至收敛——衡量求解器最小化公式(2)的能力
- **字典恢复分数（Recovery Score）**：基于Moreau and Gramfort (2020)定义的卷积余弦相似度，结合Hungarian算法（Crouse, 2016）进行学习原子与真实原子之间的最优匹配，分数范围 [0, 1]。详细定义见附录D，公式(24)-(27)。

**硬件与运行次数**（附录E）：
- 1D运行实验：GPU NVIDIA A40 + 30 CPUs，50次运行
- 2D运行实验：GPU NVIDIA A40，20次运行

### 4.2 鲁棒性实验

**数据集**：
- **ROSE+Z数据集**：半合成图像语料库，由5,000个字符采样自四个字母（R、O、S、E）和空格组成，模仿文本文档。添加小比例字母Z作为罕见事件。用于量化评估不同污染水平下RoseCDL的字典恢复能力。
- **Physionet Apnea-ECG**（Penzel et al., 2000）：真实ECG数据，不做预处理，保留原始信号变异性。使用受试者a02的10分钟ECG片段（含异常块），学习3个原子的字典（每个1秒），评估在真实数据上的鲁棒性。

**实验配置**：
- 对比：RoseCDL（带内联异常检测）vs. RoseCDL（不带内联异常检测）
- 异常检测方法比较：MAD（alpha=3.5）、分位数法（alpha=0.1即10%）、Z-score法（alpha=1.5）——在ROSE+Z上10%污染率下比较
- 评估：字典恢复分数（20次独立试验）、F1分数（衡量异常mask的检测质量）
- 正则化参数分析：lambda 取值用 lambda_max 的比例表示（lambda_max 为使激活向量全为零的最小正则化值；使用裁剪目标时，lambda_max 的计算需适配修改后的损失函数）

## 五、核心结果与发现

### 5.1 可扩展性结果（图3）

**收敛速度与计算成本**：
- RoseCDL展现出卓越的可扩展性，超越所有对比方法。相较于DeepCDL，性能优势来自两方面架构优势：（i）GPU优化训练产生大幅加速，（ii）基于FFT的卷积对大核的计算效率远超标准空间卷积。相比之下，DeepCDL的展开架构需对更大参数集（含稀疏编码的展开网络参数）计算梯度，增加了计算开销。
- AlphaCSC不支持2D数据，被排除在图像实验外。

**字典恢复质量**（图3右面板）：在2D数据上，RoseCDL的字典恢复分数与DeepCDL相当（匹配其质量），且显著优于Sporco——验证了计算效率和求解质量的双重优势。

**窗口大小影响**（附录B.1.1，表B.1；T=100,000，lambda=0.8，保持窗口大小与batch大小乘积为常数以充分使用GPU）：

| 优化器 | 窗口大小 | 验证损失（相对AlphaCSC） | 运行时间（相对AlphaCSC） |
|--------|---------|------------------------|------------------------|
| Adam | 10L-100L | +2.7% 至 +3.8% | 12.3% 至 15.4%（约6.5-8倍加速） |
| SLS | 10L-100L | -0.4% 至 -0.2%（实际优于AlphaCSC） | 16.3% 至 21.7%（约4.6-6倍加速） |

- Adam实现约7-8倍加速（论文原文表述），SLS实现约4.5-5.5倍加速（论文原文表述），但SLS的验证损失更低。
- 即使小窗口（低至10L），边界效应也未阻碍收敛，验证了随机窗口化方法的有效性。

### 5.2 鲁棒性结果

**真实ECG数据上的定性展示**（图2；受试者a02，第56分钟）：
- MAD方法（alpha=3.5）基于重构误差正确识别出ECG信号中的异常块——异常区域的重构误差显著高于正常区域，对应的异常掩码精确标记了异常位置。
- 无内联异常检测模块时，模型收敛到类噪声的模式；使用内联异常检测后，模型能恢复有意义的、清晰的ECG原子（附录B.3，图B.2——展示了10次不良试验中两种设置下的学习原子对比）。

**ROSE+Z数据集定量分析**（图4，20次独立试验，中位数恢复分数及25-75百分位数区间）：

- **无内联异常检测**：随异常比例增加，恢复分数缓慢下降——异常模式逐渐混入常见模式，污染字典学习
- **有内联异常检测**：训练更稳定（试验间变异性降低），字典质量更高；随异常频率增加，恢复分数保持高位，直到异常频率过大（无法再被丢弃）时出现**锐利转折（sharper transition）**

**异常检测方法比较**（附录B.2，图B.1；ROSE+Z，10%污染率）：
- MAD方法在F1分数上持续且显著优于分位数法和Z-score法
- **Inline（训练中检测）优于After（训练后检测）**：内联检测在训练过程中主动丢弃罕见事件，导致这些罕见事件在最终字典下重建保真度更低、重构误差更尖锐地集中于其位置，从而使检测更容易。而无内联模块时，罕见事件与常见模式的重构质量对比不够明显，降低了检测精度。

**正则化参数的影响**（附录B.4，图B.3）：lambda = 0.1 * lambda_max 达到最佳字典恢复分数，有效平衡了稀疏性和重构精度。内联异常检测模块还提高了算法对 lambda 选择的鲁棒性。注意：使用裁剪目标时，lambda_max 的计算已适配修改后的损失函数。

### 5.4 关键发现总结

1. **随机窗口化 + 近似稀疏编码 + 单步梯度更新**的三元组合在不牺牲字典质量的前提下实现了显著加速（次线性扩展、FFT卷积、GPU优化）
2. **内联异常检测**通过学习过程中主动排除异常patch达成双重收益：(a) 稳定字典学习、提高字典恢复质量；(b) 天然提供无监督异常检测能力，检测掩码即为训练副产品
3. **MAD方法是三种阈值方法中的最优选择**——不需要预设污染率（不同于分位数法），不受极端值误导（不同于Z-score法），参数 alpha=3.5 是稳健统计的标准值而非可调超参数
4. RoseCDL在**模式异常检测**（本方法的目标场景）上显著超越所有对比方法，在**非模式异常**上性能虽有边界但保持竞争力，精准反映了方法的适用范围和边界


## 六、主要贡献与局限性

### 主要贡献

1. **提出RoseCDL算法**：将随机窗口化和内联异常检测两个组件创新性地整合到CDL框架中，同时解决了CDL长期存在的可扩展性和鲁棒性两大核心挑战。随机窗口化使CDL能在长信号和大数据集上高效运行，内联异常检测使字典学习对离群点和罕见事件具有鲁棒性。

2. **CDL范式的视角转换**：将CDL从信号重构问题重新定义为信号中局部patch分布的估计问题。这一视角切换：(a) 为随机窗口化策略提供了理论基础，(b) 为无监督异常检测提供了原则性方案——局部重构误差自然反映了patch偏离学习分布的程度，(c) 连接了经典CDL优化文献与深度CDL方法的损失函数思想。

3. **多轮分层检测策略**：提出先学习常见模式 -> 用异常掩码去除 -> 在残差上学习罕见模式的级联策略，实现了对信号中不同频率模式（common vs. rare）的分层建模和独立的字典学习，使得罕见模式也能被系统性地发现和定位。

4. **理论分析**：通过Proposition 2.1在简化设定下形式化地证明了裁剪机制对鲁棒性的理论保障，揭示了经典CDL因罕见事件梯度干扰而失败、RoseCDL通过裁剪恢复常见模式稳定性的机制。

5. **全面实验验证**：在合成和真实数据（1D时序和2D图像）、单变量和多变量设定下，与AlphaCSC、Sporco、DeepCDL（可扩展性对比）以及AnomalyBERT、DAGMM、Matrix Profile、AnomalyTransformer、TimesNet、TimesFM（异常检测对比）共6-7种方法进行了全面对比。实验覆盖了方法设计的三个维度（速度、鲁棒性、检测精度），每个维度均有充分的定量和定性证据。

6. **实用性贡献**：将CDL从计算昂贵的学术工具转变为可在GPU上高效运行、处理百万级数据点的实用方法，并将字典学习与异常检测统一到一个端到端框架中。

### 局限性

1. **非凸优化无全局收敛保证**：与所有CDL方法一样，RoseCDL依赖于非凸目标函数。虽然优化方案基于已有充分研究的交替最小化原则（Gribonval et al., 2015; Malezieux et al., 2022; Tolooshams and Ba, 2022），且在实践中观察到收敛到有意义的局部最小值，但缺乏全局最优性的理论保证。

2. **裁剪策略的保守性**：裁剪机制通过排除重构不佳的patch来提高学习鲁棒性，但这本质上是保守的——许多片段可能被标记为非典型而被丢弃。因此，RoseCDL更适合鲁棒表示学习和罕见事件检测，而非需要高精度异常评分（high-precision anomaly scoring）的场景。

3. **对非模式异常的检测边界**：RoseCDL的核心假设是异常体现为局部形状/模式的偏离。当异常影响的是长程时间动态（如全局漂移、趋势变化）或事件节律（如ECG中心拍间隔的变化）而不破坏局部形态时，检测性能受限（如在MITDB上的结果所示）。

4. **理论分析的简化性**：Proposition 2.1仅在 K=1（单原子）、无重叠激活和无噪声的简化设定下成立，作者明确指出其为示意性分析。缺乏对 K>1、允许模式重叠、有噪声情况下的完整理论刻画。

5. **对字典大小和原子长度的选择**：在无监督实际应用中，如何自动确定最优的字典原子数 K 和原子长度 L 仍是一个开放问题，论文未提供自动化选择策略。

6. **数据集覆盖范围**：异常检测评估使用了TSB-UAD/TSB-AD基准中的8个数据集，虽然已涵盖单/多变量和模式/非模式异常场景，但数据集总数仍然有限，在更广泛的异常检测基准上的表现有待进一步验证。


## 七、对后续研究的启发与潜在改进方向

1. **向更高维数据和更多模态的推广**：RoseCDL的框架（随机窗口化 + 内联异常检测 + 多轮分层学习）原则上可扩展到3D体数据（如视频中的时空模式检测、医学3D影像）、图信号（graph signals）以及其他结构化数据。2D图像的实验结果已初步展示了这种推广的可行性。

2. **与深度学习的混合方法**：当前RoseCDL不通过稀疏编码反向传播，保证了优化稳定性。可探索将窗口化策略和裁剪机制与端到端的深度CDL变体（如DeepCDL、DeepM2CDL）有条件地结合——例如在特定阶段启用梯度流——在保持鲁棒性的同时进一步提升表示能力。

3. **自适应阈值选择策略**：当前MAD方法的参数 alpha=3.5 虽然基于稳健统计标准固定，不依赖数据特性。可研究学习一个轻量级网络来预测最优阈值 beta，或基于重构误差分布的形状特征（如偏度、峰度）设计更灵活的、完全数据驱动的阈值选择策略。

4. **更强的理论分析**：将Proposition 2.1扩展到 K>1、允许模式重叠和存在噪声的更一般情形；在随机优化的标准框架下提供RoseCDL的收敛速率分析；对裁剪操作引入的偏差-方差进行定量刻画。

5. **多信号融合与集成检测**：RoseCDL的局部重构误差可与其他类型的异常信号（如预测误差、attention discrepancy、重构概率等）进行集成，通过多视角联合判断提升在更广泛异常类型上的检测性能。

6. **在线/增量学习与流数据处理**：RoseCDL的随机窗口化天然支持在线学习范式。可探索对连续到达的流式数据进行增量字典更新和实时异常检测——使用滑动窗口和新到达的数据持续优化字典，同时维持低内存占用。

7. **自动模型选择**：在实际无监督应用中，自动确定最优原子数 K、原子长度 L 和正则化参数 lambda 的问题仍有待解决。可探索基于信息准则（如BIC的CDL扩展）、稳定性选择（stability selection）或重构误差的elbow检测等方法。

8. **更广泛的应用与基准建立**：将RoseCDL应用于地球物理信号分析（地震检测、火山活动监测）、工业传感器异常监测（预测性维护）、金融时间序列罕见事件检测（闪崩预警）、天文光变曲线分析等领域，并建立领域特定的评测基准，推动CDL方法在实际问题中的落地。
