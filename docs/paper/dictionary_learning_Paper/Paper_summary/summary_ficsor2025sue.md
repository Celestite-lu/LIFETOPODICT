## 研究动机与问题定义

随着深度学习模型在医疗、金融、法律、教育等高风险的现实场景中日益广泛地部署，模型不仅需要高预测精度，还需具备识别不可靠预测的能力。选择性分类（Selective Classification）允许模型在置信度不足时拒绝对特定样本做出预测，从而降低误分类比例。然而，现有的不确定性估计（Uncertainty Estimation, UE）方法各有显著局限：

1. Softmax Response (SR)：直接从Softmax层输出概率中获取置信度，但众所周知Softmax概率通常校准不良，倾向于过度自信（overconfident）。
2. Mahalanobis Distance (MD)：基于隐藏表示的均值和协方差结构计算距离，但依赖于预定义的每类高斯分布假设（需要估计类别条件均值和协方差矩阵），对于类别分布不均衡或复杂特征空间不适用。
3. 贝叶斯推断方法（如Monte Carlo Dropout, MC）：需要在推理时执行多次随机前向传播，计算开销大，难以大规模部署。

针对上述痛点，本文提出了一种全新的不确定性估计框架 SUE（Sparsity-based Uncertainty Estimation），基于稀疏字典学习（Sparse Dictionary Learning）。该方法不对类别的空间分布做任何假设（如均值或方差的预定义结构），计算效率高，可扩展性好，同时通过字典原子级别的分析提供可解释性。

该工作受到 Berend (2020) 在词义消歧任务中利用稀疏编码特征的PMI统计量的启发，将类似的思路迁移到不确定性估计任务中。

## 方法/框架（重点）

SUE 的核心思想是：利用稀疏字典学习将模型的隐藏表示分解为字典原子的稀疏组合，然后通过逐点互信息（PMI）量化每个字典原子的激活与预测错误之间的统计关联，最后基于这些关联计算每个测试样本的不确定性分数。

SUE 包含三个关键步骤：

### 步骤一：构建稀疏表示（Sparse Representation）

给定输入矩阵 X，每行对应一个样本的 [CLS] token 嵌入向量，其中 d 是隐藏维度，N 是样本数。目标是通过求解以下优化问题学习字典矩阵 D 和稀疏系数 alpha：

min_{alpha, D} (1/2) ||X - alpha D||_F^2 + lambda ||alpha||_1    (1)

其中：
- K 是字典原子的数量（超参数，实验中取 {256, 512, 768}）
- lambda 是稀疏正则化系数（超参数，实验中取 {0.01, 0.02, 0.04, 0.06, 0.08, 0.1}）
- ||alpha||_1 是 L1 正则化项，用于鼓励稀疏性（只允许少数系数为正），使得 alpha 中仅有少数值为非零，从而更可解释且具备更好的泛化能力

关键设计选择：
- 在进行分解之前，对 X 的每一行进行 L1 归一化以提高稳定性（遵循字典学习的常见实践）。
- 仅使用被模型正确分类的样本来训练字典矩阵 D。这一筛选操作鼓励字典原子反映可靠模式，避免模糊/错误分类样本将噪声引入字典。但如果仅使用某一特定类别的样本来构建字典，可能会对少数类产生欠代表性问题，因此论文选择使用所有正确分类样本，而不区分具体类别。
- 字典 D 在与模型训练数据不相交的验证集（校准集的一部分）上训练；测试时 D 保持固定，仅推断 alpha_test。训练与测试的分离使字典原子具备更强的泛化能力。

### 步骤二：通过逐点互信息（PMI）量化原子与预测不确定性的关联

核心思路是识别哪些字典原子的激活频繁与预测错误共现。这些"不确定性原子"可以作为预测失败的指标。

首先构建共现矩阵 C，记录每个字典原子的激活与二元正确性标签 L（0 表示错误分类，1 表示正确分类）之间的共现统计：

C_{k, l} = sum_{n} I[alpha^{(n, k)} != 0 AND L^{(n)} = l]    (2)

其中 I[.] 是指示函数，alpha^{(n,k)} 表示样本 n 在字典原子 k 上的稀疏系数，L^{(n)} 表示样本 n 的预测正确性。该统计使用所有校准集样本（不限于训练字典时使用的正确分类样本）。

从 C 中计算联合概率 P(k,l) 和边缘概率 P(k)、P(l) 的最大似然估计。字典原子 k 的非零激活与正确性标签 l 之间的 PMI 值定义为：

Phi_{k, l} = log( P(k, l) / (P(k) P(l)) )    (3)

Phi_{k,l} 捕捉了原子 k 的激活与特定预测结果（正确/错误）之间的统计关联强度：正的 PMI 值表示该原子的激活与正确分类的共现概率高于随机水平的期望（即该原子是 confidence-inducing），而负的 PMI 值则相反（该原子是 uncertainty-inducing）。

### 步骤三：量化不确定性估计值

对于测试样本 i，利用其稀疏表示 alpha_test^{(i)} 聚合其所有活跃原子的 PMI 分数：

U_SUE^{(i)} = -(alpha_test^{(i)} dot Phi_{(:, 1)})    (4)

其中 Phi_{(:,1)} 是与正确分类样本（即 l=1 对应列）相关的 PMI 值向量。

负号确保了分数与不确定性的直观对应关系：
- 若测试样本的活跃原子与正确分类强正相关（Phi_{k,1} > 0），则 alpha_test 与 Phi 的点积为正，取负后 U_SUE 较小，表示高置信度。
- 若活跃原子与正确分类不相关或负相关（Phi_{k,1} <= 0），则贡献接近零或为负，取负后 U_SUE 较大或为零，表示高不确定性。

关键可解释性特点：每个字典原子对 U_SUE 的贡献可以直接被检查（通过 alpha_test^{(i,k)} x Phi_{k,1} 的值），使得不确定性可以追溯到表示空间的特定构建块（building blocks），这是 SR、SE 等基于输出概率的方法所不具备的。

### SUE 整体流程

1. 从校准集中筛选出模型正确分类的样本，提取其 [CLS] 嵌入向量形成 X_dev。
2. 对 X_dev 进行 L1 行归一化。
3. 通过式（1）学习字典矩阵 D 和稀疏系数 alpha_dev。
4. 利用所有校准集样本（不限于正确分类的），用学习到的 D 获得所有样本的稀疏系数 alpha。
5. 通过式（2）构建共现矩阵 C，通过式（3）计算 PMI 矩阵 Phi。
6. 对测试样本，用固定的 D 推断 alpha_test。
7. 通过式（4）计算最终不确定性分数 U_SUE。

## 实验设置

### 模型
- BERT-Base（隐藏维度 d=768）
- BERT-Large
- RoBERTa-Base

所有模型针对各任务进行微调。微调超参数搜索空间：学习率 {1e-5, 2e-5, 5e-5, 1e-6, 2e-6, 5e-6}，批次大小 {8, 16, 32}，权重衰减 {0, 0.1, 0.01}。GLUE 任务使用公开可用的 BERT-Large 检查点。

### 数据集
1. 情感分析/内容审查任务（均二值化处理，遵循 Vazhentsev et al., 2023）：
   - ParaDetox（约19.7K样本，毒性检测）
   - Twitter Sentiment（仇恨言论/冒犯性语言检测）
   - Jigsaw Toxic Comment Classification
2. 对抗推理任务：
   - ANLI（Adversarial NLI）R1/R2/R3：故意设计为高难度挑战集，三分类任务
3. GLUE 基准（仅BERT-Large）：
   - CoLA（语言可接受性判断，二分类）、MRPC（释义检测，二分类）、QNLI（问答自然语言推理，二分类）、SST-2（情感分析，二分类）、QQP（问题对等价判断，二分类）

数据划分详情（非GLUE任务）：
- ANLI 各子集：从官方训练集中取8,000用于训练，8,000用于校准；开发集和测试集保持官方分割不变。
- ParaDetox / Twitter：8,000训练，8,000校准，1,000开发，其余测试。
- Jigsaw：从官方训练集取8,000训练，8,000校准；从官方测试集取1,000开发，3,000测试。

GLUE任务数据划分：由于GLUE任务样本量较小，保持官方训练集不变，将官方开发集按40%/60%比例划分为开发和测试集。GLUE数据统计（Table 5）：CoLA开发417/测试626（模型准确率84.85%），MRPC 163/245（87.99%），QNLI 2,185/3,278（92.23%），SST-2 348/524（93.46%），QQP 16,172/24,258（91.07%）。

### 评估指标
eAU-RCC（Excess Area Under the Risk-Coverage Curve）：

eAU-RC = integral_{0}^{1} (R(c) - R*(c)) dc

其中 R(c) 是覆盖水平 c 下的经验风险（基于零一损失），R*(c) 是Oracle（最优）风险。eAU-RCC 值越低表示不确定性估计越接近Oracle排序，性能越好。虽然某些任务通常使用专门指标（如CoLA用 Matthews Correlation Coefficient），但为与零一损失的风险覆盖曲线保持一致，所有任务统一报告准确率。

### 对比基线
- Softmax Response (SR)：U_SR = 1 - max_c p(y=c|x)
- Shannon Entropy (SE)：U_SE = -sum_c p(y=c|x) log p(y=c|x)
- Mahalanobis Distance (MD)：U_MD = min_c (h - mu_c)^T Sigma^{-1} (h - mu_c)，其中 h 为[CLS]隐藏状态，mu_c 为类别 c 的均值向量，Sigma^{-1} 为训练集协方差矩阵的逆
- Mahalanobis++ (MD++)：先对输入向量进行单位归一化再计算马氏距离（Muller and Hein, 2025）
- MC Dropout 变体（T in {10, 25, 50} 步随机前向传播）—— 重要实现细节：遵循 Shelmanov et al. (2021) 的建议，在推理时启用Transformer所有层的dropout：
  - MC-SMP（Sampled Maximum Probability）：U_SMP = 1 - max_c (1/T) sum_t p(y=c|x_t)
  - MC-PV（Probability Variance）：U_PV = (1/C) sum_c (1/T) sum_t (p(y=c|x_t) - p_bar_c)^2，其中 p_bar_c = (1/T) sum_t p(y=c|x_t)
  - MC-BALD（Bayesian Active Learning by Disagreement）：U_BALD = -sum_c p_bar_c log p_bar_c + (1/T) sum_{c,t} p(y=c|x_t) log p(y=c|x_t)

### SUE 超参数配置
- 正则化系数 lambda in {0.01, 0.02, 0.04, 0.06, 0.08, 0.1}
- 字典原子数 K in {256, 512, 768}
- 对于非GLUE任务：8,000样本的校准集按拆分比例 sr in {0.2, 0.4, 0.6, 0.8} 分为字典学习部分和PMI计算部分（sr 比例用于字典学习，其余用于PMI统计）
- 理论推荐值：lambda = 1.2 / sqrt(d)，对BERT-Base（d=768）约为 0.0433
- 超参数最终选择基于各任务验证集性能

- Jigsaw：SUE 0.44（最优，第二名为 MC-SMP 0.55）
- ANLI-R1：SUE 30.65（最优，第二名为 SE 38.81，提升约21%）

### 核心趋势总结
1. SUE 在高不确定性场景中表现尤为突出：当模型精度较低时（如ANLI各子集，准确率仅约35-40%），SUE相比所有基线方法均有显著且一致的提升。任务越难、模型精度越低，SUE相对优势越大——这一趋势在GLUE、ANLI和情感分类基准上保持一致。
2. MD/MD++ 在所有任务上普遍表现较差，表明其基于类条件高斯分布的假设在NLP序列分类任务中并不适用。MD系列方法有时甚至不如简单的SR/SE基线。
3. MC方法在简单任务上表现有竞争力（特别是MC-PV和MC-SMP在ParaDetox上取得最优），但在更难任务（ANLI）上效果下降明显。此外MC方法需要T次反复前向传播（实验中T高达50），计算成本显著高于SUE。
4. SR和SE在许多任务上表现出极其相似的eAU-RCC分数（如BERT-Base Jigsaw上两者均为0.65），说明仅靠输出概率难以区分不同样本的置信度细微差异。
5. SUE的计算优势：测试阶段仅需一次稀疏编码推断（给定固定字典D）和一次向量点积，远低于MC方法的T次完整前向传播。

### 超参数消融分析（Section 6.1）

- 校准集拆分比例（sr）对 eAU-RCC 分数影响不大，表明字典学习和PMI计算之间的数据分配并非关键因素。
- 正则化系数 lambda 和字典原子数 K 的影响更为显著，且呈现任务依赖性差异：
  - 简单任务（ParaDetox, Twitter, Jigsaw）：较少原子即可，较强正则化有帮助避免原子过拟合到少量样本。
  - 困难任务（ANLI）：更多原子可以提取更独特和多样化的模式，中等程度的正则化效果更好。
- 理论推荐值 lambda = 1.2 / sqrt(d) 表现稳定：对BERT-Base约为0.0433，与最优值仅存在微小差异，是一个非常合理的默认初始值。论文建议固定 lambda 为理论值，仅根据样本量和任务难度调整 K。
- 超参数鲁棒性验证（Figure 5）：在BERT-Base的所有超参数组合下，验证集和测试集的eAU-RCC呈现良好的正相关关系，说明验证集上表现好的超参数组合在测试集上也保持一致，SUE对超参数选择具有较好的鲁棒性。
- 任务 vs 模型的影响（Figure 7-9，附录B）：跨BERT-Base/Large/RoBERTa的对比显示，任务类型对UE分数的影响显著强于模型选择，这是SUE在不同模型上表现一致的重要原因。

### 可解释性分析（Section 6.3）

SUE的独特优势在于其原子级别的可解释性。Figure 6展示了每个字典原子对最终不确定性的贡献可视化，以力图（force plot）形式表示：
- 红色柱子（向右）：推动置信度更高（该原子与正确分类正相关，alpha_k x Phi_{k,1} > 0）
- 蓝色柱子（向左）：推动不确定性更高（该原子与正确分类负相关或无关，alpha_k x Phi_{k,1} <= 0）
- 最终SUE分数由这些对立力量的平衡点决定。

论文分析了ParaDetox中被SUE赋予高置信度但实际被误分类的样本（Table 4），发现这些样本的前6个完全不含任何"不确定原子"，而后几个样本仅含1-2个轻微不确定原子。其原因包括：
- 数据集中的简单错误（如仅将"generation"替换为"gen"就改变标签）
- 缺乏上下文或个人容忍度差异导致的语义模糊

在MRPC上也有类似发现（Table 6）：对top-25%最高置信度的误分类样本的人工检查确认，其中不少实际上是标注错误或语义高度模糊的样本。这解释了为何SUE在MRPC的早期低覆盖率阶段会出现风险上升（Figure 11b）。

## 主要贡献与局限性

### 主要贡献
1. 提出了一种全新的不确定性估计框架 SUE，基于稀疏字典学习和逐点互信息（PMI）。与MD不同，该方法无需对类别空间分布（如均值、方差）做任何参数化假设；与MC方法不同，它不需要多次随机前向传播。
2. 计算效率高：测试阶段仅需一次稀疏编码推断（给定固定字典 D）和一次向量点积运算，远低于MC Dropout的 T 次完整前向传播。
3. 可解释性强：通过原子级别的贡献分析，可以追溯模型不确定性到表示空间的具体构建块。Figure 6的力可视化方法为理解模型行为提供了独特视角，这是SR、SE等标量方法无法提供的。
4. 在低精度/高不确定性场景中表现尤为优越：在 ANLI（全部9个模型-子集组合中获8个最优）和 Jigsaw（全部3个模型中获3个最优）上以显著优势超越所有基线方法。在GLUE的5个任务中4个取得最优。
5. 对超参数选择具有较好的鲁棒性：验证集与测试集性能一致性高，理论推荐值（lambda = 1.2 / sqrt(d)）即可获得接近最优的结果。
6. 代码开源，包含所有微调模型检查点和完整源代码，可复现性强。

### 局限性

论文明确指出的局限性：
1. 依赖超参数选择：SUE 需要设置字典原子数 K 和正则化系数 lambda。尽管消融实验表明性能对这些超参数不太敏感，且理论推荐值就能达到预期效果，但与其他方法相比确实引入了额外的调参维度。不过论文也指出，其他不确定性估计方法同样存在各自形式的超参数。

从实验结果可观察到的潜在局限：
2. 在简单/高精度任务上不一定占优：当模型精度已经很高（如ParaDetox上的97-98%准确率、SST-2上的93.46%）时，SUE 的性能可能不如MC Dropout变体（例如 MC-PV 在 ParaDetox BERT-Base 上为 0.27 vs SUE 0.46）。SUE的优势区间在于模型缺乏高精度时的高不确定性场景。
3. 校准集需求：非GLUE实验中使用了8,000样本作为校准集用于字典学习和PMI统计，在样本极度稀缺的场景下可能受到一定限制。不过对于GLUE的小样本任务（如MRPC仅163个开发样本），SUE仍然有效且表现优异。

## 对后续研究的启发或潜在改进方向

1. 扩展到生成式任务：论文聚焦于序列分类（使用[CLS] token表示），而稀疏表示和PMI框架理论上可以扩展到序列生成、token级别的置信度估计等任务，利用每个位置的隐藏状态构建更细粒度的不确定性估计。

2. 动态/在线字典学习：当前方法一次性在固定校准集上训练字典，能否设计在线或增量更新的字典学习机制以适应训练后出现的分布漂移（distribution shift）和新类型错误模式？

3. 与现有方法的融合：SUE 捕获的是基于稀疏表示的全局结构信息，而 Softmax Response 捕获局部概率信息，MD 捕获距离信息——三者可能存在互补性。能否设计混合不确定性估计器，通过加权或学习组合不同来源的信号？

4. 改进稀疏编码算法：当前使用经典的在线字典学习方法（Mairal et al., 2009），可以探索更高效的稀疏编码策略，如可微字典学习（将字典学习嵌入神经网络训练流程）、深度展开网络（deep unrolling）等，以进一步提升计算效率和表示质量。

5. 激活判定准则的精细化：当前方法在式（2）中使用简单的 alpha^{(n,k)} != 0 作为激活判定（硬阈值），可以探索连续值加权方案（如直接使用 alpha 值的大小）或基于统计分布的自适应阈值，可能获得更细粒度、更具区分力的 PMI 统计。

6. 多层级融合字典学习：当前仅使用最后一层Transformer的 [CLS] 嵌入，可以探索多层次（不同Transformer层）的稀疏表示融合，捕获不同抽象层级的不确定性信号。浅层可能反映词汇/句法不确定性，深层反映语义/推理不确定性。

7. 主动学习与人工审核：SUE 的 PMI 矩阵天然适合识别模型频繁出错的样本模式，可将其应用于不确定样本的自动发现、标注优先级排序，以及定向数据增强。论文在 ParaDetox 和 MRPC 上的分析已初步展示了这一方向的潜力。

8. 跨任务/跨领域字典迁移：字典原子是否能跨任务或跨领域迁移？如果可以，可以大幅减少或消除新任务对校准样本的需求，使 SUE 也能适用于零样本或少量标注的场景。

9. 理论分析：论文未提供 PMI 分数与 eAU-RCC（或其他风险度量）之间关系的理论保证。未来可以从理论层面分析稀疏编码不确定性估计的统计一致性、收敛性质和误差界。

10. 标注质量审核工具：论文中发现部分被 SUE 赋予高置信度的"误分类"样本实际上是标注错误（尤其在 MRPC 中，多对句子虽有细微rewording但被标注为等价），可以进一步开发基于 SUE 的自动标注质量审核和纠错工具。

11. 过拟合风险的形式化控制：论文通过经验消融实验观察了过拟合现象，建议使用理论 lambda 值和限制 K 来控制过拟合风险。未来可以探索更形式化的方法（如基于信息准则的模型选择、交叉验证自动选择 K）来系统性地平衡表示能力和泛化性能。
