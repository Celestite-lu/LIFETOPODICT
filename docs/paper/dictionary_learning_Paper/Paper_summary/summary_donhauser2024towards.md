## 二、研究动机与问题定义

### 2.1 背景痛点

近年来，稀疏字典学习（Sparse Dictionary Learning, DL）已成为从大型语言模型（LLM）内部表征中提取语义可解释概念的强大工具（如 SAE 相关工作）。然而，已有成功案例均依赖于某种形式的文本监督（如语言模型中的 next-token prediction 或 CLIP 中的图文对比学习），且应用领域本身是人类天然可以理解的（文本、游戏、自然图像）。一个核心问题由此产生：**在不具备强先验知识、完全无监督的科学数据领域，能否同样提取出有意义的高层特征？**

在计算生物学中，基于 Masked Autoencoder（MAE）在细胞显微图像上训练的模型已被证明能有效学习表征并恢复已知的生物学关系（Kraus et al., 2024）。然而，尚不清楚这些大规模 MAE 基础模型内部是否也编码了类似的高层可解释特征。此场景恰恰是高层特征提取最具价值的领域：模型能够检测人类专家难以察觉的细胞形态细微差异，若机械可解释性（mechanistic interpretability）技术能被应用于此，则有望揭示这些细微差异的产生机制。

### 2.2 具体问题

- 在细胞筛选实验（cell screening campaign）中，细胞接受基因敲除（CRISPR）或小分子干扰（siRNA）等扰动处理。理解这些扰动引发的细胞形态学变化是药物发现的关键基础问题。
- 现有方法（如计算 MAE 表征的余弦相似度构建扰动关系图谱）只能判断两个扰动是否相似或不同，但**无法解释它们为何相似/不同，以及以何种方式不同**——这相当于将高维表征中丰富的多维关系坍缩为一个单一标量分数，损失了大量信息。

### 2.3 本文核心研究问题

1. **稀疏特征提取**：如何从 MAE 中高效提取稀疏特征？
2. **特征语义性**：在无任何文本或标签监督的条件下，能否学到有生物学意义的概念？
3. **评估方法**：如何系统评估稀疏特征的生物学内容质量？

## 三、方法/框架

### 3.1 理论模型：叠加假设（Superposition Hypothesis）

论文基于 Bricken et al. (2023) 提出的叠加假设：
- Transformer 的 token 表示 x in R^d 是多个概念的线性组合；
- 可用概念数量 M 远大于表示维度 d；
- 每个 token 表示是少数概念的稀疏组合。

形式化模型为：

x 约等于 W z = sum_{m=1}^{M} z_m W_m,  其中 ||z||_0 << d

其中 W in R^{d x M} 为字典矩阵（dictionary matrix），z in R^M 为稀疏编码（sparse code）。论文称 W 的列 W_m 为特征方向（feature directions），z 为特征（features）。

### 3.2 基线方法：TopK SAE

TopK SAE（Makhzani & Frey, 2013; Gao et al., 2024）的模型定义为：

x_i = W_dec z_i + b_pre,   z_i = TopK(W_enc x_i - b_pre)

其中 TopK(.) 操作保留 K 个最大元素，其余置零。通过最小化重构损失训练：

L(W_dec, b_pre) = sum_{i=1}^{N} ||x_i - x_hat_i||_2^2

x_hat_i = W_dec TopK(W_enc x_i - b_pre) + b_pre

**核心缺陷**：TopK SAE 存在严重的死亡特征（dead features）问题——大量特征方向 W_dec,m 在训练中完全不被激活（z_im = 0 对几乎所有 i）。Gao et al. (2024) 引入针对死亡特征的辅助重构损失来缓解此问题，但效果有限。

### 3.3 ICFL（Iterative Codebook Feature Learning）算法

ICFL 是本文提出的核心算法创新，合成自经典的 Orthogonal Matching Pursuit（OMP, Mallat & Zhang, 1993）算法思想。

#### 3.3.1 Batched-OMP 计算特征 z（替代编码器）

ICFL 不使用可学习的编码器 W_enc，而是用 batched-OMP 直接从字典矩阵 W_dec 中贪婪选择特征方向。

**算法详细流程**（Algorithm 1）：

1. **输入**：当前特征方向矩阵 W_dec、偏置 b_pre、模型表示 x、每轮选取数 L、迭代轮数 J
2. **初始化**：残差 x^(1) := x - b_pre
3. **对 t = 1 到 J 执行**：
   - 选取与当前残差 x^(t) 内积最大的 top-L 列 W_dec,m
   - 求解最优稀疏系数（最小二乘）：z^(t) = argmin_z ||x^(t) - W_dec z||_2^2，其中 z 仅在所选 L 列上非零
   - 更新残差：x^(t+1) := x^(t) - W_dec z^(t)
4. **输出**：最终特征向量 z = sum_{t=1}^{J} z^(t)

最终 z 的最大稀疏度为 k = J x L。默认配置为 J = 20, L = 5，即最大稀疏度 k = 100。

**关键优势**：早期迭代步骤将主导特征方向从 x 中减去，使后续迭代可以选取与 x 中主要特征不太相关、更广泛多样的特征方向，从而避免死亡特征（dead features）。

#### 3.3.2 梯度下降学习特征方向

给定 batched-OMP 计算得到的特征 z，通过小批量梯度下降最小化重构损失来更新解码器参数 {W_dec, b_pre}：

L_ICFL(W_dec, b) = sum_i ||x_i - W_dec z_i - b_pre||_2^2

重要特点：z_i 在梯度更新步骤中被视为固定的，算法**不需要通过 z 反向传播梯度**来学习编码器——编码器就是 batched-OMP 本身。只要存在某个 x_i 与 W_dec,m 对齐，该特征方向就会收到梯度更新，这直接杜绝了死亡特征的产生。

#### 3.3.3 随机重置（Random Resets）防止特征坍缩

每 100 步 SGD 更新后，对所有余弦相似度超过 0.9 的 W_dec 列对，随机重新初始化其中一个列向量（从超球面上均匀随机采样）。该操作可视为投影梯度下降中投影步骤的廉价替代方案——以计算成本换取算法简洁性，在实践中效果良好。

#### 3.3.4 初始化与标准化

- W_dec 使用 PyTorch 线性变换默认初始化
- 通过减去未扰动（对照）样本的平均表示来中心化所有表示 x，使原点对应未扰动状态
- 在输入 ICFL 之前，将表示标准化为单位范数

### 3.4 PCA 白化预处理（弱监督）

由于字典学习最小化欧氏距离，学习的特征天然偏向于捕捉数据中解释方差最大的方向。在生物学应用中，这些主方向通常对应所有实验中共有的细胞周期等非特异性变化，**而非最有价值的扰动相关概念**。

**PCA 白化方案**：
- 使用未扰动/对照细胞（HUVEC）的图像表示数据集作为对照数据集
- 定义线性变换 T: X -> W(X - mu)，将对照细胞映射为零均值、单位协方差的分布，其中 W 为 PCA 矩阵
- 将该变换 T 同时在对照数据和扰动数据上执行，再进行归一化
- 效果：**有效放大了不同扰动表示之间的差异**，使字典学习更关注扰动特异性信号

### 3.5 总体流程

1. 从 MAE 的中间层提取 token 表示 x
2. 在对照数据集上计算 PCA 白化矩阵，对所有表示施加 T 变换
3. 减去对照均值中心化，单位范数归一化
4. 使用 ICFL（batched-OMP + 梯度下降）学习 W_dec 和稀疏特征 z
5. 对学习到的特征方向进行生物学可解释性分析（选择性分数、线性探测、token 级热力图）

## 四、实验设置

### 4.1 数据与基础模型

- **数据来源**：Cell Painting 显微图像数据集 RxRx1（Sypetkowski et al., 2023）和 RxRx3（Fay et al., 2023），包含多种细胞类型经 CRISPR 基因敲除和 siRNA 沉默处理后的图像
- **基础模型**：两个基于 MAE 的 Vision Transformer 模型
  - **MAE-L**：ViT-L/8 配置，约 330M 参数，token 维度 d=1024
  - **MAE-G**：ViT-G/8 配置，约 1.9B 参数，token 维度 d=1664
- **输入**：256 x 256 x 6 像素细胞图像裁剪，patch 大小 8 x 8
- **Token 提取**：从中间层提取，MAE-L 用第 16 层，MAE-G 用第 33 层（通过最大化原始嵌入在功能基因组任务上的线性探测性能来选择）。将每张裁剪的所有 patch token（不含 class token）聚合成单个 token。
- **默认配置**：使用残差流（residual stream）表示，应用 PCA 白化

### 4.2 训练配置

| 超参数 | 默认值 |
|--------|--------|
| 特征总数 M | 8192 |
| 稀疏度（ICFL） | J=20, L=5（最大稀疏度 100） |
| 稀疏度（TopK） | K=100 |
| 训练 token 数 | 40M |
| 批大小 | 8192 |
| 训练迭代数 | 300k |
| 学习率 | 5 x 10^{-5} |
| PCA 白化 | 默认启用 |
| 表示来源 | 残差流（默认） |

### 4.3 五类分类任务（线性探测评估基准）

| 任务编号 | 任务名称 | 类别数 | 样本数 | 原始表示 BTA |
|----------|----------|--------|--------|-------------|
| (1) | 细胞类型（Cell type） | 23 | 110,971 | 97.2% |
| (2) | 实验批次（Batch） | 272 | 80,000 | 87.8% |
| (3) | siRNA 扰动 | 1,138 | 81,224 | 51.6% |
| (4) | CRISPR 单基因敲除 | 5 | 79,555 | 94.6% |
| (5) | 功能基因组（Gene Groups） | 39 | 57,863 | 32.1% |

- 除任务 (1) 外的所有任务均使用 HUVEC 细胞
- 表示均为 well 级聚合（每 well 共 1,024 个 patch token，覆盖 36 个 256 x 256 非边缘裁剪区域）
- 使用逻辑回归训练线性探针，采用类平衡交叉熵损失
- 评价指标：Balanced Test Accuracy（BTA）

### 4.4 Baselines 与对比方法

- **TopK SAE**（Gao et al., 2024）：当前主流的稀疏自编码器方法
- **CellProfiler (CP)**（Carpenter et al., 2006）：由领域专家手工设计的 964 维特征集，广泛用于显微图像分析。为公平比较，将 CP 特征做阈值化处理（取 alpha 和 1-alpha 分位数），使其平均非零数量与 ICFL 相当（约 100 个）

### 4.5 评估指标

- **选择性分数（Selectivity Score）**：源自神经科学（Hubel & Wiesel, 1968），衡量特征对特定标签的单义性
  - **平均选择性（avg selectivity）**：P(feature active | label i) - P(feature active | other labels)
  - **最大选择性（max selectivity）**：从 other labels 中取激活概率的最大值而非平均值
- **线性探测准确率**：在重构表示 x_hat = W_dec z 上训练线性分类器
- **重构余弦相似度**：cosim(x, x_hat)，常用于衡量 SAE 的无监督重构质量
- **Pearson 相关系数**：ICFL 与 CellProfiler 选择性分数的相关性

## 五、核心结果与发现

### 5.1 死亡特征显著减少

ICFL 在抑制死亡特征方面远优于 TopK SAE：

| 方法 | 无 PCA 白化 | 有 PCA 白化 |
|------|-----------|-----------|
| ICFL | 55 | 341 |
| TopK | 7640 | 8026 |

表注：8192 个特征中，在最后 1000 个训练步中激活比例低于 10^{-5} 的特征数。

### 5.2 特征与生物学概念高度相关（选择性分析）

在五个分类任务上计算特征的平均选择性分数：

- **细胞类型（任务 1）**：73 个特征平均选择性 > 0.5，455 个 > 0.2——大量特征高度专一于特定细胞类型
- **批次效应（任务 2）**：11 个 > 0.5，77 个 > 0.2
- **siRNA 扰动（任务 3）**：0 个 > 0.5，141 个 > 0.2——虽无极高选择性特征，但仍有可观的定向特征
- **CRISPR 敲除（任务 4）**：0 个 > 0.5，2 个 > 0.2——5 类任务本身类别数少，区分度相对容易
- **功能基因组（任务 5）**：0 个 > 0.5，37 个 > 0.2——即使是最困难的任务，也有超过 100 个特征选择性达 0.1 以上

此外，特征方向的余弦相似度直方图显示：特定 siRNA 扰动对应的特征方向能够有效分离来自该扰动的表示（蓝色）与来自所有其他扰动的表示（橙色）。

### 5.3 与 CellProfiler 手工特征的对比

- ICFL 提取的特征几乎匹配了由领域专家手工设计的 CellProfiler 特征的选择性水平
- 在任务 (3) 子集上，ICFL 与 CP 的最大平均选择性分数呈现强相关性：**Pearson 相关系数 r = 0.71**
- 值得注意的是，CP 特征约在平均 300 个非零元素时达到选择性峰值，而 ICFL 仅用了约 100 个非零元素（约 1/3）就获得了可比的选择性——说明 ICFL 用更稀疏的表示捕捉了同等质量的生物学信号

### 5.4 线性探测信号保留

通过比较原始表示 x 与重构表示 x_hat = W_dec z 上的线性探测准确率（Figure 4A）：

- **简单概念**（细胞类型、批次、CRISPR 基准——任务 1/2/4）：几乎全部生物学信号被保留（ICFL 重构的准确率与原始表示相差无几）
- **困难任务**（siRNA 1138 类、功能基因组 39 类——任务 3/5）：大量线性信号被保留，但存在明显下降
- **PCA 白化的核心作用**（Figure 4B）：PCA 白化对线性探测准确率的提升效果远大于单纯增加非零元素数（sparsity）——无 PCA 白化时准确率大幅下降

### 5.5 ICFL vs TopK SAE 全面对比

- **重构质量**（Figure 4C / Figure 9）：ICFL 在同等稀疏度约束下的余弦重构相似度远高于 TopK SAE，且该趋势在所有稀疏度水平上持续存在
- **线性探测准确率**（Figure 4A/B）：两者在有 PCA 白化时表现相近（ICFL 略优），但无 PCA 白化时两者均显著下降
- **选择性分数**（Figure 8）：ICFL 特征始终取得比 TopK SAE 更高的选择性分数，尤其对于细胞类型任务，ICFL 几乎在所有细胞类型上都表现出高最大选择性；TopK 的选择性整体偏低
- **训练稳定性**：TopK SAE 结合 PCA 白化时训练很不稳定（重构质量波动大），而 ICFL 则表现稳定

### 5.6 Token 级可解释性分析

论文通过生成每个图像中 8 x 8 patch token 与特征方向的余弦相似度热力图，实现细粒度可解释性。

#### 5.6.1 通道特异性扰动信号（Section 7.1, Figure 5）

对三个特定单基因扰动进行详细分析：

- **OPA-1（线粒体形态维持）**：最相关的 token 覆盖在含有肿大线粒体的远端区域，token 热力图与线粒体通道高度相关，确认该方法可捕获通道级的精细形态差异
- **ALG-3（内质网蛋白修饰）**：最对齐的 token 特定分布于内质网（ER）和 RNA 通道，与 ALG-3 在蛋白质糖基化修饰中的已知功能一致
- **TSC-2（细胞大小控制）**：质膜/高尔基体通道呈现负相关——最对齐的 token 聚焦于不被细胞膜覆盖的空区域，提示该扰动下显著特征可能是每个 well 中细胞密度的缺失
- **反向聚焦现象**（PLK-1, TMED-2）：类似地，某些扰动下最对齐的 token 反而对应无细胞区域（所有通道高度负相关），说明对某些基因扰动而言，细胞缺失的特定特征比细胞的视觉特征本身更显著

#### 5.6.2 单细胞级精度分析：黏附连接通路（Section 7.2, Figure 6）

聚焦于与黏附连接（adherens junctions）基因敲除强相关的一个特征方向：

- **生物学背景**：黏附连接蛋白（如 cadherin/catenin 复合物）是细胞间的胶水，负责连接细胞膜到细胞骨架的 actin 纤维，维持组织完整性
- **扰动表型**：CRISPR 敲除后细胞小而圆、明亮且彼此孤立（无法形成细胞间连接），但基因敲除不完美——部分逃逸细胞仍呈大而扁平的对照样态
- **热力图关键发现**：
  - Token 热力图成功在同一图像中区分两种细胞亚群：对照样细胞对应暗区域（token 与特征方向不对齐），正确受扰动细胞对应亮区域
  - 亮区域呈环状围绕受扰动的小圆细胞周边——暗示概念方向捕捉到的是**预期存在但因基因敲除而缺失的 actin 细胞骨架**
- **定量验证（Table 3）**：
  - 5 张图像共 124 个细胞（93 个受扰动 + 31 个对照样），由领域专家手动标注
  - Token 热力图正确将 27/31（87.1%）对照样细胞定位为暗区域
  - 所有 93 个受扰动细胞均被正确标记为亮（100% 召回）
- **像素级分割统计验证（Figure 6E）**：
  - 生成三类分割掩膜（背景、受扰动细胞、未受影响细胞）
  - Mann-Whitney U 检验确认对照样 vs 受扰动单细胞的 token 对齐分数存在统计学显著差异（p < 0.0001）
  - 背景区域与受扰动细胞的分布无显著差异（ns）——典型对照图像的背景暴露是黏附连接表型的重要特征

### 5.7 消融实验（Appendix C）

- **注意力输出 vs 残差流**（Table 4 / Figure 17/18）：两者在线性探测准确率和选择性分数上表现相似。例外是 TopK SAE 在细胞类型任务上，注意力输出的选择性分数显著更好，但仍远低于 ICFL
- **模型大小**（Figure 17/19）：MAE-G（1.9B）在复杂任务 (3)(5) 上比 MAE-L（330M）有持续改善——字典学习受益于模型规模扩展。但 TopK SAE 在大模型上的选择性分数反而显著下降，提示 TopK 从更丰富（经 PCA 白化后处理）的表示中提取可解释高选择性特征的能力不足
- **稀疏度**（Figure 9）：ICFL 在所有稀疏度水平上的重构余弦相似度均优于 TopK SAE
- **学习率**（Figure 9）：影响有限（在 5 x 10^{-5} 后趋于平稳）；TopK SAE + PCA 白化组合对学习率高度敏感且训练不稳定

### 5.8 附录发现：行空间与零空间分析（Appendix A, Figure 7）

- MAE 架构中，编码器 (d_e=1664) 通过投影矩阵 W (1664 -> 512) 连接解码器 (d_d=512)
- Token 可分解为 x = x_row + x_null：仅行空间分量 x_row 传递到解码器用于图像重构
- 组件级线性探测表明：**零空间分量（不传递给解码器的部分）**始终产生与完整 token 几乎相同的探测准确率；行空间分量的探测准确率显著较低，甚至低于随机 512 维子空间
- 这一发现支持假设：生物学概念主要存储在用于内部处理（而非生成图像重构）的零空间中，为线性方向假设在 ViT MAE 中的有效性提供了新的证据

## 六、主要贡献与局限性

### 6.1 主要贡献

1. **首次将字典学习应用于无监督科学数据领域**：证明了从完全无文本监督的显微图像 MAE 基础模型中可提取与细胞类型、遗传扰动等生物学概念强相关的稀疏特征，为 AI 驱动的科学发现提供了具体可行的新方向
2. **提出 ICFL 算法**：一种基于 batched 正交匹配追踪（batched-OMP）的字典学习新算法，使用贪婪选择替代可学习编码器，天然避免死亡特征问题；融合随机重置机制（每 100 步，余弦相似度 > 0.9 时重置）防止特征坍缩
3. **引入 PCA 白化弱监督范式**：利用对照数据集的 PCA 白化作为一种弱监督方式，有效抑制普遍存在于所有实验中的背景生物学变异（如细胞周期），使字典学习聚焦于扰动特异性信号——简单但效果显著的预处理策略
4. **建立系统的生物学评估框架**：精心策划了五类线性探测任务（覆盖从容易到困难的不同难度层次），并将 ICFL 特征与领域专家设计的 CellProfiler 手工特征进行系统性比较
5. **Token 级可解释性方法论**：展示了如何通过 token 热力图在单细胞精度层面解释模型学到的高层概念，为生物学假设生成（hypothesis generation）提供可操作的工具——包括通道特异性分析和单细胞亚群区分

### 6.2 局限性

1. **细微变化检测存在性能瓶颈**：在处理需要区分细胞形态更细微变化的任务（如 1138 类 siRNA 扰动或 39 类功能基因组）时，线性探测性能显著下降。尚不清楚这一限制的根本原因来自当前 DL 技术本身、模型规模不足、还是这些细微变化根本不以线性方式存储在嵌入空间中
2. **解释流程依赖领域专家**：特征的可解释性分析高度依赖生物学领域专家的人工判断和手工标注，缺乏全自动、可量化的解释验证流程，难以规模化
3. **仅探索了单个编码器层的线性概念**：对更深层的非线性概念结构、跨层概念交互尚未探索
4. **CellProfiler 对比的局限性**：CP 特征峰值选择性出现在约 300 个非零元素时，而 ICFL 仅使用约 100 个——是否可通过调整 ICFL 的稀疏度（如增大 J 或 L）来匹配或超越 CP 峰值尚未评估
5. **仅基于相关性分析，缺乏因果性验证**：当前特征与生物学概念的关联仅限于相关性（选择性分数、线性探测），未通过因果干预（如特征方向上的 patching/ablating）验证特征方向在模型推理中是否具有因果作用

## 七、对后续研究的启发或潜在改进方向

1. **将 ICFL 拓展至其他模态和数据域**：ICFL 并非专用于显微图像——可尝试在文本、音频、视频等其他模态的预训练模型中应用 ICFL 提取稀疏可解释特征，验证其跨域泛化能力
2. **探索非线性字典学习或分层概念结构**：当前线性探测在复杂任务上的性能下降可能源于线性假设的不足——未来的工作可探索非线性字典学习、多层特征联合提取、或层次化概念分解
3. **将字典学习与因果干预结合**：借鉴 LLM 领域中的因果干预方法（如 activation patching、feature ablation），验证学到特征方向的因果效应而非仅依赖相关性分析，从而区分真正被模型使用的概念与仅是相关信号的概念
4. **自动化概念标注与验证流程**：将人工解读流程部分自动化（例如使用视觉语言模型辅助生成候选特征的概念描述），提高解释的规模和一致性，减少对领域专家的依赖
5. **扩大模型和数据规模**：MAE-G（1.9B）已在复杂任务上展现优于 MAE-L（330M）的趋势——更大规模模型（如 ViT-22B 级别）可能编码更丰富、更细微的生物学概念，同时需要更强的字典学习方法以匹配模型能力
6. **多层级、多位置的特征提取**：当前仅从单一中间层提取——未来可对多个编码器层同时进行字典学习，捕捉从低层纹理到高层语义的不同抽象层次的概念层级结构
7. **从 Well 级到单细胞级：迈向精细生物学发现**：Token 热力图分析已展示了在无监督条件下区分单细胞亚群的可能性（87.1% 召回率）——若进一步改进可靠性，有望实现前所未有的生物学发现精度，如自动识别新细胞状态、发现未知的扰动特异性亚表型
8. **多模态数据融合字典学习**：将细胞显微图像特征与转录组学（RNA-seq）、蛋白质组学等多模态生物数据联合进行字典学习，建立更全面的跨模态生物学概念表征，更深入理解基因型-表型关联
9. **向端到端科学发现演进**：当前工作聚焦于从已有表征中提取概念——未来可探索将字典学习直接集成到 MAE 训练过程中（联合训练），使模型在预训练阶段就自然地学习稀疏、可解释的概念表示，真正实现通过可解释性进行科学发现的闭环
