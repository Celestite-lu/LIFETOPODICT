## 研究动机与问题定义

深度神经网络通过在表示空间中捕获潜在特征或概念来实现卓越性能。领域内的一个根本性挑战是：**能否通过外部智能体（如大语言模型 LLM 或人类）的反馈，高效地检索出模型所学的底层特征？**

该论文研究以下核心问题：给定一个目标字典矩阵 D（其列向量为原子特征向量，对应如"tree"、"house"、"lawn"等语义概念），以及一个通过相对三元组比较提供反馈的智能体（agent），一个"无知学习者"（oblivious learner，即仅满足反馈约束并从中随机选取有效特征矩阵的学习者）需要多少轮交互（即**反馈复杂度**，feedback complexity）才能学习到该字典的特征矩阵（即 D 的正规变换 D D^T，等价于协方差矩阵或马氏距离矩阵）？

具体协议如下：
- 智能体构造或选取稀疏激活三元组 (alpha, beta, zeta) in R^{3p}，并设计相对相似性反馈 l in {+1, 0, -1}，满足 sgn(||D(alpha-beta)|| - ||D(alpha-zeta)||) = l。
- 学习者求解满足所有三元组约束的特征矩阵 hat{D}，输出 hat{D}^T hat{D}。

该研究的设定与传统字典学习的关键区别在于：**学习者不能直接接触真实样本**（如图像、文本），只能通过激活向量上的相对距离反馈来推断特征矩阵。这与 LLM 机制可解释性中的**线性表示假设**（Linear Representation Hypothesis, LRH）和**叠加**（superposition）现象密切相关：模型学到的特征被假设为以稀疏激活的方式线性编码在潜在表示空间中（x approx D dot alpha + epsilon）。

## 方法/框架

### 3.1 问题形式化

- **表示空间**（激活空间）：V subset R^p
- **样本空间**：X subset R^d
- **特征矩阵族**：M_F = {Phi in Sym_+(R^{p x p})}，即所有 p x p 对称半正定（PSD）矩阵的集合。
- **反馈集 F**：由三元组 (x, y, z) in V^3 及对应符号 l in {+1, 0, -1} 组成。

**Definition 1（s-稀疏激活）**：激活 alpha in R^p 是 s-稀疏的，当且仅当其非零分量的数量不超过 s。

**Definition 2（特征等价性）**：两个特征矩阵 Phi' 和 Phi* 等价，当且仅当存在 lambda > 0 使得 Phi' = lambda dot Phi*（因为三元组比较对 Phi 的正缩放具有不变性）。

**Definition 3（无知学习者）**：学习者从给定反馈集 F 的所有有效解中随机选取一个特征矩阵。

### 3.2 从三元组到成对比较的归约（Lemma 2）

论文证明了一个关键归约：任何三元组反馈集可以转化为成对等式约束反馈集。对于每个三元组 (x, y, z)：
- 若等式成立，直接得到成对约束 (x-y, x-z)。
- 若严格不等式成立（(x-y)^T Phi* (x-y) > (x-z)^T Phi* (x-z)），则存在 lambda > 0 使得 (x-y)^T Phi* (x-y) = (1+lambda)(x-z)^T Phi* (x-z)，从而成对约束 (x-y, sqrt(1+lambda)(x-z)) 满足等式。

这使得学习问题转化为求解 Phi 满足所有成对等式约束：
```
y^T Phi y = z^T Phi z  <==>  <Phi, yy^T - zz^T> = 0
```
**几何解释**：任何解 Phi 必须湮灭由反馈集中矩阵 {yy^T - zz^T} 张成的子空间，该子空间属于 Phi* 的正交补空间：
```
O_{Phi*} := {S in Sym(R^{p x p}) | <Phi*, S> = 0}
```

### 3.3 四种反馈设定与核心理论结果

论文在四种设定下严格分析了反馈复杂度，结果汇总如下表：

| 反馈类型 | 通用构造性 | 稀疏构造性 | 通用采样 | 稀疏采样 |
|---------|-----------|-----------|---------|---------|
| 反馈复杂度 | Theta(r(r+1)/2 + p - r) | O(p(p+1)/2) | *Theta(p(p+1)/2) | dagger O(p^2(2/p_s^2 log(2/delta))^(1/p^2)) |

注：*表示"几乎必然"(almost surely)保证，dagger表示"以高概率"(with high probability)保证。c > 0 为常数，p_s 取决于激活分布和稀疏度 s。

---
#### (1) 通用构造性反馈（General Constructive Feedback）

**设定**：智能体可以从 R^p 中任意选取/构造激活向量，研究激活向量的最佳信息量。

**Proposition 1（最坏情况下界）**：在通用构造性设定下，M_F 类的最坏情况反馈复杂度至少为 p(p+1)/2 - 1（即 Omega(p^2)）。对满秩 Phi*，反馈集必须张成 O_{Phi*} 的全维度。

**Theorem 1（通用激活）**：设目标特征矩阵 Phi* 的秩为 r = rank(Phi*)。在通用构造性反馈设定下，反馈复杂度具有**紧界**：

```
Theta(r(r+1)/2 + (p - r) - 1)
```

等价于（在 Theta 意义下）Theta(r(r+1)/2 + p - r)。

**证明策略**——双管齐下的教授方法：

1. **教授核空间（Kernel）**：对 Phi* 做特征分解 Phi* = sum_{i=1}^r lambda_i u_i u_i^T（lambda_i > 0，{u_i} 为标准正交特征向量）。
   - **Lemma 3**：对正交向量集 {v_i}_{i=1}^r，秩-1矩阵集合 B = {v_i v_i^T, (v_i+v_j)(v_i+v_j)^T | 1 <= i < j <= r} 在 Sym(R^{p x p}) 中线性无关。
   - 智能体提供形如 (v_i, sqrt(c_i) y) 的成对反馈（其中 y 满足 Phi* y != 0，c_i 满足 v_i^T Phi* v_i = c_i dot y^T Phi* y）。具体来说，通过 Lemma 9 构造反馈集 O_B，大小为 r(r+1)/2 - 1。
   - 该反馈集确保在 Sym(R^{p x p}) 中张成一个 r(r+1)/2 - 1 维的子空间，强制任何解 Phi' 在核空间方向上的正确性。

2. **教授零空间（Null Space）**：对零空间的正交扩展 {u_i}_{i=r+1}^p（满足 Phi* u_i = 0），提供反馈对 (0, u_i)。
   - **Lemma 6**：若提供 F_null = {(0, v_i)}_{i=r+1}^p，则任何满足 Eq. (2) 的 PSD 解 Phi' 的零空间必包含 {v_{r+1}, ..., v_p}。
   - 共需 (p-r) 个反馈。

**Lemma 1（正交表示的恢复）**：若 Phi 具有正交 Cholesky 分解（即字典 L 的行正交），则可从 Phi 恢复 L 到正交变换和符号变化（分块对角正交矩阵 R，对应不同特征值各块；重数为 1 的特征值仅允许 +/-1 符号变化）。

---
#### (2) 稀疏构造性反馈（Sparse Constructive Feedback）

**设定**：激活向量限制为 s-稀疏（如 s=2）。

**Theorem 2（稀疏激活）**：若智能体能构造来自 R^p 的激活对，则使用 2-稀疏激活时，反馈复杂度上界为：

```
O(p(p+1)/2)
```

**关键构造**：利用以下 2-稀疏激活向量集合（来自标准基 {e_i}）：
```
B = {e_i | 1 <= i <= p} union {e_i + e_j | 1 <= i < j <= p}
```
大小恰好为 p + p(p-1)/2 = p(p+1)/2。

对应的秩-1矩阵集合 B_sparse = {uu^T | u in B} 在 Sym(R^{p x p}) 中线性无关且构成一组**基**。每个激活向量至多为 2-稀疏。

**重要注释（Remark）**：虽然 Theorem 1 的下界在此适用，但稀疏设置可能需**更多**反馈。考虑秩-1矩阵 Phi* = vv^T，其中 sparsity(v) = p。由鸽巢原理，使用 s-稀疏激活表示它至少需 (p/s)^2 个秩-1矩阵。当 sparsity s = O(1) 为常数时，需 Omega(p^2) 反馈——稀疏表示稠密特征可能**无法利用低秩结构**来减少反馈量。

---

#### (3) 通用采样反馈（General Sampled Feedback）

**设定**：更实际的场景——智能体从连续分布 D_V 中接收 i.i.d. 采样的激活向量 {alpha_1, ..., alpha_n} ~ D_V，由于独立采样中直接找到满足等式约束的对的概率为零（Sard 定理），需要**重缩放**技术。

**重缩放对**：对于任意两个采样激活 x, y ~ D_V，几乎必然有 Phi*x != 0。假设 x^T Phi* x > y^T Phi* y，存在 lambda > 0 使得：
```
x^T Phi* x = (1+lambda) y^T Phi* y = (sqrt(1+lambda)y)^T Phi* (sqrt(1+lambda)y)
```
由此构造有效成对反馈 (x, sqrt(1+lambda)y)。

**Algorithm 2**：带重缩放的采样表示特征学习。智能体接收 V_n ~ D_V，构造：
```
F(V_n, Phi*) = {(x, sqrt(lambda_x) y) | x^T Phi* x = lambda_x dot y^T Phi* y}
```

**Theorem 3（通用采样激活）**：假设激活从 Lebesgue 分布 D_V 中 i.i.d. 采样。对任意目标特征矩阵 Phi*，反馈复杂度具有**紧界**（几乎必然成立）：

```
Theta(p(p+1)/2)
```

**证明概要**：设计矩阵 M = [vec(v_1 v_1^T) ... vec(v_P v_P^T)]，其中 vec(.) 是对称矩阵的向量化。det(M) 是激活条目的非零多项式，由 Sard 定理知其零点集具有 Lebesgue 测度零。因此 P = p(p+1)/2 个随机采样的秩-1矩阵几乎必然线性无关。构建的反馈集 {v v^T - gamma_i v_i v_i^T}（其中 gamma_i 由重缩放确定）几乎必然有效。下界基于 Lemma 10 的必要性论证。

---
#### (4) 稀疏采样反馈（Sparse Sampled Feedback）

**设定**：激活向量从稀疏分布中采样。

**Assumption 1（稀疏分布）**：激活向量 alpha in R^p 的每个分量独立采样：
```
P(alpha_i = 0) = p_i,    alpha_i | alpha_i != 0 ~ Lebesgue((0,1])
```

**Theorem 4（稀疏采样激活）**：固定阈值 delta > 0 和稀疏度参数 s < p。对任意目标特征矩阵 Phi*，使用 s-稀疏反馈的反馈复杂度上界为（以概率 >= 1-delta 成立）：

```
n = O(p^2 dot (2/p_s^2 dot log(2/delta))^(1/p^2))
```

其中 p_s 取决于 D_V 和稀疏度参数 s。具体计算为：
- P_1（单非零分量概率）：sum_{i=0}^{s-1} C(p-1, i) dot p_nz^{i+1} dot (1-p_nz)^{p-1-i}
- P_2（双非零分量概率）：sum_{i=0}^{s-2} C(p-2, i) dot p_nz^{i+2} dot (1-p_nz)^{p-2-i}
- p_s >= P! dot P_1^p dot P_2^{P-p}（其中 P = p(p+1)/2）

**证明思路**：推广 Theorem 2 的构造到一般标量，定义广义基向量集合：
```
U_g = {lambda_i e_i : lambda_i != 0} union {(lambda_{iji} e_i + lambda_{ijj} e_j) : lambda_{iji}, lambda_{ijj} != 0, i < j}
```
其对应的秩-1矩阵集在 Sym(R^{p x p}) 中线性无关。定义事件 R（采样到满足 U_g 模式的 P 个激活），计算其概率 p_s，应用 Hoeffding 不等式和 Sterling 近似得到所需采样数 N。

### 3.6 学习优化算法（Algorithm 3：梯度下降优化）

针对高维特征矩阵（如 5000 x 5000，约束数量达 p(p+1)/2 approx 12.5M），论文将约束满足问题重新公式化为矩阵回归任务：

**损失函数**：
```
L(U) = L_MSE(U) + L_reg(U)
L_MSE(U) = (1/|B|) sum_{i in B} (||U dot u_i||^2 - c_i dot ||U dot y||^2)^2
L_reg(U) = lambda dot ||U||_F^2,  lambda = 10^{-4}
```

**训练细节**：
- 学习者维护 Phi = U U^T 的低秩分解（U in R^{p x r}）。
- 对每个 batch，构造稀疏向量 u_i，计算投影 U^T u_i 和 U^T y（y = e_1），计算残差 r_i = ||U^T u_i||^2 - c_i dot ||U^T y||^2。
- 使用 Adam 优化器，带梯度裁剪。
- 每步更新后强制 U[0,0] = 1（处理尺度不变性）。

**内存优化**：强制常稀疏度约束（最大稀疏度 3），实现高效的大维度数组存储。

## 实验设置

### 数据集与模型

**1. 合成任务——Recursive Feature Machines (RFM) 特征**：
- RFM (Radhakrishnan et al., 2024) 训练一个可训练核 K_Phi，每轮迭代 t 更新 Phi_{t+1} = sum_{z in D_train} (partial f_{Phi_t} / partial z)(partial f_{Phi_t} / partial z)^T。
- **Fig. 1 配置**：目标函数 f*(z) = z_0 dot z_1 dot 1(z_5 > 0)，输入 z ~ N(0, 0.5 I_10)，4000 训练样本，RFM 迭代 5 次，生成 Phi*（秩 r = 4，p = 10）。
- **Appendix C.1 配置**：目标函数 f*(x) = x_1 dot x_2 dot x_3 dot x_4 dot 1(x_5 > 0)，输入 x ~ N(0, 0.5 I_10)，5000 训练样本，生成 Phi*（秩 r = 8, p = 10, p(p+1)/2 = 55）。

**2. 大规模语言模型——SAE 字典特征**：
- **Board Game Models** (Karvonen et al., 2024)：ChessGPT 和 OthelloGPT 的 MLP 层，SAE 字典维度 4096 x 512，p(p+1)/2 approx 8.3M（论文以输入维度 4096 计算复杂度）。
- **Pythia-70M** (Biderman et al., 2023)：通用 LLM 的注意力输出层，SAE 字典维度 32768 x 512，p(p+1)/2 approx 512M（论文以此维度计算），字典秩 rank = 215。大规模实验中采用 3-稀疏均匀分布。

### 四种反馈方法与评估

| 方法 | 描述 | 理论依据 |
|------|------|---------|
| 特征分解（Eigendecomposition） | 利用 Phi* 的低秩结构和 Lemma 3 构造反馈 | Theorem 1 |
| 稀疏构造（Sparse Constructive） | 使用 Eq. (4) 的 2-稀疏标准基向量 | Theorem 2 |
| 随机采样（Random Sampling） | 从 Lebesgue 分布采样激活并重缩放 | Theorem 3 |
| 稀疏采样（Sparse Sampling） | 从稀疏分布中采样 s-稀疏激活并重缩放 | Theorem 4 |

**评估指标**：
- **MSE**（均方误差）：学习矩阵与目标 Phi* 之间的逐元素均方误差。
- **PCC（Pearson Correlation Coefficient）**：
  ```
  rho(Phi', Phi*) = sum_{i,j}(Phi'_{ij} - mean(Phi'))(Phi*_{ij} - mean(Phi*))
                    / (sqrt(sum(Phi'_{ij} - mean(Phi'))^2) dot sqrt(sum(Phi*_{ij} - mean(Phi*))^2))
  ```
  最大值为 1。

**实现工具**：低维问题用 cvxpy 求解约束；高维问题用 Algorithm 3 的批量梯度下降矩阵回归（低秩分解 Phi = UU^T）。稀疏采样的大规模实验使用 3-稀疏度。

## 核心结果与发现

### 5.1 合成任务（RFM 特征矩阵，p=10）

**Fig. 1（r=4, 目标函数 f*(z) = z_0 dot z_1 dot 1(z_5 > 0)）**：
- 特征分解、稀疏构造和随机采样均在仅 **55 个反馈**（= p(p+1)/2 = 总自由度）内达到 ground-truth MSE（0.0016）。
- 高稀疏度采样（mu=0.9，非零概率仅 10%）在 55 反馈下 MSE=5.636，质量严重劣化。
- 低稀疏度采样（mu=0.1，非零概率 90%）在 55 反馈下 MSE=0.00156753，接近 ground-truth。
- 即使高稀疏度（mu=0.9、0.97），随反馈数增加（55->110->275->440->1100），近似也逐渐改善。

**Fig. 2（目标 f*(z) = z_0 dot z_1 dot z_3 dot 1(z_5 > 0)）**：
- 稀疏采样中 mu=0.97（极高稀疏度）时需更多反馈（110、275、440、1100）才获得良好近似。
- mu 越低（越不稀疏），越少的反馈即能达到 ground-truth 质量。

**Appendix C.1（r=8，验证理论界）**：
- **特征分解**：理论界 r(r+1)/2 + p - r = **38**，恰在该反馈数下达目标 MSE。
- **稀疏构造**：理论界 **55**，MSE 在该界内饱和。
- **随机采样**：在理论界 55 的 20%-100% 处评估，MSE 随反馈增加逐步降低。
- **稀疏采样**（4-稀疏，mu=0.8，delta=0.05）：Theorem 4 理论界为 **117**。反馈量达到该阈值时 MSE 收敛到目标值。多组 mu、delta、sparsity 实验（Fig. 7-11）验证理论界的一致性。注意：界独立于非零分量的具体分布，因此即使换用非均匀分布，界也不变。

### 5.3 关键结论

1. **表达力-可恢复性权衡**：恢复网络层特征字典至少需要关于环境维度 p 的**二次样本复杂度**（O(p^2)），适用于标准 i.i.d. 学习、主动学习和机器教学等各类设定。字典越复杂或维度越高，所需交互数据越多。

2. **低秩结构可大幅降低复杂度**：当特征矩阵具有低秩性质时，反馈复杂度可从 O(p^2) 大幅降至 Theta(r^2 + p)。此结论与 Neural Feature Ansatz (Radhakrishnan et al., 2024) 互补——当任务相关方向位于低维子空间中，所需反馈显著减少。

3. **稀疏性未必有利**：稀疏表示稠密特征可能反而需要更多反馈（Theorem 2 Remark），不能简单地利用低秩结构优势——这是稀疏性与低秩性之间的基本权衡。

4. **构造性 vs 采样性反馈**：构造性反馈（Theorem 1-2）提供更紧的上界（特别是低秩情形），但实践中通常不现实；采样性反馈（Theorem 3-4）更符合实际情况，但需要更多样本。

## 主要贡献

1. **构造性设定的反馈复杂度紧界**：证明了通用激活下的 Theta(r(r+1)/2 + p - r) 和下界 Omega(p^2)（最坏情况），以及稀疏激活下的 O(p(p+1)/2)。

2. **分布性设定的反馈复杂度界**：一般采样的 Theta(p(p+1)/2)（几乎必然）和稀疏采样的 O(p^2 (2/p_s^2 dot log(2/delta))^(1/p^2))（高概率）。首次将稀疏 Lebesgue 测度概念扩展到稀疏采样情形。

3. **低秩结构利用策略**：提出"特征分解 + 零空间分离"的双管齐下教授策略，通过 Lemma 3 的线性无关秩-1矩阵集合和 Lemma 2 的归约技术，系统性地降低低秩矩阵的学习复杂度。

4. **大规模实验验证**：在 RFM 特征矩阵、ChessGPT 和 Pythia-70M 的 SAE 字典上验证了理论界。稀疏构造在 ChessGPT 上以 840 万反馈达到 PCC=0.9773，特征分解以 13.5 万反馈达到 PCC=0.9427。

5. **与已有方法的系统对比**：通过反馈复杂度比较表（Table 1），将本工作与 SAE、CRAFT、线性探针（LR/LDA）、CCS 等方法进行系统对比。

## 局限性

1. **仅恢复到正规变换**：学习者只能学到特征等价（正缩放），除非在强正交性假设（Lemma 1：字典行正交）下才可恢复到正交变换和符号变化。完整字典恢复仍是开放问题。

2. **精确等价而非近似**：理论界基于精确特征等价（Definition 2）。实际场景中，epsilon-近似的 Frobenius 范数恢复更为实际，但对应分析仍是开放问题。

3. **理论界与实用需求的差距**：尽管推导的界可直接转化为经典统计学习设置，但界与实用样本需求之间可能存在较大差距，能否利用本文发展的结构洞察收紧这一差距尚待研究。

4. **构造性反馈假设的局限性**：Theorem 1 和 Theorem 2 假设智能体能任意选取激活向量——实践中通常不可行，实际智能体只能从观测样本中选取。

5. **稀疏采样界可能较宽松**：Theorem 4 的界独立于非零分量的具体分布参数（由 Remark 知不依赖均匀分布假设），在某些设置下可能不够紧致。

## 对后续研究的启发与潜在改进方向

1. **epsilon-近似恢复理论**：建立基于 Frobenius 范数的近似特征等价理论，定量刻画反馈复杂度与近似精度 epsilon 之间的关系，弥合精确等价和实际近似之间的鸿沟。

2. **收紧稀疏采样界**：利用更精细的概率分析方法（如更紧的集中不等式或基于矩阵结构的组合论证）收紧 Theorem 4 的界，缩小理论与实践的定量差距。

3. **完整字典恢复**：在不需要 Lemma 1 强正交性假设的前提下，研究完整字典 L（而非仅特征矩阵 Phi = L^T L）的恢复条件，可结合真实样本信息（如 x = L alpha 对于某个 alpha）进行联合推断。

4. **主动学习与机器教学结合**：将当前框架与主动学习策略结合，由学习者主动选择信息量最大的查询而非仅被动接收智能体单向反馈，提升交互效率。

5. **噪声容忍学习**：研究智能体反馈存在噪声（如人类标注误差或 LLM 三元组判断不一致）时的鲁棒学习理论与复杂度界，这直接关系到人机协同和 LLM-as-judge 场景的实用性。

6. **模型蒸馏应用**：基于低秩结构洞察（Theorem 1），发展利用大型模型特征字典进行小模型蒸馏的实用方法——当存在低秩结构时，小模型（student）可高效继承大模型（teacher）的特征表示。

7. **多模态扩展**：将反馈学习框架扩展至视觉-语言等多模态场景，研究跨模态特征字典的共享、对齐与转移机制。

8. **与机制可解释性深度融合**：将反馈复杂度分析应用于量化研究 LLM 中的叠加（superposition）现象——在给定维度 d 下，要从 p 个叠加特征中恢复单个可解释特征需要的最小反馈量是多少？这为理解神经网络表示能力的理论极限提供新视角。
