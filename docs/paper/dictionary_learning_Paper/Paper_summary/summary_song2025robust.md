## 研究动机与问题定义

### 核心痛点

字典学习（Dictionary Learning, DL）作为一种强大的表示学习方法，被广泛用于处理高维非线性数据（如图像分类、场景识别、人脸识别、异常检测等），但现有方法存在以下关键不足：

1. **图结构信息利用不充分**：尽管已有一系列方法通过添加图正则化项（如 graph Laplacian regularization）或在深层进行图信号分解来引入图结构，但这些策略对字典更新过程仅提供辅助性的"边缘支持"（marginal support），并未将图信息深度嵌入字典学习的核心流程（稀疏编码和字典原子更新）中。图信息始终是辅助组件，而非优化过程的中心驱动力。

2. **局部结构细节捕捉能力弱**：由于字典更新过程未充分利用图的局部信息，学到的字典难以有效捕获数据中的局部细节特征（local details），对分类性能产生负面影响。

3. **图结构与字典之间的静态不匹配**：传统方法中的图约束在训练过程中保持静态，而数据分布和特征随迭代不断演化，导致图结构无法适应更新后的字典和稀疏系数。

### 要解决的问题

如何在字典学习的核心更新过程中充分利用图结构的局部邻域信息（特别是自表达关系，self-expression relationships），使学到的字典能够有效捕捉局部结构特征，同时实现图结构与字典原子的动态协同优化，从而提升图像分类性能。

## 方法/框架：DNADL（Deep Neighbor Atom-enhanced Dictionary Learning）

DNADL 整体架构是一个多阶段闭环网络模型，包含三个核心模块：**邻域流形学习模块**（Neighborhood Manifold Learning Module）、**原子增强字典学习模块**（Atom-enhanced Dictionary Learning Module）和**自适应图学习模块**（Adaptive Graph Learning Module）。三者构成闭环协同优化：邻域流形模块提取自表达关系并生成权重矩阵，指导原子增强字典学习；字典学习模块产生稀疏编码，为自适应图学习模块提供优化信号；更新后的图拓扑再被重新注入字典学习循环。最终由深度增强字典网络生成的稀疏表示 X 被用于训练 SVM 分类器完成分类任务。

### 3.1 邻域流形学习模块（Neighborhood Manifold Learning Module）

**Step 1：构建邻接矩阵 A**

基于预处理后的输入图像，使用高斯核函数计算样本点之间的相似度度量：

```
A_{ij} = exp(-||y_i - y_j||_2^2 / (2 * sigma^2))   (1)
```

其中 sigma 为带宽参数，决定相似度度量的敏感度：sigma 越小，相似度随距离衰减越快，仅强调最近邻；sigma 越大，则允许更广泛的邻域影响。

**Step 2：构建图拉普拉斯矩阵 L**

计算度矩阵 Z（对角线元素 Z_{ii} = sum_j A_{ij}），然后计算拉普拉斯矩阵：L = Z - A。该拉普拉斯矩阵是后续邻域划分和字典原子加权更新的核心。

**Step 3：谱聚类划分邻域流形**

- 对拉普拉斯矩阵 L 进行特征值分解，得到特征值集合 {l_1, l_2, ..., l_n}
- 计算特征值间隙 Delta = l_n - l_{n-1}，选择最大 Delta 对应的 k 值作为最优聚类数
- 选取前 k 个最小非零特征值对应的特征向量构建低维嵌入矩阵 U（谱嵌入，spectral embedding）
- 在降维空间中使用 k-means 聚类将数据点划分为 k 个不同的邻域流形
- 聚类质心定义为：mu_i = (1/|C_i|) * sum_{j in C_i} U_j，其中 C_i 为第 i 个聚类的样本集合，U_j 为第 j 个样本在低维空间中的坐标

**核心思想**：尽管高维空间中的数据分布通常是非线性的，但在足够小的邻域内，数据流形可近似为线性子空间（Baek et al., 2021; Wang et al., 2024），数据在邻域内表现出强局部一致性。每个数据点可以被其邻域内的其他点线性表达（自表达特性），这种自表达关系确保模型对远离的无关数据点具有鲁棒性，使模型能够专注于有限样本范围内的局部图像特征。

### 3.2 原子增强字典学习模块（Atom-enhanced Dictionary Learning Module）

**核心机制**：利用拉普拉斯矩阵对字典原子进行自表达加权增强，使字典原子更好地捕获局部数据分布。

**Step 1：从拉普拉斯矩阵导出权重矩阵 W**

基本等价关系形式化：

```
sum_{i,j} ||x_i - x_j||_2^2 * W_{ij}  <==>  2 * Tr(X^T * L * X)   (5)
```

左式是基于图结构的加权距离度量（W_{ij} 为权重矩阵，||x_i - x_j||_2^2 为两个稀疏表示原子之间的欧氏距离），右式是以迹运算表达的拉普拉斯矩阵 L 与稀疏表示 X 之间的关系。通过量化图结构中数据点之间的关系并根据加权距离差异对字典原子分配不同权重，达到最小化重建误差的目标。

**Step 2：计算加权字典原子 D_i^R**

```
D_i^R = sum_{j=1}^{l} W_{ij} * D_j   (6)
```

其中 D_i 为字典 D 的第 i 列（一个字典原子），l 为字典原子总数。该步骤在更新字典原子时引入邻居或相似样本的权重信息。

**Step 3：生成增强字典原子 hat(D)_i**

```
hat(D)_i = D_i + lambda * sum_{j=1}^{l} W_{ij} * D_j = D_i + lambda * D_i^R   (7)
```

参数 lambda 控制邻居样本信息的影响程度。设计原则：若直接用 D_i^R 完全替换原始原子，字典会过度关注局部特征而忽视全局优化；由于 D_i^R 由 D_i 变换而来且二者具有相似特征语义，因此通过线性组合在局部与全局之间实现权衡。

**Step 4：统一优化目标函数**

将增强字典 hat(D) 整体替代原始字典 D，构建如下复合优化问题：

```
min_{hat(D), X} ||Y - hat(D) * X||_F^2 + lambda_1 * ||hat(D)||_2^2 + lambda_2 * sum_{ij} ||y_i - y_j||_2^2 * W_{ij}
s.t. 0 <= W_{ij} <= 1,  sum_j W_{ij} = 1   (8)
```

- 第一项：Frobenius 范数重建误差（Y 为原始数据，hat(D) 为增强字典，X 为稀疏表示）
- 第二项：增强字典的 L2 正则化项，由 lambda_1 控制，防止字典更新过度依赖图结构导致过拟合
- 第三项：相似性约束项，由 lambda_2 控制，用拉普拉斯矩阵衡量数据点之间的关系
- 约束条件：权重矩阵 W 满足非负性（0 <= W_{ij} <= 1）和归一化（sum_j W_{ij} = 1）

使用 ReLU 激活函数促进稀疏表示（继承自作者前期工作 Gou et al., 2024），省略了显式的稀疏约束项以简化优化过程。由于仅选择离输入数据最近的字典原子，编码系数保持稀疏，从而在特征编码中保留输入数据的空间信息。

### 3.3 优化过程

**总体策略**：基于 CADL（Consistent Adaptive Sequential Dictionary Learning, Seghouane & Iqbal, 2018）的迭代优化方法——该方法在最终收敛率上优于经典的 K-SVD 算法。维持对稀疏系数 X 和字典 D 的交替更新，每次独立更新一个字典原子。利用图拉普拉斯的半正定性，将每个原子更新转化为与该拉普拉斯矩阵关联的凸二次优化问题，保证唯一解。

**Step 1：问题转换**

将式 (8) 中重建误差部分的 hat(D) 展开，将相似性正则化项转换为拉普拉斯正则化约束项：

```
min_{hat(D), X} ||Y - hat(D) * (I + lambda * W) * X||_F^2 + lambda_2 * Tr(X^T * L * X)   (9)
```

**Step 2：初始稀疏编码**

使用正交匹配追踪（OMP, Orthogonal Matching Pursuit）获取初始字典 D_0（此时不使用图拉普拉斯影响），在选定的支持集上通过 Moore-Penrose 伪逆计算稀疏编码系数：

```
X_i = (lambda * D_0^T * D_0 + I)^{-1} * D_0^T * Y_i   (10)
```

其中 Y_i 为原始样本中的第 i 个原子。

**Step 3：引入辅助变量 M**

用辅助变量 M 替代增强字典 hat(D) 以简化计算，避免显式更新权重矩阵 W，将图的影响集中在统一字典 M 上：

```
||Y - M * X||_F^2 + mu_1 * ||M||_2^2 + mu_2 * ||M - D * (I + lambda * W) * X||_F^2   (11)
```

- mu_1：增强字典 M 的正则化系数
- mu_2：邻域流形正则化项的超参数
- mu_1 与 lambda_1 成正比，mu_2 与 lambda_2 成正比，通过粗略验证确定比例常数以降低计算复杂度（后续参数敏感性分析仅关注 lambda_1 和 lambda_2）

**Step 4：坐标梯度下降法（CGD, Coordinate Gradient Descent）原子级更新**

将重建误差按列展开，隔离第 j 个字典原子 m_j 及其对应的稀疏系数 x_j：

```
||Y - M * X||_F^2 = ||E_j - m_j * x_j^T||_F^2   (12)
```

其中 E_j 表示与第 j 个原子相关的重建误差（即 Y 去掉除第 j 个原子以外所有原子的贡献后的残差）。利用 CGD 方法（Merad & Gaiffas, 2023）交替更新（固定其他变量），得到闭式更新规则：

```
m_i = (x_j^T * x_j + mu * d_j^T * x_j + lambda * mu * w^T * d_j) / (mu + 2 * lambda + x_j^T * x_j)   (13)
x_i = (m_j * E_j^T) / ||m_j||_2^2   (14)
```

**Step 5：块坐标下降法（BCD, Block Coordinate Descent）还原标准字典 D**

增强字典 M 完全导出后替代 hat(D)，在固定变量假设下应用 BCD 方法（Qin et al., 2013）最小化式 (9)。将分离的原子 m_i 整体重新整合并优化，分离出标准字典 D：

```
D = Y * M * (I + lambda * W) * M / (mu * sum_{j=1}^{n} (w_{ij} + lambda_1^{-1}))   (15)
```

其中 n 为字典样本数。注意：式 (11) 在 (M, X, D) 联合空间中是非凸的，但分别对 M 和 X 单独而言是凸的，这保证了交替优化策略的可行性。

**算法 1（Algorithm 1）：原子增强字典学习**

- 输入：图像样本 Y，正则化系数 mu，初始字典 D_0，权重矩阵 W
- 循环直到损失收敛：
  1. 通过式 (10) 更新稀疏表示 X
  2. 通过式 (13) 更新增强字典原子 hat(D)_i
  3. 通过式 (15) 更新标准字典 D
- 输出：增强字典 M，标准字典 D，稀疏表示 X

### 3.4 自适应图学习模块（Adaptive Graph Learning Module）

**设计动机**：字典和稀疏系数迭代更新后，数据分布和局部流形可能发生微妙变化，原始静态的图结构不再完全适应当前字典。需要通过堆积学习块（stacked learning blocks）构建多层网络，使图结构随字典和数据更新持续动态调整，确保字典更准确地反映数据的局部流形结构。

**网络结构**：三层深度字典学习网络，每层迭代后对字典降维，最终获得最具代表性的特征表示。在网络传播过程中，每层基于重建误差形成图偏差项（graph deviation term）Delta L，辅助图更新。

**Step 1：目标函数**

```
min_X sum_{i=1}^{N} ||X_{i-1} * Theta^{(i)} * P^{(i)} - X_i||_F^2 + alpha * Tr(X_i^T * L * X_i)   (16)
```

- 第一项：对前一层稀疏表示 X_{i-1} 经过图拉普拉斯变换后的重建误差
- 第二项：图拉普拉斯结构的正则化项，确保局部结构考虑的充分性和合理性
- N = 3 为深度字典网络层数
- Theta 为负责分配特征权重的正则化参数
- P 为投影矩阵，执行降维操作并对稀疏表示施加谱约束
- alpha 为正则化项系数，控制图拉普拉斯项 Tr(X^T L X) 相对于重建损失的权重

若 X_i 的元素表现出强局部结构一致性，正则化项较小；反之，显著的结构变化将产生更大的惩罚。

**Step 2：求解投影矩阵 P^{(i)}**

由于矩阵 P^{(i)} 正定，采用矩阵分解方法：

```
P^{(i)} = (Theta^{(i)} * X_{i-1}^T * X_{i-1} * Theta^{(i)} + alpha * I)^{-1} * Theta^{(i)} * X_{i-1}^T * Theta^{(i)}   (17)
```

该投影矩阵将前一层参与权重的稀疏表示投影到下一层空间。

**Step 3：联合优化获得新图拉普拉斯**

将式 (17) 代回式 (16)，固定除 X 和 Theta 外的其他变量，导出关于 X^{(i)} 和 Theta^{(i)} 的联合优化问题：

```
min_{X^{(i)}, Theta^{(i)}} Tr(X_{(i)}^T * (alpha * L + Delta L(X_{(i-1)}, Theta^{(i)})) * X_{(i)})   (18)
```

由于图偏差项 Delta L 和原拉普拉斯矩阵 L 均为半正定矩阵，可联合求解。对 L 和 Delta L 进行特征分解，特征值按升序排序，最优解由最小的 v^{(i)} 个特征值对应的特征向量组成。

**Step 4：非线性激活获取新的稀疏表示**

```
X_{(i)} = phi_{v^{(i)}}(alpha * L + Delta L(X_{(i-1)}, Theta^{(i)}))   (19)
```

非线性激活函数 phi 保留不超过阈值 sigma_{v^{(i)}} 的特征值对应的 v^{(i)} 个特征向量，丢弃不相关的特征分量。系数 alpha 控制拉普拉斯矩阵在模型中的影响程度。

**Step 5：优化正则化参数 Theta**

定义 hat(P) = Theta * P 为投影矩阵 P 的调整结果：

```
Theta^{(i)} = sqrt(||P^{(i)}||_2^2 / sum_{k=1}^{v^{(i-1)}} ||P^{(i)}||_2^2)   (20)
```

其中 v 表示正定矩阵线性组合的最小特征值。Theta 作为先验正则化项，引导自适应图学习框架中拉普拉斯矩阵的下一次迭代。

**算法 2（Algorithm 2）：自适应邻域流形学习**

- 输入：稀疏表示 X，正则化系数 alpha，初始化 Theta_{ii}^{(i)} = 1/v^{(i)}，投影矩阵 P，图拉普拉斯 L
- 循环直到收敛：
  1. 通过式 (17) 更新 P^{(i)}
  2. 通过式 (19) 更新 X_{(i)}
  3. 通过式 (20) 更新 Theta^{(i)}
- 输出：投影矩阵 P^{(i)}，稀疏表示 X_{(i)}，正则化参数 Theta^{(i)}

**最终分类器**：深度增强字典网络生成的稀疏表示 X 作为输入特征，训练 SVM 分类器进行最终的图像分类任务。

### 数据集

共使用六个分类数据集（四个基准 + 两个细粒度）：

| 数据集 | 类型 | 特征维度 | 训练样本数 | 测试样本数 | 类别数 |

| EMNIST | 手写字母 (32x32) | 3072 | 131,600 | 14,000 | 52 |

### Baseline 算法

**字典学习类方法**（用于 Fashion-MNIST、MNIST、EMNIST、SVHN 四个基准数据集对比）：

1. **M2ADL**（Memory Augmented Attentional Dictionary Learning, Zhou et al., 2023b）：利用动态内部和跨阶段记忆增强卷积字典学习网络。
2. **HILADLE**（Hierarchical Locality-aware Deep Dictionary Learning, Gou et al., 2024）：通过分层字典学习获取多抽象级别的局部约束字典。
3. **DSSLDDR**（Discriminative Semi-supervised Learning via deep and Dictionary Representation, Yang et al., 2023）：结合半监督学习与深度字典学习，利用字典表示的判别性重建样本特征。
4. **MCDL**（Multimodal Convolutional Dictionary Learning, Gao et al., 2022）：有效关联多种图像模态并充分考虑图像级别邻域信息。
5. **DDDL**（Intra- and Inter-class Induced Discriminative Deep Dictionary Learning, Gou et al., 2023）：在深度字典学习中形式化类内紧凑性和类间可分性作为两个判别约束。

**细粒度图像分类方法**（用于 Oxford Flowers 102 和 Stanford Dogs 对比）：

1. **RPS**（Representer Point Selection, Song et al., 2023）
2. **JGP**（Joint Graph Partition, Su et al., 2022）
3. **MO**（Mining frequent Itemsets with Multi-scale features, Zhang et al., 2020）
4. **ORE**（Object Representation Enhancement, Li et al., 2022）

### 评估指标

- **Accuracy（准确率）**：(TP + TN) / (TP + TN + FP + FN)
- **Precision（精确率）**：TP / (TP + FP)
- **Recall（召回率）**：TP / (TP + FN)

### 实现细节

- **硬件配置**：Intel Core i9-13900 CPU @ 2.90GHz，64GB RAM，NVIDIA GeForce RTX 3090 GPU，64 位 Windows 10
- **网络结构**：三层深度字典学习网络，字典原子典型配置为 400-200-100（按第 1/2/3 层排列）
- **激活函数**：逆双曲正切（Inverse Tanh, Jagtap et al., 2020）用于重建；Elliot-Sig（Kaleeswaran et al., 2020）用于分类
- **损失函数**：交叉熵损失（Cross-Entropy Loss）
- **优化器**：SGD，学习率 = 0.1，动量 = 0.9，权重衰减 = 3e-4，批次大小 = 128
- **超参数搜索空间**：lambda_1 和 lambda_2 从集合 {1e-5, 1e-4, ..., 1e2, 1e3} 中选取
- **最近邻数**：固定为 k = 5
- **参数比例关系**：mu_1 正比于 lambda_1，mu_2 正比于 lambda_2，通过粗略验证确定比例常数

### 5.6 参数敏感性分析

在四个基准数据集上对 lambda_1（增强字典正则化参数）和 lambda_2（相似性权重参数）进行敏感性分析（Fig.6），取值集合为 {1e-5, 1e-4, ..., 1e2, 1e3}，最近邻数固定为 k = 5：

- **lambda_1 的影响**：对 DNADL 性能有显著影响。在三层 DNADL 中，第一层的 lambda_1 对深度字典学习过程起更关键的调节作用——这符合 lambda_1 负责防止增强字典过拟合的角色设定。
- **lambda_2 的影响**：当 lambda_1 固定时，lambda_2 的变化对性能影响相对不显著，表明方法对 lambda_2 不敏感，相似性权重的调整空间较大。这与 lambda_2 控制拉普拉斯矩阵分配的相似性权重这一相对次要角色一致。
- 实验表明，合适的 lambda_1 和 lambda_2 值可以从预设范围中较容易地确定以达到最优性能，方法具有较好的实用性和鲁棒性。

## 主要贡献与局限性

### 主要贡献

1. **邻域自表达流形模块**：针对高维非线性数据表示挑战，提出通过谱聚类（特征间隙自动确定聚类数 + k-means）将数据划分为内部一致的邻域流形，从中提取自表达关系作为图结构化的字典学习起点，使自表达关系准确反映局部数据结构的固有相关性。同时，该模块确保模型对远离的无关数据点具有鲁棒性，实现平滑的数据更新。

2. **基于图拉普拉斯的字典原子增强机制**：首次将图结构信息直接嵌入字典原子更新的核心过程。通过从邻域流形导出的拉普拉斯矩阵对字典原子赋予自表达权重（hat(D)_i = D_i + lambda * sum_j W_{ij} * D_j），使增强后的字典原子有效对齐局部数据分布，提升重建质量和分类性能。这是本文区别于"仅在图正则化层面引入图结构"的现有方法的关键创新点，将图信息从辅助组件提升为优化过程的中心驱动力。

3. **自适应图学习模块**：设计了逐层动态更新的图学习机制，以深层稀疏编码的潜在表示为输入，通过计算图偏差项 Delta L 并联合特征分解，实现图拓扑与字典学习的协同优化。该模块从根本上解决了传统方法中图约束静态性的局限，赋予模型强大的动态自适应能力，使其能够应对数据分布在迭代过程中的演变。

4. **全面的实验验证**：在六个数据集（四个基准 + 两个细粒度）上全面超越 SOTA 方法。消融实验清晰验证了各模块的独立贡献（邻域流形学习的增益最大，自适应图学习进一步显著提升），层数分析验证了三层架构的最优性，参数敏感性分析证明了方法的实用性和鲁棒性。

### 局限性（基于论文内容的分析归纳）

1. **计算开销未量化**：DNADL 涉及三个模块的多轮迭代优化（谱聚类的特征分解、CGD/BCD 原子级迭代优化、自适应图的逐层更新），论文未提供训练时间、推理时间或 FLOPs 的量化对比，实际部署的计算效率不可知。

2. **超参数繁多**：模型涉及多个超参数（lambda_1, lambda_2, mu_1, mu_2, alpha, k, sigma 等），虽然通过比例关系（mu_1 正比于 lambda_1, mu_2 正比于 lambda_2）降低了部分复杂度，但在新数据集上找到最优配置仍需较大搜索工作量。

3. **仅验证图像分类任务**：实验集中在图像分类，未评估方法在字典学习其他经典应用场景（如去噪、超分辨率、图像修复、异常检测等）上的有效性和泛化能力。

4. **对谱聚类的依赖**：邻域流形划分依赖特征值间隙（eigenvalue gap）自动确定聚类数。在数据分布高度不规则、噪声严重或类别数极大的数据集上，特征间隙可能不显著，从而影响流形划分的可靠性和最终性能。

5. **网络深度探索有限**：仅验证了 1-5 层线性堆叠的配置，未探讨更深架构或更复杂的连接模式（如残差连接、跳跃连接、多分支结构）在更大规模数据上的潜在收益。

6. **与深度学习方法的系统对比缺失**：baseline 主要限于字典学习类方法，未与现代 CNN/Transformer 分类方法在统一实验设置下进行系统对比，DNADL 在更广泛分类方法谱系中的定位不够清晰。

## 对后续研究的启发与潜在改进方向

1. **任务泛化**：将 DNADL 的邻域原子增强机制推广到图像去噪、超分辨率重建、图像修复、异常检测等其他字典学习典型应用场景，验证方法在分类任务之外的通用性和泛化能力。

2. **深度优化框架集成**：目前 DNADL 使用传统 SGD 优化器和手工配置的激活函数（Inverse Tanh、Elliot-Sig），可考虑全面集成现代深度学习训练技术——如 AdamW 优化器、批量归一化（BatchNorm）、学习率调度（余弦退火）、混合精度训练等，可能加速收敛并提升最终性能。

3. **轻量化与加速**：研究降低计算开销的策略——使用近似谱聚类（如 Nystrom 方法）、稀疏图构造、随机投影降维、知识蒸馏、模型量化等技术，将模型压缩至可部署于资源受限设备（如移动端、嵌入式系统）的规模。

4. **端到端可微图学习**：当前自适应图学习通过交替优化实现，可探索用可微的图神经网络层（如 GCN, GAT, GraphSAGE）替代当前机制，实现完全端到端的训练，可能提升优化效率和表示质量。

5. **注意力引导的邻域加权**：在邻域流形内部引入图注意力机制（GAT）或 Transformer 风格的自注意力，使邻居权重 W_{ij} 由数据驱动动态计算而非仅依赖固定高斯核函数，增强对复杂局部模式的建模能力和对不同类型数据分布的适应能力。

6. **理论收敛性分析**：提供关于邻域增强字典原子更新收敛性和表示能力的理论保证，例如分析增强字典的 Restricted Isometry Property (RIP) 或 mutual coherence 特性，从理论上解释为何局部自表达增强能提升表示质量。

7. **跨模态与域自适应扩展**：将 DNADL 扩展到多模态数据（如图文匹配、跨模态检索）或无监督域自适应场景，利用图结构在源域和目标域之间传递局部结构信息，提升跨域泛化能力。

8. **自适应网络深度**：基于数据固有维度或学习难度自动确定最优网络层数，如通过验证集上的早停策略或基于拉普拉斯特征间隙的动态深度选择机制，避免手工设定"3层"的先验假设。

9. **更广泛的实验对比**：将 DNADL 与基于 CNN/Transformer 的现代深度学习方法在统一实验设置下进行包含计算效率（训练时间、推理延迟、参数量、内存占用）的全面对比，提供更完整的性能定位。

10. **可解释性分析**：可视化不同层学到的增强字典原子及其对应的局部流形区域，分析哪些局部图像特征（如边缘、纹理、形状）被不同层的字典原子捕获，增强模型的透明度和可解释性。

11. **sigma 和 k 的自适应选择**：目前高斯核带宽 sigma 和最近邻数 k 为固定值或经验选择，可研究针对不同数据集或不同层自适应调整这些参数的方法。

12. **数据增强与鲁棒性**：结合数据增强技术（如旋转、裁剪、颜色抖动等）训练 DNADL，测试方法在数据扰动下的鲁棒性，进一步提升实际应用价值。
