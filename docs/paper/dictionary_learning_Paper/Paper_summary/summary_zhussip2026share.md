## 二、研究动机与问题定义

### 核心痛点

大型语言模型（LLM）虽然性能强大，但其 Transformer 架构存在巨大的计算和存储开销。现有压缩技术主要聚焦于**块内（intra-block）冗余**——通过低秩近似（Low-Rank Approximation）或注意力头剪枝（Attention Head Pruning）来压缩单个 Transformer 块内部的参数。然而，Transformer 的**重复性层级结构**天然存在显著的**跨层/块间（inter-block）冗余**，这一维度除了 KV Cache 外几乎未被系统性探索。

具体而言：一个具有 L 层、隐藏维度为 d 的 Transformer 需要 O(L·d²) 的参数量，其中**注意力模块（Q、K、V、O 四个投影矩阵）**在 LLaMA 和 Mistral 等基础模型中占参数总量的近一半。

### 已有方法的不足

近期提出的方法各有局限：
- **GQA（Grouped-Query Attention）**和 **QK 压缩（如 LISA）**仅在单层内操作或仅关注特定投影矩阵
- **Repeat-all-over** 和 **Sequential-Sharing** 等跨层共享方法探索了有前景的方向，但在推理任务上出现性能退化（Liao and Vargas, 2024）
- 关键缺陷：这些方法**缺乏一个原则性的框架来捕获跨层统计规律**

### 研究目标

如何系统性地利用 Transformer 层间的统计规律和冗余，通过**结构化的跨层权重共享**来大幅降低注意力模块的参数量，同时在不引入知识蒸馏、架构修改或额外正则化项的前提下，保持甚至提升模型性能？

## 三、方法/框架：MASA (Matrix Atom Sharing in Attention)

### 3.1 核心思想

将注意力投影矩阵（Q、K、V、O）的压缩问题**重新构建为字典学习（Dictionary Learning）问题**。受经典信号处理中字典学习（Mairal et al., 2009）的启发，MASA 学习一组**共享的矩阵原子（shared matrix atoms）组成字典 D**，每一层的权重矩阵则表示为这些共享原子的**线性组合（linear combination）**，组合系数每个 block 独有。

与先前方法的本质区别：
- **并非刚性权重绑定（rigid weight tying）**：每层不完全共享同一权重，而是通过系数的不同来保持层间差异
- **并非在固定基上投影**：字典原子本身是可学习的，随训练自适应调整
- **提供从完全共享到完全独立之间的平滑谱系**：通过调整原子数 S 可以灵活控制共享程度

### 3.2 数学形式化

设有 L 个 Transformer 块，第 l 块的任一注意力投影矩阵记为 **W**_l ∈ R^(d×h)（对应 Q、K、V 或 O 之一）。将所有层的该类型权重向量化后水平堆叠：

**W** = [vec(**W**_1) ... vec(**W**_L)] ∈ R^(d·h × L)

MASA 的核心近似形式：

**W** ≈ **D C**  (1)

其中：
- **D** = [vec(**D**_1) ... vec(**D**_S)] ∈ R^(d·h × S) 为**字典矩阵**，包含 S 个共享的矩阵原子
- **D**_s ∈ R^(d×h) 为第 s 个原子（s = 1, …, S）
- **C** ∈ R^(S × L) 为**线性系数矩阵**
- S 为字典原子总数，且满足 S < L 以实现参数压缩

逐层展开的重构形式（对第 l 层的重构权重）：

**Ŵ**_l = Σ_{s=1}^{S} c_{ls} · **D**_s  (**D**_s ∈ R^(d×h), c_{ls} ∈ R)  (2)

即每一层的权重矩阵由**共享字典 D**（所有层公用）和**每层独有的混合系数向量 c_l = [c_{l1}, …, c_{lS}]^T ∈ R^S** 共同决定。每层的独立参数仅为一个 S 维系数向量，而非完整的 d×h 矩阵。

### 3.3 压缩率计算

对于某一特定类型的投影矩阵（如 Q），原始参数量为 L·d·h，压缩后参数量为 S·d·h（字典原子）+ S·L（系数矩阵）。精确压缩率为：

r = 1 − S(d·h + L) / (L·d·h) ≈ 1 − S/L （当 d·h >> L 时近似成立）

**关键配置**：在主要实验中取 S = L/3，即 r ≈ 66.7%。这在 700M 参数模型中意味着注意力参数从 226.5M 降至约 75M。

### 3.4 训练策略：端到端联合学习

与传统字典学习不同（传统方法需先求解优化问题 min ||**W** − **D C**||_F^2 再固定字典），MASA 的字典 **D** 和系数 **C** 通过**网络训练损失的梯度反向传播联合学习**。

重要设计选择：
- **不添加任何软约束**（如原子正交性、单位范数等）到训练损失中，以允许更灵活的学习过程
- **分投影独立字典**：对 Q、K、V、O 四种投影矩阵**分别学习独立的字典池**（即 D_Q ≠ D_K ≠ D_V ≠ D_O），每种投影有自己的一套共享原子，以最大化模型表达能力
- 使用标准优化器（如 AdamW）即可训练，无需特殊的优化算法

### 3.5 系数参数化技巧：Block-Specific Embedding

为增强训练稳定性和混合系数的自适应性，MASA 引入了一种**基于 block 特定嵌入的参数化方案**：

1. 每个 Transformer block 分配一个**唯一的可训练嵌入向量（embedding vector）**
2. 该嵌入向量作为输入送入一个 **3 层 MLP**，MLP 输出该 block 的混合系数 c_l ∈ R^S
3. **训练完成后，MLP 和嵌入向量被丢弃**，仅保留最终的系数矩阵 C 用于推理

该设计的优势：
- 将混合系数的优化与直接梯度更新解耦，减少训练过程中的梯度波动
- 起到**隐式正则化（implicit regularization）**的作用，促进更平滑的收敛
- **推理时无任何额外计算或存储开销**

### 3.6 两种压缩配置

1. **MASA-QKVO（高压缩，66.7%）**：Q、K、V、O 四个投影矩阵全部压缩，各用 S = L/3 个共享原子
2. **MASA-QKV（中等压缩，50%）**：仅压缩 Q、K、V 三个投影矩阵（各 S = L/3），O 投影保持逐层独立

该设计允许可控地研究表达能力与计算效率之间的权衡。

## 四、扩展到预训练模型：免调优的 Matrix PCA 方法

### 4.1 Matrix PCA

与从零训练不同，对于预训练模型，MASA 采用**解析求解（analytical solution）**方法，不依赖网络训练损失。目标是找到一组**单位范数且互相正交**的矩阵基 D_s ∈ R^(d×h)，满足 tr(D_i^T D_j) = δ_{ij}，使重构误差最小：

**D**_1^*, …, **D**_S^* = argmin_{D_s, tr(D_i^T D_j)=δ_{ij}} Σ_{l=1}^{L} ‖**W**_l − Σ_{s=1}^{S} tr(D_s^T W_l)·D_s‖_F^2  (4)

该优化问题存在**闭式解**：矩阵基由矩阵乘积 **W W**^T（其中 W 即式 (1) 中的堆叠权重矩阵）的**前 S 大特征值对应的特征向量**构成。系数由内积直接给出：c_{ls} = tr(D_s^T W_l)。

### 4.2 分组策略（Grouping Strategy）

为在预训练 LLM 中有效应用 MASA，提出了一种基于**层间功能相似性**的数据驱动分组方法：

1. 使用少量校准数据（calibration data），计算每个 Transformer block 的输出隐藏状态
2. 利用模型的最终输出投影（LM head）作为语义探针，将每层的平均（over tokens）隐藏状态映射到输出词汇空间，获得每层对应的**概率分布序列**
3. 计算**连续层之间概率分布的 KL 散度（Kullback-Leibler divergence）**，KL 散度越小表示两层的语义行为越相似
4. 依据 KL 散度将连续块编入同一组，每组内的层共享各自的字典

该策略的核心优势：**完全数据驱动、免训练**，确保参数共享发生在行为语义相似的层之间，从而最大化保持模型的语义连贯性。

### 4.3 局部细化（Local Refinement）

为在不进行微调的情况下提升重构保真度，MASA 引入**数据知情的局部细化**：

1. **残差计算**：通过 Matrix PCA 重构每层权重后，计算残差 ΔW_l = W_l − Ŵ_l
2. **Cholesky 白化变换**：基于校准数据计算输入自相关矩阵的 Cholesky 因子 L_l，对 L_l ΔW_l 进行低秩近似。该变换考虑了输入数据的几何分布，提高了近似效率
3. **自适应秩分配（Adaptive Rank Allocation）**：基于矩阵秩不等式 rank(AB) ≤ min{rank(A), rank(B)}，为不同类型投影矩阵分配不同的残差秩预算：
   - 高内在秩的矩阵（如 W_q、W_o）获得**更多残差容量**
   - 结构性受限的矩阵（如 GQA/MQA 中的 W_k、W_v）获得**较少残差容量**
   - 该非对称分配确保在架构不平衡（如 GQA 中 KV 头数少于 Q 头数）的情况下最优利用参数预算

该细化方法**完全免训练、即插即用**，在保持与预训练检查点兼容的同时显著降低近似误差。

## 五、实验设置

### 5.1 模型架构与规模

- **基础架构**：标准 Transformer（Vaswani et al., 2017），多头自注意力 + GeLU 激活 FFN
- **Tokenizer**：LLaMA tokenizer（Touvron et al., 2023）
- **三个模型规模**：
  - Transformer-S：110M 参数
  - Transformer-M：335M 参数
  - Transformer-L：729M 参数

### 5.2 训练协议

- **训练数据**：Refined-Web 数据集（Penedo et al., 2023），高质量、经过语言和事实一致性过滤的网络语料库
- **训练量**：遵循 Chinchilla-optimal 训练机制（Hoffmann et al., 2022），分配 **20 倍于模型参数量的训练 Token**（如 Transformer-S 对应 2.2B Token）
- **超参数**：遵循已有缩放法则（Zhang et al., 2022; Hoffmann et al., 2022）设置学习率、批次大小、学习率预热等（详见附录）
- **硬件与优化**：A100 40GB GPU，混合精度训练，使用 FlashAttention（Dao et al., 2022）优化长序列处理

### 5.3 评估协议与基准

**零样本（Zero-shot）评估**，覆盖两大类基准：

**多选题推理基准（8 项，报告 AVG 平均准确率 ↑）**：
- PIQA（Bisk et al., 2019）——物理常识推理
- HellaSwag（Zellers et al., 2019）——常识推理
- LAMBADA accuracy（Paperno et al., 2016）——语言理解
- ARC Easy / ARC Challenge（Clark et al., 2018）——科学推理
- SciQ——科学问答
- Race——阅读理解
- MMLU——多任务语言理解

**语言建模基准（报告困惑度 PPL ↓）**：
- WikiText validation set（Merity et al., 2016）
- LAMBADA perplexity（Paperno et al., 2016）

### 5.4 Baselines

| Baseline | 压缩率（注意力） | 说明 |
|----------|-----------------|------|
| GQA（Ainslie et al., 2023） | 43.8% (M) / 41.7% (S, L) | Transformer-M 用 8 组，S/L 用 6 组 |
| Low-Rank Attention | 66.7% | 受 LoRA 启发（Denil et al., 2013），Q/K/V/O 各约束秩 r = d/3 |
| Sequential-Sharing（Takase and Kiyono, 2021） | 66.7% | 确定性共享模式 |
| Repeat-all-over Sharing（Liu et al., 2024） | 66.7% | 重复使用前几层权重 |

### 5.5 视觉任务扩展

- **模型**：Vision Transformer (ViT)
- **数据集**：CIFAR-10、CIFAR-100、TinyImageNet
- **三种 ViT 配置**：
  - 小型：hidden_dim=64, L=12
  - 中型加宽：hidden_dim=256, L=12
  - 深层变体：hidden_dim=256, L=24
- **对比**：Vanilla Attention vs MASA-QKVO (S=4)

### 5.6 预训练 LLM 免调优实验

- **模型**：Llama 3.2 1B、Llama 3.2 3B、Llama 3.1 8B
- **Baseline**：SVD-LLM
- **压缩率**：20% 和 30%（注意力权重矩阵）
- **MASA 方法**：Matrix PCA + 分组策略 + 局部细化

## 六、核心结果与发现

### 6.1 主要实验结果（Table 1）

#### Transformer-S（110M）

- **MASA-QKV（50% 压缩）**：平均准确率 **34.43%**，超过完整 Transformer-S（33.48%）约 **+0.95pp**（论文报告 +1.0%）；WikiText 困惑度从 76.11 降至 72.08（降低 4.03），LAMBADA 困惑度从 167.39 降至 112.23（大幅降低 55.16）
- **MASA-QKVO（66.7% 压缩）**：平均准确率 **33.74%**，略超完整模型（+0.26pp），显著优于所有 66.7% 压缩率的 baseline——比 Low-Rank（32.27%）高 +1.47pp，比 Seq-Sharing（33.50%）高 +0.24pp，比 Repeat-all-over（33.24%）高 +0.50pp。WikiText 困惑度 72.82（比第二好的 Repeat-all-over 的 78.97 低 6.15），LAMBADA 困惑度 133.62（比 Repeat-all-over 的 162.15 低 28.53）

#### Transformer-M（335M）

- **MASA-QKV（50% 压缩）**：平均准确率 **37.86%**，超过完整模型（37.31%）和 GQA（37.39%）；WikiText 困惑度 42.31，LAMBADA 困惑度 45.27
- **MASA-QKVO（66.7% 压缩）**：平均准确率 **37.37%**，与完整模型（37.31%）**基本持平**，优于所有 66.7% baseline（Low-Rank 36.84%, Seq-Sharing 36.80%, Repeat-all-over 36.83%）。WikiText 困惑度 45.00，LAMBADA 困惑度 50.26

#### Transformer-L（729M）

- **MASA-QKV（50% 压缩）**：平均准确率 **41.74%**，WikiText 困惑度 30.83（比完整模型的 30.88 低 0.05），准确率比完整模型（42.12%）略低 0.38pp
- **MASA-QKVO（66.7% 压缩）**：平均准确率 **41.30%**，在 66.7% 压缩率下全面领先所有 baseline：比 Repeat-all-over（40.54%）高 +0.76pp，比 Seq-Sharing（40.51%）高 +0.79pp，比 Low-Rank（40.07%）高 +1.23pp。WikiText 困惑度 31.34，LAMBADA 困惑度 21.21（Repeat-all-over 为 27.67，差距 6.46）。与完整模型的差距：困惑度差 0.46，准确率差 0.82pp——**均控制在 1 个百分点以内**

### 6.2 模型缩放分析

关键缩放规律发现：

- **小模型受益最大**：在低容量条件下（110M），MASA-QKVO 引入的归纳偏置（inductive bias）补偿了有限的模型表达能力，相对优势最大
- **困惑度差距随模型增大收窄，但依然可观**：在 729M 模型上，Repeat-all-over 在 LAMBADA 上仍落后 MASA-QKVO 6.46 个困惑度点
- **准确率领先幅度随模型增大而小幅扩大**：在 S 尺度上 MASA-QKVO 领先第二好的 66.7% 方法 +0.24pp（vs Seq-Sharing），在 M 尺度上领先 +0.53pp（vs Low-Rank），在 L 尺度上领先 +0.76pp（vs Repeat-all-over）——表明 MASA 在参数受限条件下能更好地利用增加的模型容量
- **大模型对层间多样性需求更高**：完整模型与 MASA 在大模型上的差距略大于小模型（0.82pp vs 0.26pp），与缩放法则（Kaplan et al., 2020）一致
- **关键结论**：一个注意力模块被压缩了三分之二的 MASA-QKVO 模型，在 729M 参数规模上仍与完整模型保持 1pp 以内的准确率差距，同时显著优于所有 SOTA 压缩方法

### 6.3 字典大小 S 的消融实验（Table 2, Transformer-S）

研究 S = 2, 4, 6, 8 对 MASA-QKV 和 MASA-QKVO 性能的影响：

**发现一：字典越大，性能越好**。对于 MASA-QKVO，增大 S（降低压缩率）持续改善困惑度和准确率，验证了更丰富的字典表示能力对长程建模和推理的促进作用。

**发现二：MASA-QKVO 的准确率对压缩高度鲁棒**。MASA-QKVO 在 S=2 到 S=8 的不同配置下，平均准确率从 33.82% 到 33.94%，最大波动仅 0.20pp。即使在极高压缩率下（S=2，83.3%），准确率也稳定在 33.82%，提示适度的字典共享具有正则化效果。注：MASA-QKV 的准确率波动略大（33.77%–34.43%，范围 0.66pp），主要是 S=4 配置表现突出。

**发现三：O 投影对压缩更敏感**。在相近压缩率下比较：MASA-QKV S=2（压缩 62.5%）LAMBADA 困惑度为 133.03，而 MASA-QKVO S=4（压缩 66.7%）LAMBADA 困惑度为 133.62——两者压缩率和困惑度相近，但 MASA-QKV 使用了更少的参数（因为 O 未压缩）。若以同等 S 值直接比较：MASA-QKV S=4 的 LAMBADA 困惑度为 112.23，远优于 MASA-QKVO S=4 的 133.62，表明压缩 O 投影会引入显著的语言建模瓶颈。

**发现四：Q、K、V 投影的跨层冗余度更高**。MASA-QKV 即便在高压缩率下（S=2，62.5% 压缩），性能仍与完整模型相当甚至更优（AVG 33.77% vs 33.48%）；而压缩 O 投影（MASA-QKVO）即使有更多共享矩阵也难以恢复同等性能。这说明 **Q、K、V 在层间冗余度高，而 O 投影在信息变换中扮演更专业化、不可替代的角色**。

**实践设计原则**：优先压缩 Q、K、V 投影，保留 O 投影的参数独立性。

### 6.4 计算开销

在 A100-40GB 上，序列长度 n=256、batch=16 条件下：
- MASA-QKVO：**1240 tokens/sec**
- Transformer-S：1352 tokens/sec
- 吞吐量下降约 **8.3%**
- FLOPs 从 4n²d + 8d²n 增加至 4n²d + 8d²(n+k)，其中 k 为原子数，满足 k << n，因此额外计算开销可忽略

**关键发现**：MASA-QKVO（S=4）在所有 ViT 配置下**持续超越 Vanilla Attention**，在小模型（64 维）上优势尤其显著（+2.35pp）。论文指出在 CIFAR-10 和 TinyImageNet 上同样观察到一致优势（结果见附录）。

## 七、主要贡献

1. **理论贡献**：首次将注意力压缩问题重构为字典学习问题，建立了经典信号处理与 Transformer 效率优化之间的原则性联系，揭示了共享矩阵原子如何捕获跨层统计规律并高效利用块间冗余。

2. **方法贡献**：提出 MASA 框架——一种**无需知识蒸馏、额外正则化或架构修改**的即插即用方案。通过分投影独立字典（Q/K/V/O 各有自己的原子集）和 block 特定嵌入参数化，实现了灵活的自适应跨层共享。训练用标准优化器，推理时无额外开销。

3. **性能贡献**：在语言建模（困惑度）、推理和知识基准上全面超越 GQA、Low-Rank、Sequential-Sharing 和 Repeat-all-over Sharing，在相同或更高压缩率下表现更优。66.7% 压缩的 MASA-QKVO 在多尺度上匹配甚至超越完整 Transformer 性能。

4. **通用性验证**：方法成功扩展到 ViT（图像分类）和预训练 LLM 免调优场景（Matrix PCA + 分组 + 局部细化），展示出跨领域、跨训练范式的广泛适用性。

5. **实践指导**：通过系统消融实验提供明确的设计原则——Q、K、V 投影比 O 投影更适合压缩，为工程实践提供直接指导。同时探索了利用共享跨投影字典的设计空间。

---

## 八、局限性

1. **大模型极端压缩时的性能差距**：在 729M 的 Transformer-L 上，MASA-QKVO（66.7% 压缩）与完整模型存在 0.82pp 准确率和 0.46 困惑度差距，表明超大模型可能更需要层间多样性。

2. **仅限于注意力模块**：MASA 仅压缩注意力投影矩阵（Q、K、V、O），未涉及 FFN 层的压缩，而 FFN 同样占据大量参数。

3. **O 投影压缩瓶颈**：消融实验明确显示 O 投影对压缩高度敏感，压缩 O 会导致语言建模性能显著退化，限制了整体压缩率可进一步提升的空间。

4. **预训练模型免调优压缩率有限**：预训练模型的免调优注意力压缩率仅在 20%–30% 范围，远低于从零训练时可达到的 66.7%，且分组策略需要校准数据，无法做到完全的零数据依赖。

5. **未在大规模现代 LLM 上验证从零训练**：从零训练实验的最大模型仅 729M 参数，远小于当前主流的 7B–70B 级别 LLM。MASA 在 7B+ 模型从零训练时的效果和缩放行为尚待验证。

6. **推理速度轻微下降**：由于原子加权操作，推理吞吐量下降约 8.3%，在延迟敏感场景中可能需要针对性的 kernel 优化。

7. **共享字典在极端异构层结构中的适用性有限**：若模型的不同层使用不同的头数或维度（非均匀架构），统一字典的适用性可能受限。

## 九、对后续研究的启发与潜在改进方向

1. **扩展至 FFN 层**：将 MASA 的字典学习思想应用于 FFN 权重矩阵（W1, W2, W3），实现 Transformer 全模块的跨层压缩；进一步探索注意力与 FFN 联合字典学习的可能性。

2. **多层次混合压缩**：结合 MASA（跨层共享）、GQA 或 MQA（跨头共享）和低秩分解（块内压缩），构建"跨层 + 跨头 + 块内"的三维参数共享体系，更全面地挖掘 Transformer 不同维度的冗余。

3. **更大规模验证**：在 7B、13B 乃至 70B 级别的模型上验证 MASA 从零训练的效果，研究其缩放行为是否持续成立，以及是否需要调整原子数与模型规模的缩放关系。

4. **自适应字典大小**：当前所有层共享相同数量的原子 S，可研究根据层深度或功能自适应调整 S——例如浅层和深层可能对字典多样性的需求不同，或者通过可微方式学习最优的 S。

5. **稀疏系数约束**：在系数矩阵 C 上引入稀疏性约束（如 L1 正则化或 top-k 选择），使每层仅使用少数原子的组合，进一步提升压缩率、可解释性和计算效率。

6. **预训练模型压缩增强**：将局部细化步骤与少量微调（fine-tuning）结合，在适度增加计算成本的前提下显著提升压缩率（从 20%–30% 提升至 50%+ 免调优压缩）。

7. **跨模态与跨架构扩展**：除 ViT 外，可尝试将 MASA 应用于语音 Transformer、多模态模型、Encoder-Decoder 架构、以及 Mixture-of-Experts（MoE）Transformer 等更多领域和架构。

8. **软硬件协同优化**：针对 MASA 的原子加权操作（即 Σ c_ls · D_s 的线性组合）设计专用 CUDA kernel 或硬件加速方案，消除推理时的约 8.3% 吞吐量下降，甚至通过 fused kernel 实现加速。

9. **字典初始化策略研究**：利用预训练权重中的统计先验（如聚类中心、PCA 基）来初始化字典原子，以加速训练收敛并提升最终性能；或者利用已训练好的 MASA 字典作为更大模型的初始化（progressive growing）。

10. **与高效注意力机制融合**：将 MASA 与线性注意力（Linear Attention）、稀疏注意力（Sparse Attention）或状态空间模型（如 Mamba）等方法结合，同时降低参数冗余和计算复杂度，实现"参数效率 + 计算效率"的双维度高效 Transformer。

11. **理论分析**：深入研究字典原子数 S 与模型表达能力之间的关系，提供理论上的压缩率下界或表达能力保证，而非仅依靠经验性消融实验。例如，通过信息论或矩阵分析工具定量刻画跨层冗余度。

12. **动态字典**：探索在推理时根据输入动态选择字典原子的子集（输入依赖的稀疏激活），使模型在保持参数共享的同时实现对不同输入模式的自适应表达，类似于 Mixture-of-Experts 中的条件计算范式。
