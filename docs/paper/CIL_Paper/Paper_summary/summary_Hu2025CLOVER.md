## 二、研究动机与问题定义

### 2.1 背景

非样例类增量学习（Non-Exemplar Class Incremental Learning, NECIL）要求在无法保存旧类样本（出于隐私或存储限制）的前提下，持续学习新类同时不遗忘旧类知识。

### 2.2 现有方法的局限

现有 NECIL 方法主要分为两类：

1. **基于原型的方法（Prototype-based）**: 如 PASS、SSRE、NAPA-VQ 等。用类表征的均值作为原型来维持决策边界，但模型的持续更新会导致"原型退化"（prototype degradation），即保存的旧类原型偏离其真实分布。

2. **基于冻结特征提取器的方法（Frozen Feature Extractor-based）**: 如 FeTrIL、FeCAM 等。在初始任务训练后冻结特征提取器以维持表征稳定性。但该方法存在核心缺陷——**冻结的特征提取器没有针对新旧类之间的判别性训练，导致新旧类的特征表征产生重叠（representation overlap）**，阻碍了清晰决策边界的建立。

### 2.3 针对的具体痛点

针对上述表征重叠问题，目前有两条技术路线：

- **自监督学习（SSL）**: 如 PASS 中使用的旋转预测自监督任务，通过变换原始类并赋予任务无关标签，增强模型泛化能力以减少表征重叠。**但本文发现**（图 1a）：旋转变换会显著改变原始类的表征分布，使得即使不用 SSL 也能轻易区分旋转后的类，因此旋转 SSL 实际上未能有效增强模型的判别性表征提取能力——SSL 的潜力未被充分挖掘。

- **集成学习（Ensemble Learning）**: 如 SEED 等，利用多个专家模型从不同视角提取判别性表征。**但本文发现**（图 1c）：新增专家反而会导致性能下降——因为第一个专家（在基任务上训练，数据量大、覆盖类别广）远强于后续专家，刚加入的新专家预测能力有限且不可靠，会干扰已有专家的正确预测。

### 2.4 研究目标

提出 CLOVER 框架，通过以下两个创新来解决上述问题：
1. 增强冻结特征提取器的表征提取能力，减少新旧类表征重叠；
2. 缓解集成模型中不可靠新专家的干扰。

## 三、方法/框架（CLOVER）

### 3.1 整体框架

CLOVER 是一个包含 K 个专家的集成模型（K = 5）。每个专家由以下部分构成：
- 共享编码器（Shared Encoder）**f**：在第一个任务训练后冻结
- 专家编码器（Expert Encoder）**e_i**（i = 0, 1, ..., K-1）
- 对应的线性分类器 **g_i**（仅训练阶段使用，训练后丢弃）

**训练流程**（图 2 所示）:
1. 对任务 t <= K-1，使用 CDSSL 方法训练第 t 个专家
2. 训练完成后冻结 e_t，丢弃线性分类头 g_t
3. 对每个已训练专家 k，计算其对新类 c 的类表征，并建模为独立的高斯分布 G(mu_k^c, Sigma_k^c)，类似原型存储下来用于后续分类推断
4. 当 t > K-1 时，不再新增专家，仅更新已有专家的类分布记录

**推断流程**:
1. 输入 x 经过每个专家得到专家特定表征：r_k = e_k(f(x))
2. 计算 r_k 相对于该专家内各类分布的对数似然（基于高斯分布的 log-likelihood，公式 1）
3. 由于新专家 h（h > 0）无法访问先前类数据，对新专家无法预测的旧类 i（i in C_{0~h-1}），设置 l_h^i(x) = -inf
4. 对似然值应用带温度 tau 的 softmax，得到每个专家对每类的预测概率
5. 使用 PWP 策略计算各专家的权重 w_k，通过加权平均聚合所有专家的预测概率（公式 2）
6. 取 argmax 得到最终预测类别

### 3.2 关键创新 1：Confusion-Driven Self-Supervised Learning (CDSSL)

**核心思想**: 不仅使用传统 SSL 中的旋转变换，还引入颜色通道交换（color channel swapping）和噪声注入（noise injection），生成与原类高度相似（高度易混淆）的任务无关类，迫使模型学习更具判别性的特征。

**具体变换**（公式 3）: 对每张输入图像 x_i in D_k，生成 7 个变体：

| 索引 j | 变换 | 含义 |
|--------|------|------|
| 0 | 原图 | x_i 本身 |
| 1-3 | rotate(x_i, j*90) | 旋转 90/180/270 度 |
| 4 | GBR(x_i) | RGB 通道交换为 GBR 顺序 |
| 5 | BRG(x_i) | RGB 通道交换为 BRG 顺序 |
| 6 | x_i + s * noise(0,1) | 加入标准正态噪声，噪声强度 s = 0.5 |

新标签分配: y_tilde_{7i+j} = 7y_i + j，将原始 N-way 分类扩展为 7N-way 分类。

**训练损失**: 标准交叉熵损失（公式 4）:
```
L = L_ce(g_i(e_i(f(x_tilde))), y_tilde)
```

**关键区别**: 相比 PASS 等的 4N-way（仅旋转），CDSSL 的 7N-way 多出了颜色通道交换和噪声注入这两类变换。这些变换生成的类与原类分布更相似（KL 散度更小，如图 8 所示），因此区分它们需要更精细的判别性特征，从而真正增强模型的特征提取能力。这些任务无关类仅用于训练，推断阶段不涉及。

### 3.3 关键创新 2：Progressively Weighted Prediction (PWP)

**动机**: 在 NECIL 中，基任务通常占一半训练数据，其余均分给增量任务。因此，第一个专家（e_0）预测能力强、覆盖类多，而新专家（e_h, h > 0）刚加入时预测能力有限，对超出其训练范围的旧类往往以高置信度错误分类，干扰集成模型的联合预测。

**策略**（公式 5）: 为每个专家分配不同权重：

```
w_i = {
    1 - sum_{j=1}^{K-1} w_j,                  i = 0 (第一个专家)
    min{alpha + beta * (t - i), 1/K},         i > 0 (后续专家)
}
```

- **alpha**: 新专家的初始权重（低值，如 0.05~0.15）
- **beta**: 逐任务递增的步长
- **t**: 当前任务编号
- **最大权重**: 1/K（即 1/5 = 0.2，等权重情况下的公平权重）
- **第一个专家的权重**: 自动适配为 1 减去其他专家权重之和

**效果**: 新专家刚加入时权重较低，随着训练推进（它见过更多类、预测能力增强），权重逐渐增加至与其他专家平等。这保证了在早期阶段，集成模型的预测不会被不可靠的新专家干扰。

### 3.4 与 SEED 的关系

CLOVER 的 Baseline 基于 SEED [39]——SEED 是一个选择性训练专家的集成学习方法。CLOVER 在 SEED 的基础上增加了 CDSSL 训练策略和 PWP 推断策略。

## 四、实验设置

### 4.1 数据集

| 数据集 | 类别数 | 图像分辨率 | 训练/测试样本 |
|--------|--------|------------|---------------|
| CIFAR100 | 100 | 32x32 | 500/100 每类 |
| TinyImageNet | 200 | 64x64 | 500/50 每类 |
| ImageNet-Subset | 100（选自 ImageNet） | 224x224 | ~13000 训练总量，50 测试/类 |

每个数据集均按 PASS [9] 的配置划分为 3 种增量设置: 5 任务、10 任务、20 任务。

### 4.2 评估指标

- **Average Accuracy (Avg)**: 所有增量阶段的平均准确率
- **Last Accuracy (Last)**: 完成所有任务后在所有已知类测试集上的最终准确率

### 4.3 对比方法（Baselines）

包括 LwF_MC、PASS、SSRE、FeTrIL、PRAKA、POLO、TASS、FGKSR、CEAT、SEED、FeCAM 等（其中 CEAT 和 FGKSR 基于 ViT 架构，其余基于 ResNet18）。

### 4.4 实现细节

- **骨干网络**: ResNet18（与 SEED 一致）
- **专家数 K**: 5
- **训练分类器**: 线性分类头
- **推断分类器**: 贝叶斯分类器（基于高斯分布的 log-likelihood）
- **优化器**: SGD，初始学习率 0.1，weight decay 1e-4
- **学习率衰减**: 在第 60、120、160 epoch 乘以 0.1
- **Batch Size**: 128
- **共享层数**: Baseline 中前 5 层在专家间共享参数
- **运行次数**: 所有实验重复 3 次取平均
- **硬件**: 单张 NVIDIA A100 GPU

## 五、核心结果与发现

### 5.1 基准对比（Table 1）

**CIFAR100**:
- 5/10/20 任务上，CLOVER 的 Avg 分别达到 72.7%/72.3%/71.0%，比次优方法分别高 1.6%/1.5%/1.6%
- Last 分别达到 68.0%/67.5%/64.9%，比次优方法分别高 1.7%/2.5%/3.5%

**TinyImageNet**:
- 5/10 任务上 Avg 和 Last 均为最优
- 20 任务上 FeCAM 的 Avg（59.3%）略优于 CLOVER（58.5%）
- 20 任务上 CLOVER 的 Last（52.8%）与 FeCAM（52.8%）持平

**ImageNet-Subset**:
- CLOVER 在所有配置下的 Last 均为最优（73.2%/71.5%/67.5%）
- Avg 略低于 FeCAM（5 任务: FeCAM 78.3% vs CLOVER 77.8%；10 任务: FeCAM 78.2% vs CLOVER 77.1%；20 任务: FeCAM 75.1% vs CLOVER 74.5%）

**关键观察**: 虽然 CLOVER 在早期任务的 Avg 可能不如 FeCAM，但在所有三个数据集的所有任务设置下，Last Accuracy 始终是最优的，证明了其在缓解灾难性遗忘方面的卓越能力。

### 5.2 消融实验（Table 2）

| 配置 | CIFAR100 (5/10/20) | TinyImageNet (5/10/20) |
|------|---------------------|-------------------------|
| Baseline | 69.9/69.7/67.7 | 56.3/55.3/54.5 |
| +CDSSL | 72.1/71.7/70.5 | 59.9/59.4/58.1 |
| +PWP | 70.5/70.2/68.2 | 56.5/55.8/54.9 |
| +Both (CLOVER) | 72.7/72.3/71.0 | 60.2/59.9/58.5 |

- **CDSSL 是最关键的组件**: CIFAR100 上贡献约 2.0-2.8% 提升，TinyImageNet 上贡献约 3.6-4.1% 提升
- **PWP 贡献约 0.5%** 的额外提升
- CDSSL 在更长任务序列上优势更明显

### 5.3 CDSSL 各变换消融（Table 3）

| 变换组合 | CIFAR100 (5/10/20) | TinyImageNet (5/10/20) |
|----------|---------------------|-------------------------|
| Baseline | 69.9/69.7/67.7 | 56.3/55.3/54.5 |
| +Rot only | 70.7/70.8/69.2 | 57.2/55.9/54.9 |

| +Rot+Color | 71.6/71.3/70.1 | 59.2/58.3/57.2 |

| +Color+Noise | 71.1/70.3/68.5 | 56.7/55.6/55.0 |
| +All(CDSSL) | **72.1/71.7/70.5** | **59.9/59.4/58.1** |

- 旋转提供基础提升（CIFAR100: 0.8-1.5%，TinyImageNet: 0.4-0.9%）
- 颜色通道交换在 TinyImageNet 上尤其有效（额外提升 2.0-2.4%）
- 噪声注入进一步提供至少 0.4% 的提升
- 三者组合（CDSSL）达到最优效果

### 5.4 表征质量与泛化能力分析（图 4、图 7）

- CDSSL 在保持高新任务精度的同时，显著提高了首个任务（旧知识）的准确率
- 传统 SSL 虽有类似趋势但效果远不如 CDSSL
- CDSSL 在 CIFAR100 和 ImageNet-Subset 上均表现出一致的优越性

### 5.5 可视化分析（图 5、图 8、图 9）

- **t-SNE 可视化**（图 5）: 在 CIFAR100 上，当增量引入 2 个和 4 个新类时，Baseline 出现明显的新旧类表征重叠；SSL 难以有效减少重叠；CDSSL 保持了新旧类之间的清晰分离，同时增强了类内紧致性
- **KL 散度分析**（图 8）: 旋转变换产生的任务无关类与原始类的 KL 散度较大（90度: 31.5, 180度: 23.2, 270度: 31.8），而颜色通道交换（GBR: 16.8, BRG: 14.7）和噪声注入（14.5）的任务无关类与原始类的 KL 散度更小，即更易混淆，因此训练模型区分它们能更有效地增强判别性表征学习
- **Bhattacharyya 距离**（Table 15）: CDSSL 训练下类间 Bhattacharyya 距离始终大于 Baseline 和 SSL，定量证明了 CDSSL 有效增强了类间可分离性

### 5.6 专家数量分析（Fig. 6）

- 专家数从 1 增加到 4 时，Avg 和 Last 持续提升
- 超过 4 个后，5/10 任务场景下 Avg 开始下降，Last 提升趋于平缓
- 最终选择 K=5（与 SEED 一致），以在性能和参数量之间取得平衡

### 5.7 共享层数分析（Table 9）

- 共享 5 层时性能最优（5 任务 Last 68.0%、10 任务 Last 67.5%）
- 即使 0 层共享（参数量 56.0M），CLOVER 仍全面优于 SEED
- CLOVER(13 shared) 参数量仅 44.9M 仍优于 SEED（56.0M），验证了方法的有效性

### 5.8 超参数敏感性（Table 10）

- PWP 对 alpha 和 beta 的变化表现出良好的鲁棒性
- 高 alpha 在短任务设置中有优势；低 alpha 在长任务设置中更优（因为新专家数据更少，预测更不可靠）
- 不同配置下 PWP 均能持续带来提升

### 5.9 类均衡设置下的表现（Table 14）

- 在类均衡设置（每个任务类别数相同）下，CDSSL 仍带来显著提升
- CIFAR100 20 任务设置下，CDSSL 带来 6.4% 的 Avg 提升

### 5.10 额外变换实验（Table 12、Table 13）

- 部分变换（如模糊、中心裁剪）在不同数据集上表现不一致（在 CIFAR100 上有效但在 TinyImageNet 上可能无效甚至有害）
- 过度的变换（如更多颜色通道排列 RBG/GRB/BGR 或额外的模糊/裁剪）在 TinyImageNet 上反而导致性能下降
- CDSSL 的三种变换（旋转、颜色交换、噪声注入）在两个数据集上表现一致且稳定

## 六、主要贡献与局限性

### 6.1 主要贡献

1. **提出了 CLOVER 框架**: 一个用于 NECIL 的创新集成学习框架，通过 CDSSL 增强特征提取能力，通过 PWP 优化多专家联合预测

2. **提出了 CDSSL 方法**: 在传统旋转 SSL 的基础上，引入颜色通道交换和噪声注入生成高度易混淆的任务无关类，有效增强了模型的特征提取和判别能力，相比传统 SSL 显著减少了新旧类表征重叠

3. **提出了 PWP 策略**: 通过为新专家分配渐进增长的权重，解决了集成模型中不可靠新专家干扰已有专家预测的问题

4. **全面的实验验证**: 在 CIFAR100、TinyImageNet、ImageNet-Subset 三个数据集上进行了大量实验，包括基准对比、组件消融、变换消融、超参数分析、可视化等，全面验证了方法的有效性。尤其在 Last Accuracy（衡量抗遗忘能力）上达到了 SOTA 水平

### 6.2 局限性

1. **依赖基任务数据量**: 方法依赖基任务有充足的训练数据，尚未在全部任务数据量均衡的设置下验证整体框架（仅验证了 CDSSL 在该设置下的效果）

2. **训练成本较高**: 将 N-way 分类扩展为 7N-way 分类，增加了训练时间。且集成模型（K=5 个专家）导致参数量较大（55.4M）

3. **长任务下平均准确率非最优**: 在 TinyImageNet 和 ImageNet-Subset 的 20 任务设置下，Avg 略低于 FeCAM

4. **共享层数依赖**: 虽然实验显示不同共享层数下均优于 SEED，但达到最优需要仔细调参

## 七、对后续研究的启发与潜在改进方向

### 7.1 方法设计层面的启发

1. **"制造混淆来增强判别"的思路可推广**: CDSSL 的核心哲学——通过引入高度易混淆的训练样本来强迫模型学习更精细的判别性特征——不仅适用于 NECIL，也可以推广到其他需要增强特征提取质量的持续学习或自监督学习场景

2. **表征重叠的定量分析**: 使用 KL 散度评估任务无关类与原始类的相似度、使用 Bhattacharyya 距离量化类间可分离性——这些定量分析工具可被后续工作采用

3. **渐进式权重分配策略**: PWP 的思想（根据专家可靠程度动态分配权重）对其他基于集成的持续学习方法也有借鉴意义

### 7.2 潜在的改进方向

1. **降低训练成本**: 探索如何在不显著损失性能的前提下减少 7N-way 分类带来的训练开销，例如使用更高效的对比损失替代交叉熵，或使用知识蒸馏压缩变换空间

2. **减少参数量**: 探索更高效的参数共享策略或轻量化专家网络设计，使集成模型的参数量接近单模型水平

3. **自适应变换选择**: 当前 CDSSL 使用固定的三种变换组合，未来可以探索根据数据特性自适应选择或生成最优变换策略

4. **扩展到大规模和更复杂场景**: 论文提到了这是未来方向之一。可探索将 CLOVER 的框架扩展到更大规模数据集、更多类别、更细粒度的分类任务

5. **类均衡设置下的全面验证**: 在当前方法中，第一个任务占一半数据是关键假设。探索如何在完全均衡的任务划分下保持或接近当前性能是一个重要方向

6. **与其他技术结合**: CDSSL 的训练方法可以与基于原型的方法、数据回放方法等结合，进一步挖掘协同增益

7. **更深入的消融分析**: 例如分析不同噪声强度 s 的影响、不同旋转角度组合的影响、温度参数 tau 的敏感性等
