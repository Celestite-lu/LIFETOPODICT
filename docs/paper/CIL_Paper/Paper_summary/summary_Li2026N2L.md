## 研究动机与问题定义

### 痛点
现有的基于预训练模型的类增量学习（Class Incremental Learning, CIL）方法虽然在性能上取得了显著进展，但普遍假设每个增量任务都能获得**完整的标注数据**（fully labeled data）。然而在实际应用中，标注数据获取成本高昂、耗时耗力，这一假设往往不切实际。

### 问题设定
本文提出了一种**更现实的CIL范式**：在每个增量任务 t，模型仅能获得：
- 该任务的**无标注图像数据** U_t = {x_j}（n_t 个样本）
- 该任务对应的**类别名称集合** C_t = {c_y | y in Y_t}

不再提供任何 ground-truth 标签。这是一个结合了无标签学习（learning from unlabeled data）与类增量学习的新设定。

### 核心挑战
- 虽然可以利用预训练视觉-语言模型（如CLIP）的零样本能力生成伪标签，但伪标签**天然存在噪声**
- 若直接将现有CIL方法应用于这些带噪伪标签，**灾难性遗忘（catastrophic forgetting）会被严重加剧**
- 伪标签的数量不均衡（不同类别预测样本数差异大）和置信度信息的丢失（argmax硬标签）进一步恶化了学习效果

## 方法/框架（重点）

N2L 的整体流程在每一增量任务 t 包含四个步骤：(1) 伪标签生成，(2) 渐进式标签精炼，(3) 双层次权重调整，(4) 递推式分类器更新。核心设计理念是：**使用MSE回归目标代替交叉熵**（对标签噪声更鲁棒），并以**递推闭式解**更新分类器（等价于联合训练，消除灾难性遗忘）。

### 3.1 伪标签生成 (Pseudo Label Generation)

利用 CLIP 的零样本能力，计算每张无标签图像 x_i 的图像特征与类别 c 的文本特征之间的余弦相似度，将最高得分的类别作为伪标签：

\tilde{y}_i = argmax_{c in C_t} < f_img(x_i), f_text(p_c) >

其中 p_c 是类别的文本 prompt（例如 "a photo of a [CLASS]"）。

### 3.2 基础框架：解析式CIL (Analytic CIL)

给定所有任务 1 到 T 的特征 X_{1:T} 和 one-hot 标签 Y_{1:T}，联合训练的岭回归（ridge regression）目标为：

L(W_T) = ||X_{1:T} W_T - Y_{1:T}||_F^2 + \lambda ||W_T||_F^2

闭式解为：

\hat{W}_T = (A_T + \lambda I)^{-1} C_T

其中矩阵 A_T 和 C_T 可按如下递推形式计算（A_0, C_0 初始化为零矩阵）：

A_t = A_{t-1} + X_t^T X_t
C_t = C_{t-1} + X_t^T Y_t

这一递推更新的关键性质在于：增量学习得到的分类器 \hat{W}_T 与在所有历史数据上进行联合训练得到的解**完全等价**，从而理论上消除了灾难性遗忘。

### 3.3 渐进式标签精炼 (Progressive Label Refinement) —— 核心创新之一

**关键思路**：对特征矩阵进行**降维**（而非 RAIL (Xu et al., 2024) 方法的升维），在降维后的特征上学习标签精炼分类器，迭代更新伪标签。

**具体流程（每个任务 t）**：
1. 对特征矩阵 X_t (R^{n_t x d}) 进行**奇异值分解（SVD）**：X_t = UDV^T，其中 V = [v_1, ..., v_d]
2. 选择前 k 个**奇异值超过阈值 \theta** 的奇异向量 V_k = [v_1, ..., v_k]
3. 投影特征获得降维表示：X_{t,k} = X_t V_k (R^{n_t x k}, k < d)
4. 使用**降维特征 X_{t,k} 和当前伪标签 \tilde{Y}_t**，通过岭回归学习一个标签精炼分类器 \hat{W}'_t
5. 利用该分类器更新伪标签：\tilde{Y}'_t = argmax(X_{t,k} \hat{W}'_t)
6. 将更新后的伪标签替换原始伪标签，**迭代重复步骤 4-5**（默认 3 轮），渐进式地提升伪标签质量

**理论保证（Theorem 1）**：
考虑含噪回归模型 y = X w* + \epsilon，其中 \epsilon 为零均值、方差为 \sigma^2 的噪声。令 X = UDV^T 为 SVD 分解，\alpha* = V^T w*，\alpha_i* 为 \alpha* 的第 i 个分量，d_i 为 D 的第 i 个对角元素（奇异值）。\lambda 为岭回归正则化系数（通常取 0.1）。

**定理陈述**：若 \sigma^2 \ge (2\lambda + d_j^2)(\alpha_j*)^2，则将 X 投影到去除第 j 个奇异方向后的特征 X' 上，所得回归预测的期望均方误差（MSE）更小：

E[||X' \hat{w}' - X w*||_F^2] \le E[||X \hat{w} - X w*||_F^2]

**直观解释**：当 \alpha_j* 很小（第 j 个方向上的真实回归信号微弱）或 d_j 很小（第 j 个奇异方向包含的特征信息贫乏）时，保留该方向会使得模型更多地拟合噪声而非信号。此时，**去除该方向反而有利**——这等价于对特征进行降维去噪。

**证明概要**（Appendix E.1）：通过将岭回归解分解为信号分量和噪声分量，分别计算偏差平方和方差，然后比较去除第 j 个奇异方向前后的 MSE 表达式，利用条件 \sigma^2 \ge (2\lambda + d_j^2)(\alpha_j*)^2 导出 MSE' \le MSE。

**实践中的阈值选择**：
- 由条件推导出理论阈值 \theta = sqrt(\sigma^2/(\alpha_i*)^2 - 2\lambda)
- 在 Aircraft 第一个任务上实测，**98.14%** 的 \alpha_j* 满足 \sigma^2 \ge (\alpha_j*)^2，**99.9%** 满足 \sigma^2 \ge 2\lambda(\alpha_j*)^2（\lambda=0.1）
- 经实验确定 \theta = 10 为全局最优：MSE 和准确率曲线均呈 U 形，\theta 过小无法充分去噪，\theta 过大则会误删有用信息方向

### 3.4 双层次权重调整 (Bi-level Weight Adjustment) —— 核心创新之二

#### (a) 类间调整 (Inter-class Adjustment)
解决伪标签导致的**类别样本数不均衡**问题。设 N_{t,i} 为第 t 个任务中预测为类别 c_i 的样本数：

m_{inter,i} = n_t / (N_{t,i} * |C_t|)

效果：将每个类别的总权重归一化为 n_t / |C_t|，确保所有类别在训练中的贡献力相等，**防止高频类主导分类器学习**。可视化实验（Fig. 6）表明该策略显著抑制了高频类别的分类器参数范数（L2 norm），实现了更好的类别平衡。

#### (b) 类内调整 (Intra-class Adjustment)
引入伪标签的**置信度信息**，降低低置信度（更可能错误标记）样本的影响。具体策略：

1. 对每个样本，基于精炼分类器的输出 logit 计算**熵** E_i（低熵 = 高置信度）
2. 从高斯分布 N(1, \sigma^2) 中采样 n_t 个权重值 {m'_1, ..., m'_{n_t}}
3. 将采样权重**升序排列**：m'_1 \le m'_2 \le ... \le m'_{n_t}
4. 将样本按熵值**降序排列**（即高熵/低置信度排前面），获得每个样本的排名 rank(E_i)
5. 分配类内权重：**m_{intra,i} = m'_{(rank(E_i))}**

这一排序-映射机制的核心效果是：**熵高（低置信度）的样本获得较小的采样权重，熵低（高置信度）的样本获得较大的采样权重**。

**为何不用简单的 1/E**：当熵接近零时 1/E 会爆炸，且不同数据集的熵分布差异大，单一函数难以泛化。实验（Table 3）证实，直接使用 1/E 作为权重**甚至比不调整更差**（A_B 从 39.69% 降至 38.45%），因为少数极低熵样本会获得巨大权重，主导训练并导致偏差。

**采样分布的选取**：经对比实验（Table 3），高斯分布 N(1, 1/4)（即 \sigma=0.5）取得最佳 A-bar 和 A_B 综合表现（A-bar=43.73%, A_B=40.21%）。因此 N2L 最终采用 \sigma = 0.5。

#### (c) 最终权重
样本 i 的最终权重为两步调整的乘积：

m_i = m_{intra,i} \times m_{inter,i}

#### (d) 带权重的递推求解（Analytic CIL with Weight Adjustment）
引入对角权重矩阵 M = diag(M_1, ..., M_T)，其中 M_t 的第 i 个对角元素为 m_i。加权岭回归目标为：

L(W_T) = (X_{1:T}W_T - Y_{1:T})^T M (X_{1:T}W_T - Y_{1:T}) + \lambda ||W_T||_F^2

闭式解及递推形式为：

\hat{W}_T = (A_T + \lambda I)^{-1} C_T

A_t = A_{t-1} + X_t^T M_t X_t
C_t = C_{t-1} + X_t^T M_t Y_t

**关键性质**：带权重的增量更新解同样等价于在全部数据上进行加权联合训练的解。与无权重版本（Eq. 4）的区别在于特征自相关矩阵和互相关矩阵中引入了权重 M_t，使低置信度样本和少数类样本对统计量 A_t、C_t 的贡献得到合理调节。

### 3.5 推理步骤

推理时遵循 RAIL (Xu et al., 2024) 的预测融合策略，将 N2L 学习到的分类器 logit（\tilde{Y}_i）与 ZS-CLIP 零样本 logit（Y_i）进行加权融合：

Y_{i,final} = (1 - \beta) \tilde{Y}_i + \beta Y_i

其中 \beta = 0.2（N2L 权重 0.8，ZS-CLIP 权重 0.2）。这一融合使得模型在利用新知识的同时保留了 CLIP 的零样本泛化能力。

## 实验设置

### 数据集
六类主要基准数据集：
1. **FGVCAircraft**：飞机细粒度分类，100 类
2. **StanfordCars**：汽车细粒度分类
3. **CIFAR100**：通用物体分类，100 类
4. **CUB-200-2011**：鸟类细粒度分类，200 类
5. **ObjectNet**：偏向真实场景的物体识别数据集，200 类
6. **UCF101**：人类行为识别，101 类

附录中额外评估三个数据集：**Food-101**（食物分类，101 类）、**ImageNet-R**（200 类）、**SUN**（场景识别）。

### 类增量协议
- **无基类（B0IncX）**：所有类别均匀且不重复地划分为 10 个增量任务，每个任务引入 X 个新类别
- **有基类（BNIncX）**：第一个任务包含一半总类别作为基类（即 N 个基类），剩余类别均匀划分为 5 个增量任务（每任务 X 个新类别）

具体任务划分：Aircraft（B0Inc10 / B50Inc10）、Cars（B0Inc10 / B50Inc10）、CIFAR100（B0Inc10 / B50Inc10）、CUB（B0Inc20 / B100Inc20）、ObjectNet（B0Inc20 / B100Inc20）、UCF（B0Inc10 / B50Inc10）。

### 对比方法
- **基于视觉-语言模型的非回放方法**：MoE-Adapters (Yu et al., 2024)、RAPF (Huang et al., 2024)、ENGINE (Zhou et al., 2025a；报告不启用 re-ranking 的结果)、RAIL (Xu et al., 2024)
- **单模态基线**：CODA-Prompt (Smith et al., 2023；仅使用 CLIP 视觉分支)
- **上下界**：ZS-CLIP（零样本推理，下界）；N2L + 真实标签（Label，视为上界）
- **基于回放的方法**（附录，存储 20 样本/类）：PROOF (Zhou et al., 2025b)、CLAP4CLIP (Jha et al., 2024)
- **无标签学习方法**（Table 2）：CPL (Zhang et al., 2024)，分别与 RAIL、ENGINE、N2L 结合

### 评估指标
- **A-bar（平均准确率）**：A-bar = (1/B) \sum_{b=1}^B A_b，其中 A_b 是第 b 个任务完成后的分类准确率
- **A_B（最终任务准确率）**：最后一个增量任务结束时的分类准确率

### 实现细节
- 骨干网络：LAION-400M 预训练的 **CLIP ViT-B/16**（主实验）；OpenAI 预训练的 CLIP ViT-B/16（附录验证跨预训练权重泛化性）
- 特征降维奇异值阈值 **\theta = 10**
- 伪标签迭代精炼轮数 = **3**（0 轮性能最低，1-5 轮均有效，3 轮为默认）
- 类内权重采样高斯分布 **N(1, 1/4)**，即标准差 **\sigma = 0.5**
- 岭回归正则化系数 **\lambda = 0.1**（论文中典型值）
- 推理融合权重 **\beta = 0.2**（遵循 RAIL 的设置）
- 全部结果取 **3 次独立运行的平均值**，同时提供标准差
- 硬件：NVIDIA RTX 4090 GPU，PyTorch
- 所有方法使用**完全相同的数据分割**以确保公平比较

## 核心结果与发现

### 主实验（Table 1）：全面超越 SOTA

**N2L 在所有 12 种场景（6 数据集 x 2 协议）的 A-bar 和 A_B 上均排名第一，无一例外。**

- 在**分布偏移最大**的 Aircraft 和 ObjectNet 数据集上，相对于第二优方法的领先幅度为 **2.75% 到 8.46%**（ObjectNet-B100Inc20 的 A_B 上以 38.65% 领先第二优的 RAIL 30.19%，差距达 8.46 个百分点；Aircraft-B50Inc10 的 A-bar 上领先 ENGINE 2.75 个百分点）
- 在剩余数据集上分别保持至少 **2.82%（Cars）、0.46%（CIFAR100）、1.77%（CUB）、3.39%（UCF）** 的持续优势
- CODA-Prompt 等纯视觉方法在 Cars、CIFAR100、CUB 上**甚至低于 ZS-CLIP**，说明其未能利用 CLIP 的图文对齐能力，且被噪声伪标签严重影响
- N2L 将无标签学习与有标签学习之间的差距**在 Cars、ObjectNet、UCF 上缩小近 50%**（相对于 ZS-CLIP 到上界的差距）

### CPL 对比（Table 2）

- RAIL + CPL、ENGINE + CPL 在 Aircraft-B0 和 CUB-B0 上均有提升，但**仍不敌 N2L（不使用 CPL）**（如 Aircraft-B0 A-bar: N2L 43.71% vs RAIL+CPL 43.61%）
- N2L + CPL 进一步提升至最优（如 Aircraft-B0 A-bar 从 43.71% 提升至 47.48%）

### 与回放方法的对比（Table 4）

- N2L **无需存储任何历史样本（buffer size = 0）**，即超越存储 20 样本/类的 PROOF 和 CLAP4CLIP
- 仅在 CIFAR100、CUB、ObjectNet 的带基类设置下，N2L 以极小差距（0.27%/0.58%/0.43%）次于最佳回放方法
- 原因：递推闭式解 + 权重调整天然具备强遗忘缓解能力，且伪标签精炼提供了更准确的监督信号

### 跨预训练权重泛化（Table 5）

使用 OpenAI 预训练的 CLIP ViT-B/16 时，N2L 在所有设定下同样全面优于对比方法，证明了方法的**预训练权重无关性**。

### 额外数据集（Table 6）

在 Food-101、ImageNet-R、SUN 上，N2L 以无标签方式学习可达到甚至**超过 ENGINE 使用真实标签的性能**。例如 Food-B0Inc10: N2L A-bar=90.58% vs ENGINE+Label A-bar=88.52%。原因是这些数据集的 CLIP 零样本准确率高，生成的伪标签本身质量较高。

### 噪声任务边界鲁棒性（Table 9）

在 20% 或 50% 的训练样本来自先前任务类别的噪声条件下，N2L 的性能衰减显著小于 RAIL 和 ENGINE，且绝对性能仍**全面领先**。例如 Aircraft-B0Inc10 在 50% 噪声下，N2L A-bar=40.49% vs RAIL=33.46% vs ENGINE=33.36%。

### 消融实验

**各组件贡献（Fig. 4, Table 8）** —— 以 Aircraft-B0Inc10 为例：

| 配置 | A-bar | A_B |
|------|-------|-----|
| Base (RAIL) | 36.23% | 33.59% |
| + Inter-class Adjustment | 37.31% | 35.31% |
| + Intra-class Adjustment | 37.29% | 34.35% |
| + Pseudo-label Refinement（单组件贡献最大） | 39.50% | 35.64% |
| + Inter + Intra | 38.14% | 36.45% |
| + Intra + Refine | 41.17% | 36.17% |
| + Inter + Refine | 42.34% | 39.66% |
| + **全部三组件** | **43.73%** | **40.21%** |

**类内调整策略消融（Table 3, Aircraft-B0Inc10）**：
- 不进行类内调整：A-bar=43.39%, A_B=39.69%
- 使用 1/E 作为权重：A-bar=43.25%, A_B=38.45%（**劣于不调整**，因低熵样本权重爆炸导致偏差）
- 均匀分布 U(0.5, 1.5)：A-bar=43.71%, A_B=40.08%
- 均匀分布 U(0.25, 1.75)：A-bar=43.55%, A_B=40.12%
- 高斯分布 N(1, 1/16) (\sigma=0.25)：A-bar=43.61%, A_B=40.23%
- **高斯分布 N(1, 1/4) (\sigma=0.5)**：**A-bar=43.73%, A_B=40.21%**（最优，采纳为默认）

**标签精炼轮数（Fig. 7, Aircraft-B0Inc10）**：
- 0 轮（无精炼）：约 36.7% 最终准确率（最低）
- 1 轮：大幅提升至约 39.6%
- 2 轮：约 39.9%
- 3 轮：约 40.2%（默认设置）
- 4-5 轮：性能稳定（约 40.0%-40.1%）

**奇异值阈值 \theta 与 MSE/准确率（Fig. 5）**：
- 误差（MSE）曲线呈**清晰 U 形**：\theta 从 0 逐渐增大时误差持续下降，\theta 过大（>12-14）则误差回升
- 准确率曲线趋势相同：\theta=10 时的 A_B 约 40.3% 为最优
- 不同任务（1-10）的 MSE-U 形曲线一致性高，验证了方法的跨任务稳定性

**类别平衡效果可视化（Fig. 6）**：
- 类间调整策略显著抑制了高频类分类器权重的 L2 范数
- 各任务下不同类别间的范数差异被大幅缩小，验证了类间平衡的有效性

**统计显著性（Table 7）**：
- 3 次独立运行标准差极小，方法输出高度稳定。例如：
  - Aircraft-B0Inc10: A-bar=43.73+/-0.24, A_B=40.21+/-0.20
  - Cars-B0Inc10: A-bar=92.38+/-0.14, A_B=87.50+/-0.15
  - CIFAR100-B0Inc10: A-bar=87.80+/-0.10, A_B=81.13+/-0.03

**理论假设验证（Fig. 8, Appendix E.2）**：
- 在 Aircraft 第一个任务上实测：**98.14%** 的 \alpha_j* 分量满足 \sigma^2 \ge (\alpha_j*)^2
- **99.9%** 满足 \sigma^2 \ge 2\lambda(\alpha_j*)^2（\lambda=0.1）
- 以上实验结果为 Theorem 1 的条件在使用适当 d_j 阈值时可以被满足提供了实证支持

**各任务详细性能（Fig. 9, Fig. 10）**：
- 在某些数据集上，准确率随任务数增加呈现上升趋势（非典型下降），缘于不同阶段生成的伪标签质量存在差异，高质量伪标签阶段性能提升
- N2L 在几乎所有任务上均取得最优性能

## 主要贡献

1. **新问题设定**：提出首个面向视觉-语言模型的"仅使用无标签数据和类别名称"的类增量学习范式，更贴近实际应用场景
2. **特征降维伪标签精炼**：基于 SVD 降维的渐进式迭代精炼算法，并给出严格的理论分析（Theorem 1），证明在特定条件下降维可降低预测 MSE，为伪标签去噪提供了理论依据
3. **双层次权重调整**：类间调整解决类别不平衡，类内调整（高斯采样 + 熵排序映射）引入置信度信息并避免数值不稳定，两者均无缝集成在递推框架中
4. **递推闭式解保证等价联合训练**：加权岭回归可递推求解，增量学习解与全量数据联合训练解数学等价，理论上完全消除灾难性遗忘
5. **无需回放超越回放方法**：不存储任何历史样本（buffer=0），在多数场景下性能超越每类存储 20 样本的回放方法，兼顾隐私保护与存储效率
6. **大量实验全面验证**：6 大基准 + 3 额外数据集，2 种协议，2 种 CLIP 预训练权重，提供消融、鲁棒性（噪声任务边界）、标准差等全面分析

## 局限性

1. **假设无标签数据严格对应当前任务类别名**：现实场景中无标签数据可能混杂旧类或未来类样本，即存在"开放集"问题。论文附录 I.3 中有初步的噪声任务边界实验（N2L 在此场景下仍最优），但该假设的彻底放宽仍有待深入探索，作者将此列为未来工作方向
2. **对 CLIP 零样本能力高度依赖**：初始伪标签完全依赖 ZS-CLIP 的图文对齐能力。对于与预训练分布差距极大的领域（如细粒度 Aircraft），ZS-CLIP 的绝对准确率仅 26.61%（A-bar, B0Inc10），初始伪标签质量低，制约了 N2L 的绝对性能上限（即使已大幅超越 SOTA）
3. **骨干网络完全冻结**：仅更新线性分类头（通过闭式解）。对于分布偏移特别大的增量任务，CLIP 的冻结特征可能不足以提供足够的判别力，全部或部分微调骨干网络（需配合遗忘缓解机制）可能进一步提升性能
4. **超参数的经验依赖性**：阈值 \theta=10 基于 Aircraft 上的实验选定（虽有理论指导），类内权重采用固定的 N(1, 1/4)，这些设置在理论上并非对所有数据分布都是最优的
5. **未涉及更极端的无监督场景**：如连类别名称也不提供的纯无监督增量聚类、伪标签质量极差甚至完全随机时的应对等

## 对后续研究的启发与潜在改进方向

1. **放宽类别对应假设**：探索开放世界增量学习场景（论文作者也已列为未来工作方向），即无标签数据可能来自旧类、当前类或完全未见过的类别，需要同时具备拒识（out-of-distribution detection）与增量学习能力
2. **设计条件式骨干微调机制**：在伪标签精炼质量达到一定置信度阈值后，谨慎地解冻骨干网络的特定层或适配器模块（如 LoRA、Adapter），以获得更强的任务适配能力。需设计配套的遗忘防护机制
3. **自适应/类别级降维策略**：替代全局固定阈值 \theta=10，根据每个任务或每个类别的奇异值谱自适应确定最优降维维度 k。可参考信息论准则（如 AIC、BIC）、拐点检测（elbow method）或基于重构误差的自适应策略
4. **融入更强的视觉-语言基座模型**：将 CLIP ViT-B/16 替换为更强的基座模型（如 SigLIP、MetaCLIP、DFN-CLIP、EVA-CLIP 等）。同时可借鉴 ENGINE 的思路，使用 LLM（如 GPT-4）为各类别生成更具判别力的文本描述，以改善初始伪标签质量
5. **类内权重策略的理论深化与优化**：目前"高斯采样 + 熵排序映射"策略虽经实验验证有效，但缺乏严格的理论解释。可从 Huber 损失、鲁棒 M 估计、importance weighting 或 influence function 的角度给出理论推导，指导更优的权重函数设计
6. **伪标签质量的在线评估与自适应机制**：设计轻量级模块（如基于预测一致性、熵统计量或邻域一致性）动态估计当前任务伪标签的整体可靠性，并据此自动调节精炼轮数、权重采样方差、推理融合权重 \beta 等超参数
7. **MSE 与对比/度量学习的混合优化**：虽然 MSE 对标签噪声鲁棒，但对比学习或度量学习在细粒度判别任务上更具优势。可探索在伪标签精炼或最终分类器训练阶段引入对比损失项
8. **扩展到其他视觉任务**：将框架从图像分类推广到视频理解（动作识别已在 UCF101 上初步验证）、语义分割、目标检测、跨模态检索等更复杂的视觉任务
9. **与参数正则化或蒸馏方法的系统结合**：当未来版本需要对骨干网络进行微调时，递推闭式解方法与参数正则化（EWC、MAS、SI）、知识蒸馏或提示学习（prompt learning）的结合可提供多层遗忘防护
10. **类别名称未知的纯无监督增量学习**：进一步提升挑战性——连类别名称也不提供，仅给出一组无标签图像，要求模型自行发现新类别（novel class discovery）并增量学习，同时不遗忘旧类别知识
