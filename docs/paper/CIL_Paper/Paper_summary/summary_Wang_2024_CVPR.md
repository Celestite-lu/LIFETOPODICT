## 二、研究动机与问题定义

### 2.1 研究背景与痛点

现实世界中的数据流往往同时存在两个严峻问题：
1. **数据分布呈长尾形态**（long-tailed distribution）：多数类（majority classes）样本充足，少数类（minority classes）样本稀缺，导致模型在少数类上表现极差。
2. **数据持续到达**：模型需要不断学习新类别，而旧数据因隐私等原因不可再访问，这导致灾难性遗忘（catastrophic forgetting）。

将二者结合便构成了**长尾类增量学习**（Long-Tail Class Incremental Learning, LT-CIL）场景——模型需从长尾分布、持续到达的数据流中不断学习新类，同时保留对旧类的判别能力。

### 2.2 现有方法的不足

此前唯一的 LT-CIL 专项工作（Liu et al., ECCV 2022, [22]）仅通过加平衡训练损失来适配已有类增量学习方法，但忽略了**探索不同类别样本之间的潜在关系**，导致：
- 学习到的表征不够鲁棒（non-robust representations）；
- 少数类上的遗忘尤为严重。

### 2.3 两个核心障碍

论文将 LT-CIL 面临的两大挑战形式化为：
- **任务间不平衡（Inter-task Imbalance）**：学习新任务时遗忘旧任务知识，即灾难性遗忘。
- **任务内不平衡（Intra-task Imbalance）**：同一任务内不同类别的样本数差异巨大，呈长尾分布。

### 2.4 两种 LT-CIL 场景

论文遵循 [22] 定义了两种 LT-CIL 场景，用不平衡比率 rho 参数化（rho = 最少类样本数 / 最多类样本数）：
- **Ordered LT-CIL**：整个数据集按递减样本数划分为不同任务，任务间的总样本数也呈递减趋势。
- **Shuffled LT-CIL**：多数类和少数类随机分配到各任务中，任务间的总样本数呈随机趋势。

### 2.5 问题形式化

模型需依次学习 T 个不同任务，各任务包含互不相交的类别集合。网络由特征提取器 f_theta 和统一分类器 g_phi 组成，模型在任意时刻需对所有已见类别做出分类预测。LT-CIL 的特殊之处在于每个任务内的类别样本数不等，存在长尾分布。

## 三、方法/框架（重点）

### 3.1 整体思路

论文提出**两个并行空间**协同运作：
1. **子原型空间（Sub-prototype Space, SS）**：由跨类别共享的独立子原型基向量张成，融合来自不同类别的知识，缓解任务内不平衡。
2. **回忆空间（Reminiscence Space）**：存储每个类别的特征分布（高斯分布 + 子原型关联矩阵），约束模型优化以缓解任务间遗忘。

### 3.2 子原型空间（Sub-prototype Space）

子原型空间包含两个阶段：**空间构造（Space Construction）** 和 **特征重采样（Feature Re-sampling）**。

#### 3.2.1 空间构造阶段

**核心思想**：学习一组可训练的独立子原型基向量，作为不同类别共享的细粒度语义原子，利用多数类的丰富知识辅助少数类的表征学习。

**具体机制**：

1. **基向量定义与扩展**：
   - 设特征提取器输出特征为 z^t = f_theta(x^t) in R^{B x D}（B 为 batch size，D 为特征维度）。
   - SS 由 M^t 个基向量组成，每个新类增加 n 个基向量。
   - M^0 = n x N^0，M^t = M^{t-1} + n x N^t（t >= 1）。
   - 基向量矩阵：L_t = [L_{t-1}; l_1, ..., l_n] in R^{M^t x D}。

2. **相关性查询**：使用余弦相似度作为查询函数 Q，计算输入特征与所有基向量的相关性矩阵 A_t = Q(z^t, L_t) = [a_{ij}]_{i in B, j in M^t}。

3. **Top-k 筛选与控制因子**：
   - 仅保留相关性最强的 k 个基向量，防止特征投影过度分散。
   - 引入控制因子 H = [eta_i]，其中 eta_i = e^{-n_i}（n_i 为基向量 i 被选中的累计次数），防止部分基向量被频繁选中而导致空间向某些维度倾斜。
   - 仅当 a_{ij} in [H*A[i:]]_{top_k} 时保留 a_{ij}，否则置 0。

4. **特征投影**：Z_tilde = A_t L_t^T

5. **构造损失**：
   - L2 约束损失：L_con = ||Z_tilde - Z||_2，确保投影前后语义一致性。
   - 分类损失：L_cls = L_ce(g_phi(x), y)（标准交叉熵损失）。
   - 构造阶段基本损失：L = L_cls + lambda_1 L_con。

#### 3.2.2 特征重采样阶段

构造完成后，固定子原型空间（基向量不再更新），仅训练特征提取器 f_theta 和分类器 g_phi。

**重采样策略**：
1. 对每个特征，重新计算与 SS 中所有基向量的相关性因子。
2. 选取相关性最强的 top-2 基向量 l_top1, l_top2 作为重采样的基准方向。
3. 从剩余 M^t - 2 个基向量中随机选取 h 个，组合生成增强特征：
   z_hat = l_top1 + l_top2 + I[C_{M^t-2}^h sum_{i=1}^h l_i]
   其中 I 为指示矩阵，[C sum l_i] 表示任选 h 个基向量的所有组合。
4. 自适应重采样数量：N_{re,i}^t = N_{max}^t - N_i^t + 10，其中 N_max 为任务中最大类样本数。
5. 重采样特征与原始特征拼接：Z_new := [Z, Z_hat]。
6. 重采样损失：L_f = L_ce(Z_new, Y_new)。

---

### 3.3 回忆空间（Reminiscence Space）—— 抗遗忘机制

为避免学习新任务时已有子原型基向量被新知识腐蚀（即任务间遗忘），论文提出回忆空间来存储每类的数据分布信息，以无回放（replay-free）方式约束模型。

**构建方式**（每个任务训练结束时）：
1. 计算类别 k 的特征质心 mu_k = (1/n_k) sum f_theta(x_i) 及协方差矩阵 Sigma_k，形成多元正态分布 N_k = N(mu_k, Sigma_k)。
2. 计算类别 k 在 SS 中的平均相关性矩阵 A^k = (1/n) sum triangle_k，其中 triangle_k = A_t[a_{k:}] 表示类别 k 与所有基向量的相关性向量。
3. 回忆空间中该类的存储项：S_k = (N_k, A^k)。

**两种蒸馏/约束损失**：
- **L_dis1（子原型空间蒸馏损失）**：用存储的 A^k 约束新任务训练时的基向量相关性矩阵，防止 SS 被破坏。由于不同任务对应的基向量维度不同，需进行维度掩码对齐：
  L_dis1 = sum_{i=1}^{N_t} ||A^i - Q(mu_i, L_t)[: I_i]||_2，其中 I_i 表示 A^i 的维度。
- **L_dis2（回忆空间特征采样损失）**：从回忆空间分布中采样特征 v_tilde^k ~ S_k，计算交叉熵损失：L_dis2 = L_ce(v_tilde^k, k)。

### 3.4 完整训练流程与损失函数

**阶段一 —— 空间构造**：L_1 = L_cls + lambda_1 L_con + lambda_2 L_dis1

**阶段二 —— 特征重采样**：L_2 = L_f + lambda_3 L_dis2

### 3.5 关键超参数汇总

| 超参数 | 值 | 含义 |
|--------|------|------|
| n | 2 | 每个新类新增基向量数量 |
| k | 10 | Top-k 筛选保留数量 |
| h | 4 | 重采样随机选取额外基向量数量 |
| lambda_1 | 6e-4 | L_con 权重 |
| lambda_2 | 10 | L_dis1 权重 |
| lambda_3 | 10 | L_dis2 权重 |
| 学习率 | 0.001 | 每 40 epochs 衰减为原来的 1/10 |
| Batch Size | 64 | 训练批次大小 |
| 构造阶段 epoch | 121 | 空间构造轮数 |
| 重采样阶段 epoch | 81 | 特征重采样轮数 |

## 六、主要贡献与局限性

### 6.1 主要贡献

1. **提出子原型空间（Sub-prototype Space）**：首个通过可学习的跨类别共享子原型基向量来同时缓解任务内和任务间不平衡的方法。该空间融合了不同类别的知识，使多数类的丰富信息辅助少数类学习更鲁棒的表征。核心洞察：纵然类别间样本量差异悬殊，但它们共享细粒度的语义原子（如哺乳动物共享爪子、眼睛等特征）。

2. **提出回忆空间（Reminiscence Space）**：以存储每类特征分布（多元高斯分布 + 子原型关联矩阵期望）的方式，在完全不需要存储原始样本（replay-free）的前提下，通过两种互补的蒸馏损失有效防止灾难性遗忘，兼具隐私友好性。

3. **双空间协同机制与两阶段训练**：通过构造阶段（学习基向量）和重采样阶段（利用基向量增强特征）将两个空间有机结合，显著超越了所有有回放和无回放的对比方法，在 2 数据集 x 2 场景 x 3 不平衡比率 x 2 任务划分 共 24 种实验设置中全部达到 SOTA。

4. **全面细致的实验分析**：通过消融实验、相似性热力图、少数类精度分析、基向量选择频次分析等多个维度，系统性地证明了各模块有效性及其内在机理。

### 6.2 局限性

1. **两阶段训练开销**：需要先进行 121 个 epoch 的空间构造训练，再进行 81 个 epoch 的重采样训练（共 202 epoch），训练时间近乎翻倍。

2. **回忆空间存储开销**：虽不需存储原始样本，但需为每个已见类别存储特征质心、协方差矩阵（D x D）和平均相关性矩阵（M^t 维）。存储量随类别数线性增长。

3. **基向量数量线性增长**：每个新类固定增加 n=2 个基向量，SS 维度 M^t x D 随任务数线性增长。相关性查询复杂度 O(B x M^t)，超长序列下可能成为瓶颈。

4. **仅在小/中等规模数据集上验证**：仅在 CIFAR100 和 ImageNet-Subset（各 100 类）上验证，未在大规模数据集（如全量 ImageNet-1K）或复杂任务（如检测、分割）上验证。

5. **超参数较多**：n, k, h, lambda_1, lambda_2, lambda_3 共 6 个关键超参数需调节。参数敏感性分析仅在补充材料中，正文未展示。

6. **少数类阈值依赖数据集特性**：CIFAR100 阈值 100，ImageNet-Subset 阈值 200，缺乏自适应策略。

## 七、对后续研究的启发与潜在改进方向

### 7.1 启发

1. **共享子原型概念的推广价值**：论文从直觉（哺乳动物共享爪子、眼睛等特征）出发，将跨类别共享子原型形式化为可学习的基向量空间，可推广至小样本学习中的原型增强、领域泛化中的跨域共享表征、联邦学习中 Non-IID 数据的表征对齐等任务。

2. **分布统计量作为隐私友好的知识留存手段**：回忆空间通过存储分布充分统计量（均值 + 协方差矩阵）而非原始样本来实现抗遗忘，在隐私敏感场景（如医疗数据联邦学习）中具有重要价值。

3. **双空间解耦设计范式**：将表征增强（SS）和抗遗忘（回忆空间）解耦为两个并行模块各司其职的设计思路，为持续学习系统的模块化设计提供了有价值的参考。

4. **基向量控制因子机制**：通过 e^{-n_i} 指数衰减的频次惩罚来均衡基向量使用频率，可推广至其他需要均衡资源利用的场景（如 MoE 的专家均衡、聚类中心的负载均衡）。

### 7.2 潜在改进方向

1. **自适应/非均匀基向量分配**：当前每个新类固定分配 n=2 个基向量，可探索根据类的学习难度或样本稀缺度动态分配，给少数类分配更多基向量。

2. **合并两阶段训练**：探索将构造和重采样阶段合并为端到端联合优化，或通过元学习加速第二阶段收敛。

3. **非线性子原型空间**：当前基向量组合是线性的（直接相加），可探索使用非线性映射（如自编码器隐空间或 HyperNetwork）构建更具表达力的空间。

4. **扩展到更大规模场景与复杂任务**：在 ImageNet-1K 或 iNaturalist 等更大规模长尾数据集上验证，同时探索在目标检测（LVIS）、语义分割、实例分割等更复杂任务上的适用性。

5. **基向量生命周期管理**：研究基向量剪枝（移除冗余/低频基向量）、合并（融合相似基向量）或压缩策略，将复杂度从 O(B x M^t) 降为常数。

6. **完全在线的 LT-CIL**：当前方法需任务边界来计算回忆空间统计量，可探索 task-free / online 设定，使统计量随数据流在线更新（如使用 EMA）。

7. **理论分析**：从信息瓶颈理论、互信息最大化或 NTK（Neural Tangent Kernel）角度为方法有效性提供理论解释。

8. **与视觉-语言模型（VLM）的结合**：探索利用 CLIP 等预训练 VLM 的多模态知识来初始化或增强子原型基向量，利用文本语义先验减少对训练样本的依赖。
