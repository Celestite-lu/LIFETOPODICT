## 二、研究动机与问题定义

### 2.1 背景：类增量学习 (CIL) 与预训练模型

类增量学习 (Class-Incremental Learning, CIL) 要求模型连续学习新类别，同时保留对旧类别的知识。核心挑战是灾难性遗忘 (catastrophic forgetting)。近年来，基于预训练模型 (Pre-Trained Model, PTM) 结合参数高效微调 (Parameter-Efficient Fine-Tuning, PEFT) 的 CIL 方法取得了显著进展，且无需存储旧任务样本（即 rehearsal-free）。

### 2.2 现有方法的问题

现有的基于 adapter 的方法（如 EASE、APER）和基于 LoRA 的方法（如 O-LoRA、InfLoRA）普遍采用 **为每个新任务创建新 adapter** 的策略。这种做法存在两个主要问题：

1. **参数冗余 (Parameter Redundancy)**：在推理阶段，随着任务数 T 增加，需要对每个任务对应的 adapter 分别做前向传播，推理计算复杂度高（O(NT)，N 为 transformer block 数）。
2. **无法利用跨任务共享知识 (Lack of Cross-Task Knowledge Sharing)**：不同任务的 adapter 相互独立训练，无法从已学任务中迁移共用特征，导致知识利用率低。

### 2.3 核心挑战

设计一个既能捕获跨任务共享知识、又能保留任务特定特征的 CIL 学习模块面临两个挑战：

- **(i) 共享知识保留**：持续更新共享模块会导致对先前任务模式的灾难性遗忘，偏向最近的类别。
- **(ii) 任务特定特征学习**：在参数效率约束下（低秩分解），如何有效捕获每个任务独有的判别特征，同时防止任务间干扰。

## 三、方法/框架 (CL-LoRA)

### 3.1 整体架构：双适配器架构 (Dual-Adapter Architecture)

CL-LoRA 提出了一种 **双适配器架构**，包含两个互补组件：

- **任务共享 LoRA 适配器 (Task-Shared LoRA Adapter)** `f_shared`：插入到前 `l` 个 Transformer block（本文 l = 6），持续更新以捕获跨任务通用知识。
- **任务特定 LoRA 适配器 (Task-Specific LoRA Adapter)** `f_spec`：插入到后 `N - l` 个 block，每个任务 t 拥有独立的适配器 `{A_t, B_t}`，捕获任务独有特征。

骨干网络为 **ViT-B/16**（N = 12 个 Transformer block），在 ImageNet-21K 上预训练并冻结。LoRA 模块仅插入到 Multi-Head Self-Attention (MHSA) 层的 **query (Wq) 和 value (Wv)** 投影矩阵中，保持 key (Wk) 不变。

### 3.2 任务共享 LoRA 的设计

#### 3.2.1 固定随机正交下投影矩阵

共享适配器采用一种非对称设计：

- **下投影矩阵 Bs**：随机初始化后通过 SVD 转化为**随机正交矩阵**，并在训练过程中**固定不变**（frozen）。
- **上投影矩阵 As**：初始化为零，跨任务持续训练（trainable）。

具体形式为：`f_shared(x) = A_s B_s x`，其中 `B_s B_s^T = I`。

Bs 的初始化方式：
1. 从标准正态分布 N(0,1) 中采样生成随机矩阵 `M in R^{r x k}`。
2. 对 M 进行 SVD 分解：`M = U Sigma V^T`。
3. 取 `Bs = U V_r^T`，其中 `V_r` 表示 V 的前 r 行。

设计动机来源于近期理论分析 (Zhu et al., 2024)，表明 LoRA 中微调 A（上投影）比微调 B（下投影）固有更有效，且随机、未经训练的 B 可以取得与全微调 B 近乎相同的性能。固定正交 B 能有效保留输入数据在低维空间中的结构，缓解遗忘。

#### 3.2.2 双适配器在 ViT 中的插入方式

对于第 i 个 block 的输出 z^i：

- 当 i <= l 时：`z^i = f_theta^i(z^{i-1}) + A_s^i B_s^i z^{i-1}` （共享适配器）
- 当 l < i <= N 时：`z^i = f_theta^i(z^{i-1}) + A_t^i B_t^i z^{i-1}` （任务特定适配器）

设计利用了 ViT 的层级结构特性：浅层 block（1 到 l）捕获可泛化的通用模式，适合跨任务共享；深层 block（l+1 到 N）专注任务特定细节。

### 3.3 跨任务知识学习 (Learning Cross-Task Knowledge)

尽管采用了固定随机正交 Bs，持续更新的 As 仍面临灾难性遗忘风险。为此，CL-LoRA 提出两个互补机制：

#### 3.3.1 早退知识蒸馏 (Early Exit Knowledge Distillation)

在共享适配器与任务特定适配器的**切换点（第 l 个 block）**处设置"早退点"（early exit），在此位置应用知识蒸馏而非在最终层输出处。具体做法：

- 提取当前任务 t 和前一个任务 t-1 在早退点处的 [CLS] token 表示：`z_t^l[CLS]` 和 `z_{t-1}^l[CLS]`。
- 使用当前任务的本地分类器 `h_phi^t` 计算软化概率分布（温度 tau = 2）。
- KD 损失定义为当前任务类别上的知识蒸馏损失（基于软化概率的交叉熵形式）：
  ```
  L_kd = sum_{i in C_t} s_{t-1,i}^tau * log(s_{t,i}^tau)
  ```
  其中 `s_t^tau = Softmax(h_phi^t(z_t^l[CLS]) / tau)`。

在早退点而非最终层做 KD 的动机：若在最终层蒸馏，会损害任务特定适配器学习新任务独特特征的塑性（plasticity）。

#### 3.3.2 梯度重分配 (Gradient Reassignment)

仅靠 KD 提供的隐式引导不足以有效保留知识。CL-LoRA 提出直接利用共享适配器的结构信息——梯度重分配。

核心思路：As 初始化为零，训练后其权值向量的 L2 范数反映了各特征维度需要多大幅度的适配。前一个任务 t-1 的 As 中 L2 范数较大的权值向量对应的特征维度对跨任务知识更为关键。

对当前任务 As^t 的 KD 梯度进行按元素重分配：
```
nabla_{A_s^t} L_kd^* = nabla_{A_s^t} L_kd (element-wise mul) sigma({||a_{s,j}^{t-1}||_2}_{j=1}^d)
```
其中 `sigma(w) = d * w / sum_i w_i` 为维度保持的归一化函数。

效果：对前一任务重要的维度获得更强的保留梯度，其他维度则有更大灵活性适应新任务。

### 3.4 任务特定知识学习 (Learning Task-Specific Knowledge)

#### 3.4.1 可学习块权重 (Learnable Block-wise Weights)

为每个任务的特定适配器引入可学习的缩放因子 `{mu_t^i}_{i=l+1}^N`，调制每个 block 中 LoRA 模块的贡献：
```
z^i = f_theta^i(z^{i-1}) + mu_t^i * A_t B_t z^{i-1},   l < i <= N
```

#### 3.4.2 正交约束正则化

为减少任务间干扰，引入正交约束正则化损失，鼓励不同任务的块权重向量之间保持正交：
```
L_orth = sum_{i=1}^{t-1} sum_{j,k} || (U_t^T U_i)_{j,k} ||_2
```
其中 `U_t = [mu_t^{l+1}, ..., mu_t^N]` 为任务 t 的块权重拼接向量，`mu_t > 0`。

与 InfLoRA、O-LoRA 等方法直接在全部 adapter 参数上施加正交约束不同，CL-LoRA 只在轻量的块权重向量上施加正交约束，避免了过度约束对塑性的损害，同时有效减少任务间干扰。

### 3.5 总体训练目标

```
L = L_ce + lambda1 * L_kd + lambda2 * L_orth
```

其中 lambda1 = 5，lambda2 = 0.0001，在所有实验中固定不变。

### 3.6 推理过程

采用原型分类器 (Prototype Classifier)。推理时，对于输入样本：
1. 通过前 l 个 block 提取共享表示 `z^l`（只计算一次，无需按任务重复）。
2. 对每个已见任务 i，使用其对应的任务特定适配器在剩余 N-l 个 block 上计算任务特定特征 `z_i^N[CLS]`。
3. 分别与各任务的原型进行余弦相似度匹配，取最高分对应的类别作为预测结果。

推理复杂度从 O(NT) 降为 O(l + (N - l)T)。

## 四、实验设置

### 4.1 数据集（4 个 benchmark）

| 数据集 | 类别数 | 任务划分 | 特点 |
|--------|--------|----------|------|
| CIFAR-100 | 100 | T=20 (每任务5类) | 自然物体分类 |
| ImageNet-R | 200 | T=40 (每任务5类) | 艺术渲染风格，分布偏移 |
| ImageNet-A | 200 | T=10 (每任务20类) | 自然对抗样本，分布偏移 |
| VTAB | 50 | T=5 (每任务10类) | 多样化视觉任务（自然场景到医学图像） |

### 4.2 对比方法（9 个 baseline）

- **Prompt-based**: L2P, DualPrompt, CODA-Prompt
- **Adapter-based (MLP)**: APER, EASE, RanPAC
- **Adapter-based (LoRA)**: LAE w/ LoRA, InfLoRA, O-LoRA

### 4.3 评估指标

- **平均准确率 (Average Accuracy) A_bar**：`A_bar = (1/T) * sum_{t=1}^T A_t`，其中 A_t 为学完任务 t 后在所有已见类别上的准确率。
- **最终准确率 (Final Accuracy) A_T**：学完最后一个任务后，在所有类别上的准确率。

### 4.4 实现细节

- 骨干网络：**ViT-B/16**，N = 12 block，ImageNet-21K 预训练，冻结。
- LoRA 秩：**r = 10**（As in R^{768x10}，B in R^{10x768}）。
- 共享适配器插入位置：**l = 6**（前 6 个 block 共享，后 6 个 block 任务特定）。
- LoRA 作用层：MHSA 的 **query (Wq) 和 value (Wv)** 投影矩阵，key (Wk) 不修改。
- lambda1 = 5（KD 损失系数），lambda2 = 0.0001（正交损失系数），全实验固定。
- 分类器：原型分类器 (Prototype Classifier)。
- 结果统计：所有结果基于 **10 次独立运行**，报告均值 ± 标准差。
- 实现框架：基于 LAMDA-PILOT 和 Mammoth 代码库。

## 五、核心结果与发现

### 5.1 主要实验结果 (Table 1)

CL-LoRA 仅使用 **0.3% 的可训练参数**（相对预训练骨干），在多个 benchmark 上取得最优或次优结果：

| 数据集 | CL-LoRA A_T (%) | CL-LoRA A_bar (%) | 最佳对比方法及参数占比 |
|--------|----------------|-------------------|----------------------|
| CIFAR-100 (T=20) | 85.32 (±0.08) | 91.02 (±0.12) | RanPAC (87.62/91.63，使用 3.1% 参数，约十倍) |
| ImageNet-R (T=40) | 74.51 (±0.14) | 81.58 (±0.59) | 最优（超越 EASE 71.43/78.04） |
| ImageNet-A (T=10) | 60.54 (±0.63) | 70.15 (±2.23) | 最优（超越 EASE 59.25/68.92） |
| VTAB (T=5) | 94.29 (±0.34) | 94.57 (±0.60) | 最优（超越 EASE 92.85/93.01） |

**关键发现**：
- CL-LoRA 在具有分布偏移的挑战性数据集（ImageNet-R 艺术渲染，ImageNet-A 对抗样本）上优势尤为显著，大幅领先第二名。
- 在 LoRA-based 方法中（InfLoRA、O-LoRA），CL-LoRA 以同等参数效率取得显著优势（ImageNet-R 上 InfLoRA A_bar=73.22, O-LoRA A_bar=72.52 vs CL-LoRA A_bar=81.58）。
- 相比 prompt-based 方法，CL-LoRA 在参数效率和性能上均全面领先，尤其在长序列（T=40 的 ImageNet-R）中优势明显。
- 虽然在 CIFAR-100 上 RanPAC 略优（A_T 87.62 vs 85.32，A_bar 91.63 vs 91.02），但 RanPAC 使用了约 10 倍的可训练参数（3.1% vs 0.3%）。

### 5.2 消融实验 (Table 2)

验证三个核心组件的贡献（A_bar %）：

| KD | GR | BW | CIFAR-100 T=10 | CIFAR-100 T=20 | ImageNet-R T=20 | ImageNet-R T=40 |
|----|----|----|----------------|----------------|-----------------|-----------------|
| No | No | No | 88.20 | 88.13 | 82.24 | 79.61 |
| Yes | No | No | 90.83 | 90.06 | 83.42 | 80.77 |
| Yes | Yes | No | 91.69 | 90.72 | 84.08 | 81.25 |
| No | No | Yes | 89.01 | 88.72 | 82.93 | 80.48 |
| Yes | Yes | Yes | **91.85** | **91.02** | **84.77** | **81.58** |

注：KD = Knowledge Distillation with early exit, GR = Gradient Reassignment, BW = Block-wise Weights。

**关键发现**：
- 仅添加 KD（早退蒸馏）即带来显著提升（CIFAR T=10 上 +2.63 个百分点），表明共享适配器在没有保留机制时会偏向最近任务，逐步遗忘先前知识。
- GR（梯度重分配）进一步增强 KD 的效果（在各设置下均有稳定提升，约 +0.66~+0.86 个百分点）。
- BW（块权重）独立也能带来增益（约 +0.59~+0.87 个百分点）。
- 三个组件组合达到最优，且互补性强——KD+GR 负责跨任务知识保留，BW 负责任务特定特征学习。

### 5.3 共享适配器位置分析 (Figure 3)

在 CIFAR-100 (T=10) 和 ImageNet-R (T=20) 上，变化共享适配器与任务特定适配器的分界点 l in {0, 2, 4, 6, 8, 10, 12}（最终准确率 A_T %）：

| l | CIFAR (T=10) | CIFAR w/o FixB | ImageNet-R (T=20) | ImageNet-R w/o FixB |
|---|-------------|----------------|-------------------|---------------------|
| 0 | 85.0 | 83.0 | 76.0 | 74.0 |
| 2 | 86.0 | 84.0 | 77.0 | 75.0 |
| 4 | 87.0 | 86.0 | 79.0 | 76.0 |
| 6 | 88.0 | 85.0 | 79.0 | 74.0 |
| 8 | 87.0 | 84.0 | 79.0 | 70.0 |
| 10 | 86.0 | 79.0 | 77.0 | 67.0 |
| 12 | 84.0 | 71.0 | 73.0 | 61.0 |

**关键发现**：
- **l = 0**（全部任务特定，无共享）：性能最低，验证了引入共享适配器的必要性。
- **l 增大到 4-8**：性能持续提升，A_T 在 l=6 时达到峰值（CIFAR: 88.0, ImageNet-R: 79.0）。
- **l 过大（10 以上）**：性能明显下降，因为过多的共享适配器挤压了任务特定学习的容量。
- **固定正交 Bs 对比可训练 Bs（w/o FixB）**：固定正交通常优于可训练版本，且在大 l 时优势更加明显（l=12 时 CIFAR: 固定 84.0 vs 可训练 71.0；ImageNet-R: 固定 73.0 vs 可训练 61.0）。即使是 l=0（全部任务特定），固定正交 B 也优于可训练 B（CIFAR 85.0 vs 83.0），印证了 A/B 不对称性的理论发现（Zhu et al., 2024）。

### 5.4 LoRA 配置分析 (Table 3)

在 CIFAR-100 (T=20) 和 ImageNet-R (T=20) 上，变化：
- LoRA 秩 r in {1, 5, 10, 20, 64}
- MHSA 投影矩阵组合：仅 Wv / Wk+Wv / Wq+Wv / Wq+Wk+Wv

**以 Wq+Wv 组合为例的关键数据**（平均准确率 A_bar %）：

| r | CIFAR-100 | ImageNet-R | 参数量 |
|---|-----------|------------|--------|
| 1 | 90.48 | 82.03 | 0.28 * 10^5 |
| 5 | 90.91 | 84.95 | 1.38 * 10^5 |
| 10 | 91.02 | 84.77 | 2.76 * 10^5 |
| 20 | 91.28 | 84.68 | 5.53 * 10^5 |
| 64 | 91.30 | 83.67 | 17.69 * 10^5 |

**关键发现**：
- 即使 r=1，CL-LoRA 仍能取得有竞争力的结果（CIFAR 90.48），表明 CIL 的有效性更多取决于如何高效利用适配能力而非简单增加参数。
- 增加 r 并未始终带来性能提升（存在饱和甚至退化），小秩（r=5 或 r=10）已足够有效。
- 适配更多矩阵（如 Wq+Wk+Wv，r=10 时 CIFAR 90.66, ImageNet-R 84.92 vs Wq+Wv 的 91.02/84.77）参数量大增但性能未见提升，说明保持部分预训练知识不被适配很重要。
- ImageNet-R 对配置选择更敏感（分布偏移大），例如仅用 Wv 在 r=1 时 ImageNet-R 为 81.23 vs Wq+Wv 的 82.03。

### 5.5 推理可扩展性 (Figure 4)

使用任务共享适配器将推理时每个测试样本所需的 adapter 前向传播复杂度从 O(NT) 降为 O(l + (N-l)T)。以 N=12, T=20 为例（基于公式估算）：
- l=0（全任务特定）：约 240 次 adapter 前向传播（12 块 * 20 任务）
- l=6（CL-LoRA 默认配置）：约 126 次（6 共享 + 6*20 特定）
- l=10：约 50 次（10 共享 + 2*20 特定）
- l=12（全共享）：约 12 次（无任务特定）

实际测量值（Figure 4）因包含原型计算等额外开销而略高于上述公式估算值，但趋势一致。

论文进一步指出，task-shared adapter 有潜力降低训练中对清晰任务身份（task identity）的依赖，为 online CIL 和模糊任务边界（blurry task boundary）场景铺路。

## 六、主要贡献与局限性

### 6.1 主要贡献

1. **全新的双适配器架构**：首次在 PTM-based CIL 中提出将任务共享 LoRA 和任务特定 LoRA 统一到双适配器框架中，同时实现高效的跨任务知识共享和任务特定特征学习。
2. **梯度重分配机制**：提出基于前任务 A_s 权值 L2 范数的梯度重分配策略，将 KD 隐式引导转为对关键维度的显式选择性保留，是一种面向 CIL 的针对性知识保留手段。
3. **块权重与正交约束**：引入可学习块权重和轻量正交约束，在不损害塑性的前提下有效减少任务间干扰。与直接在全部 adapter 参数上施加正交约束的 InfLoRA、O-LoRA 等方法相比，更加灵活高效。
4. **全面且系统的实验验证**：在 4 个 benchmark 上与 9 个 baseline 对比，系统验证了方法的有效性、参数效率（仅 0.3%）、推理可扩展性，并提供了消融分析、位置分析、秩与投影矩阵组合分析的丰富实验洞察。

### 6.2 局限性

1. **l 的选取依赖启发式**：本文在所有实验中固定 l=6（N=12 的一半），虽指出最优 l 可通过前几个任务的验证集确定（类似 DualPrompt 的做法），但未给出自动化或自适应的 l 选择策略。
2. **r 和 MHSA 层配置选择缺少自动化**：最优秩和投影矩阵组合依赖手动调参和数据集特性（ImageNet-R 对配置更敏感），未提供自适应选择算法。
3. **未在更大 backbone 上验证**：实验仅基于 ViT-B/16（12 block, 86M 参数），未在更大规模的 ViT（如 ViT-L）或其他架构（如 Swin Transformer）上验证泛化性。
4. **梯度重分配基于 L2 范数**：虽表明 L2 范数是有效的重要性度量，但未对比其他度量方式（如 Fisher 信息、梯度幅值、SNR 等）的优劣。
5. **任务边界假设**：方法仍假设清晰的任务边界（task identity 已知），仅在讨论中提到 task-shared adapter 有降低对明确 task identity 依赖的潜力，但未实验验证在 online CIL 或无任务边界设置下的效果。

## 七、对后续研究的启发与潜在改进方向

### 7.1 方法论层面

1. **自适应 l 选择**：设计基于任务特性（类间差异、分布偏移程度）自动确定共享/特定分界点的机制，例如可学习的分界控制器或基于验证性能的动态调整策略。
2. **更优的重要性度量**：探索除 L2 范数外的重要性度量方式（如基于 Fisher Information、基于梯度的敏感性分析、SNR 等），进一步提升梯度重分配的效果。
3. **动态秩分配**：结合 AdaLoRA 等动态秩调整方法，根据任务难度和数据特性自动分配不同维度的适配能力。
4. **跨架构与跨 PEFT 泛化**：将双适配器思路推广到其他 backbone（如 ViT-L、Swin Transformer、ConvNeXt）以及与其他 PEFT 方式（如 Prompt Tuning + LoRA 混合）。

### 7.2 应用层面

5. **无任务边界/在线 CIL**：本文在讨论中提出了将 task-shared adapter 应用于 online CIL 和模糊任务边界设置的潜力，这是直接的后续方向。可研究在无法获得 task-id 条件下的推理策略（如基于共享特征直接分类或采用 routing 机制）。
6. **多模态 CIL**：将 CL-LoRA 的共享/特定双适配器设计推广到多模态（视觉-语言）CIL 任务中，利用跨模态的知识共享。
7. **联邦增量学习 (Federated CIL)**：LoRA 的轻量特性天然适合联邦学习场景，将 CL-LoRA 的共享/特定分离思路引入联邦 CIL 中，在客户端保留任务特定适配器、在服务端聚合共享知识。

### 7.3 理论层面

8. **共享适配器的理论分析**：对固定正交 Bs 为何能保留低维结构并缓解遗忘提供更深入的理论分析（如从 NTK (Neural Tangent Kernel) 或表征坍缩的角度）。
9. **任务间知识迁移的量化度量**：建立可量化的指标来评估共享适配器捕获的跨任务知识的质量，指导适配器设计和训练策略优化。
10. **最优 l 的理论依据**：从信息瓶颈或互信息角度分析 ViT 不同深度的表征特性，为共享/特定分界点的选择提供理论支撑。
